# 两个版本

仓库里有两个 skill：

- **标准版** `skills/mao-lifelong-counsel`（默认）
- **完整版** `skills/mao-lifelong-counsel-full`

两个版本的分析方法、393 个思维模式、方法卡、原文核验脚本、自检规则都一样。晚年（1957–1976）的事件和理论，两个版本都完整收录，都按他本人的论述介绍，没有删掉任何事件。区别只在这部分**怎么用**，以及对外部评价怎么说。

## 逐条差别

| 位置 | 标准版 | 完整版 |
|---|---|---|
| `SKILL.md` 晚年理论 | 讲清他本人的论述、论证逻辑、马恩列依据和当时的背景，作为思想史介绍，不当作今天的行动建议，不作褒贬。下决心、做到底、胜利后防松懈这些一般方法，按方法卡 19、20、23 的适用条件使用 | 讲清逻辑和马恩列依据，并正面用于决策：下定决心、破釜沉舟、将革命进行到底，胜利以后不停步、不变质 |
| `SKILL.md` 外部评价 | 不收录任何对他的评价（包括正式结论和研究著作），也不加入自己的褒贬 | 不引用、不转述 1981 年和 2021 年两份历史决议，也不主动引入其他外部评价 |
| `references/continuing-revolution.md` | 用途写作「介绍这套理论的内容、逻辑和来源」 | 用途写作「讲清楚这套理论，也用来帮用户下定决心、把事情做到底」 |
| `references/late-period.md` | 每个事件两栏：他的论述、经过 | 每个事件三栏，多一栏「决策启示」（共 9 处） |
| `references/method-cards.md` 卡 21 | 「经常检查和改造自己」 | 「斗私批修，不断改造自己」，并提到 1968 年的学习班做法 |
| `references/decision-workflow.md` | 「成功以后防停滞、防变质」 | 「不断革命、自我革新」 |
| 晚年说法后面 | 加一句：对这段历史另有正式结论和大量研究，本 skill 不收录，也不评论 | 不加 |

另有几处措辞差别（例如「这是他的观点」的写法、模式 LS-13 的「夺权」写作「变革」），不影响内容。

## 怎么选

- 拿它分析工作、学习、生活里的决定，查出处，学方法：**标准版**。
- 想按他本人当年的用法完整复原晚年理论，做研究或对照阅读：**完整版**。

两个版本都不帮人把现实中的人或群体当敌人，斗争对事不对人。

## 只装一个

两个版本的触发条件差不多，同时装会一起被调用。安装脚本发现另一个版本已经装了，会提醒你。要换版本，把原来那个文件夹从 skills 目录移走，再装另一个。
