# 原文来源、分层和版权

## 分层

回答里放进引号的话，都要先在原文库里核到，再按层级标出处。

| 层级 | 内容 | 引用时怎样标 |
|---|---|---|
| A | 《毛泽东选集》第一至四卷 | 篇名和卷次，如（《矛盾论》，选集第一卷） |
| A5 | 《毛泽东选集》第五卷（1977 年版，后停止发行） | 同上；文集也收了的，可以标文集卷次 |
| AW | 《毛泽东文集》第一至八卷 | 篇名和卷次 |
| D | 建国以来毛泽东文稿、军事文集、外交文选、书信选集、早期文稿 | 书名和册次；OCR 文本，个别字可能有误 |
| S | 诗词 | 诗题；注释不是他的话 |
| Y | 《毛主席语录》 | 尽量找回原篇 |
| AM | 竹内实等编《毛泽东集》正编、补卷 | 注明「据《毛泽东集》（原始版本）」 |
| B | 谈话记录、批示、散篇 | 注明「据某年某月谈话记录」 |
| C | 静火版、《毛泽东思想万岁》等非官方汇编 | 注明「据非官方汇编，未经官方文本核对」 |
| P | 《毛泽东哲学批注集》 | 先确认是他的批注，不是被批注的原书文字 |
| N | 《毛泽东年谱》 | 只有引号里、确认是他说的写的摘引才能引；编者叙述只作史实线索 |
| M | 马恩列原著、艾思奇《大众哲学》 | 理论来源，不能说成毛泽东的话 |

网上流传、但核不到原文或常被误引的句子，列在 `references/quote-blacklist.md`，处理时以清单为准。

## 原文库的规模（作者本机）

约 9,300 篇、64.8 MB。其中建国以来文稿 7,189 个文件，军事文集 2,335 个，毛泽东集补卷 1,519 个，《毛泽东思想万岁》999 个，文集 820 个，年谱 803 个（按年月分文件）。

## 为什么仓库默认不带原文库

以下是作者的理解，不构成法律意见：

- 按中国《著作权法》，自然人作品的保护期是作者终生加去世后五十年，截至第五十年的 12 月 31 日。毛泽东 1976 年去世，他本人作品在中国的保护期到 2026 年 12 月 31 日。
- 编者的注释、年谱的叙述、文献集的编辑整理、马恩列著作的中文译本，著作权属于编者或出版单位，另有各自的保护期。
- 其他国家的规定不同。GitHub 按美国法律处理侵权通知。

所以本仓库只收录：本项目自己写的说明文件、思维模式（含为说明问题引用的少量原话，每条标明出处）和脚本。原文库的目录结构和安装方法见 `skills/mao-lifelong-counsel/kb/README.md`。没有原文库时，skill 照样可以分析问题，只是原话一律按「未核到」处理，不加引号。

## 已知问题

- D、AM 补卷、P、N 四层多来自扫描件的 OCR，没有和纸本逐页对校，个别字可能有误。
- 网页转录的文本也没有和纸本逐页对校。正式写作时请核对纸本。
- 库里没有传记和回忆录。出自传记的句子会显示「未核到」，这不等于是伪造的。
