# 使用说明

## 怎样调用

- Codex：在对话里写 `$mao-lifelong-counsel`，或者直接说「用毛泽东的方法帮我分析……」，Codex 会按描述自动选用。
- Claude Code 和其他支持 Agent Skills 的工具：提到毛泽东思想方法、毛选、「教员的方法」等，工具会自动加载；也可以明确说「用 mao-lifelong-counsel 这个 skill」。

## 怎样问效果好

1. **给事实。** 数字、时间、涉及哪几方、你手里有什么、限期是多久。它会先给判断，再告诉你哪一条事实变了结论就要变。事实不够时，它会先追问一两个最关键的。
2. **说清你要什么。** 是要拿主意、判断趋势、复盘一件事，还是查一句话的出处。
3. **允许它追问。** 按他的方法，没有调查就没有发言权；回答末尾的「需要查清的事」值得认真看。

## 可以问的几类问题

- 拿主意：「我们公司收到一份收购意向，估值低于预期，还要求创始团队留任三年；另一条路是融资，但投资人要先看到客户集中度下降。我该怎么想？」
- 带人、做事：「我接手了一个全年级倒数第一的班，一年内想带起来，从哪里下手？」
- 判断趋势：「我家做外贸面料，订单在往东南亚转，未来三到五年这个行业会怎么走？」
- 读书和学习：「毛泽东自己是怎么读书的？他怎样对待作者、对待不同意的地方？」
- 查出处：「网上说『××××』是毛泽东说的，是真的吗？出自哪里、什么场合？」
- 复盘：「这件事我做砸了，按他复盘的办法，我该怎样总结？」

## 它不会做的事

- 不扮演他，不用第一人称替他说话。你明确要求时，只写一段由核验过的原话串成、标明「仿写」的文字，分析另起一段。
- 不帮你把同事、家人或任何现实中的人当成敌人，不出整人的方案；会改给对事不对人的办法。
- 不引用外部评价，史实按通行的事实中性叙述。
- 不替代医疗、法律、财务、心理方面的专业意见。

## 自己核验一句话

装了原文库以后，在 skill 目录下运行：

```
python scripts/verify_quote.py "没有调查，没有发言权"
python scripts/search_kb.py 调查 发言权 --tiers A,AW
python scripts/find_patterns.py 几条路要选 谈判让步
```

Windows PowerShell 下中文出现乱码时：参数写进 UTF-8 文本文件，用 `--file` 传入；输出加 `--out 结果.txt` 再打开这个文件。

## 更新和卸载

- 更新：重新运行安装脚本（旧版本会自动改名备份），或用 `npx skills add` 重新安装，然后重启工具。
- 卸载：删掉 skills 目录下的 `mao-lifelong-counsel` 文件夹。
