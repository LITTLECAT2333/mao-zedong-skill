# 工作原理

## 一条流水线

```mermaid
flowchart LR
  A["分层原文库<br/>约 9,300 篇"] --> B["思维切片卡<br/>约 1.3 万张"]
  B --> C["按 14 个领域聚类"]
  C --> D["思维模式<br/>393 个"]
  D --> E["总索引 + find_patterns.py"]
  E --> F["按主线分析<br/>thinking-engine.md"]
  F --> G["verify_quote.py<br/>逐字核验原话"]
  G --> H["回答"]
```

1. **原文库**按来源可靠程度分层：选集、文集（A、A5、AW），建国以来文稿、军事文集等文献集（D），竹内实编《毛泽东集》（AM），谈话记录（B），非官方汇编（C），哲学批注集（P），年谱（N），以及作为理论来源的马恩列原著（M）。层级决定一句话能不能引、怎样标出处，见 [SOURCES.md](SOURCES.md)。
2. **思维切片卡**：每篇原文由 AI 逐段抽成卡，每张卡 10 栏：篇目、证据性质（实时决策、讲话、事后总结、书信……）、场景、思维动作、观点、领域、关键词、锚点（原话）、可迁移、边界。锚点必须能在原文正文里原样找到，编者注释里的话不算。
3. **思维模式**：把讲同一个思维动作的卡聚到一起，提炼成「他在某类处境下反复走的一条推理链」。提炼时要求至少三条证据、跨三个年代；393 个模式里有 375 个达到，其余 18 个证据偏少或集中在一两个年代，以后补卡时优先补。每个模式都写明：一句话、触发处境、推理链、他常问的问题、跨期证据、前后变化、边界与失误、可迁移的用法。393 个模式按 14 个领域分文件，总索引按用户常带来的问题分组。
4. **回答时**：模型先把用户的处境概括成几个抽象的处境词，用 `find_patterns.py` 找出一到三个合用的模式；再按 `thinking-engine.md` 的主线走一遍（问准、摸情况、找特点、抓矛盾、算力量账、看对手和环境、分阶段、定关节、出方案、下决心、边做边认识、总结）；原话一般只引零到三条，每条先用 `verify_quote.py` 核到原文；交出前按 13 条自检。

## 它和真人有什么不同

这个 skill 复原的是他留在文字里的思考方法，不是他本人。差别主要在六处：

1. **信息从哪里来。** 他做决定靠第一手情况：亲自调查、前线电报、当面谈话，还有大量没写下来的口头讨论。skill 只知道用户告诉它的事，所以「调查研究」在这里变成了向用户追问。事实给得不全，结论就只是假设。
2. **知识是什么形态。** 他的经验是几十年打仗、做组织工作练出来的，遇事时全部经验同时起作用。skill 的知识是写成文字的模式和原文，每次只能读进当前问题用得上的几段；读得越多，越挤占分析的注意力。
3. **会不会从结果里学。** 他做错了会复盘、改主意，下一次就不同。skill 不会从一次对话里学到东西，每次都从同一份文件开始。
4. **有没有利害。** 他的决定关系成败生死，这决定了他敢冒多大的险、下多大的决心。语言模型没有利害，又被训练得周全稳妥，给出的方案往往比他本人更保守、更面面俱到。
5. **材料本身有偏。** 留下来的文字经过挑选和编辑：公开发表的多，私下的考虑少；成功的总结多，失败的细节少。本 skill 又只用他本人的论述，不加外部评价，所以它呈现的是他对自己思想的叙述，不是一份独立的历史评价。
6. **时代不同。** 他的推理建立在他那个时代的处境和概念上。把这些方法用到创业、带班、外贸这些今天的事情上，是模型在做类比，不是他本人在做。

能做到的是：方法有出处，原话可核对，推理步骤可以检查。「完全像他」做不到，本 skill 也不往这个方向用力，比如不扮演、不模仿口吻。

## 怎样才能更像

这些是下一步要做的事，欢迎参与：

1. **用他当年的真实决策点回测。** 只给出某个日期以前已知的情况，看 skill 推出的决定和理由是否接近他实际的决定。这是衡量「像不像」的直接办法；现有的回测衡量的是「建议好不好」。难点是模型本来就记得著名事件，要选冷门的决策点。
2. **不用 skill 的对照组。** 同一个模型不装 skill 回答同样的问题，才能看出 skill 本身带来了多少提升。
3. **完整的案例库。** 现在的模式是抽象的推理链。按「当时的情况、他的判断、下的决心、结果、他本人事后的复盘」整理一批完整案例，类比会更贴实。
4. **分时期调用。** 同一个模式在不同年代的用法不同（模式里有「变化」一栏），回答时可以按用户处境挑最接近的时期。
5. **用户复盘。** 用户按建议做了以后，把结果记下来，下次一起复盘。这是让建议接近他「边做边认识」的唯一办法。
