# 意志与人生（YZ）思维模式

## YZ-01 亲友求助，公私分开
- 一句话：亲友求工作求推荐时，公事交给管事的人按标准办，私人困难用自己的钱帮。
- 触发：亲友、旧交、同乡来信求安排工作、求推荐、求接济，或者亲属仗着关系搞特殊时。
- 推理链：1. 先把一家一人的困难放到许多人的处境里看，说明不是个别情况。 2. 讲清公家的标准和自己的局限：机构有资格规定，自己不了解对方底细，不凭私交和来信表态。 3. 把能不能办的判断交给了解情况、管这件事的人去考察，自己不直接安排。 4. 肯定对方守在原岗位的价值，劝他就近设法，不要远出徒劳。 5. 实际的生活困难用私人的钱另行接济，并先问对方愿不愿接受；对亲属则明说“因为爱他们，所以不能特殊”，请当地干部放手管。
- 他常问的问题：这件事归谁管，那里的标准是什么？我真的了解这个人的底细吗？对方现在的工作本身是不是就很好？能不能用我自己的钱帮，而不是用公家的名义？
- 跨期证据：
  - 1937｜《给文运昌的信》｜AW｜“我为全社会出一些力，是把我十分敬爱的外家及我家乡一切穷苦人包括在内的，我十分眷念我外家诸兄弟子侄，及一切穷苦同乡，但我只能用这种方法帮助你们”｜11c-47——公家给旅费是因为烈士家属身份，「不是他私人的缘故」
  - 1949｜《年谱 1949-10-25 条（NP06037，第 275–278 行）》｜N｜“你在上海教书甚好，教书就是为人民服务。为不荒废课业，不要来京。”｜np08-48——劝旧识守原岗位、就近设法
  - 1951｜《关于彭友胜工作安排问题的信》｜D｜“我在复信上已说明，不一定有结果，因为程先生他们不清楚彭的历史，连我也不清楚，不便提出确定的意见。”｜wg03-84——把决定交给地方考察
  - 1954｜《给石城乡党支部、乡政府的信》｜AW｜“第二、因为我爱他们，我就希望他们进步，勤耕守法，参加互助合作组织，完全和众人一样，不能有任何特殊。”｜32c-29——替乡干部解除「不好放手管理」的顾虑
  - 1954｜《给田家英的信》｜D｜“我不大愿意为乡里亲友形诸荐牍，间或也有，但极少。”｜wg07-085——文史馆资格严，改用稿费私人资助
  - 1957｜《给孙燕的信》｜D｜“升学的事，我不宜于向学校写信。能否考取，听凭学校。”｜wg11-011——同时寄钱、给退路
- 变化：延安时期以上下待遇平等、没有薪水为由劝阻亲友来投；建国后改为把事情转给地方和机构按通例考察，再用稿费私人资助。
- 边界与失误：拒绝特殊照顾不等于冷淡亲人，他在信里照样慰问、寄钱、请对方常通书信（11c-47、wg11-011）。只劝耐心而不把问题转给管事的人，就不是这种做法。这一招处理的是私事求助；涉及原则分歧时另有态度，他早年说“所争者主义，非私人也”（sx01-03）。
- 可迁移：〔个人〕有了一点位置以后，亲友托办事时先分清哪些归制度管、哪些可以自己掏钱帮；不了解的人不凭一封信表态。〔社会〕机构用人要有公开标准，掌权者的亲属同众人一样受管理，基层干部可以放手管。
- 相关：YZ-15，YZ-20

## YZ-02 准备革命革到自己头上——人人要改造，包括自己
- 一句话：拿要求别人的那把尺子先量自己，承认自己也在改造之中，而且没有终点。
- 触发：批评别人、发动整顿、听到“我已经改造好了”“为什么只要我们改”的议论，或者别人夸自己英明时。
- 推理链：1. 先点破双重标准：对人一套、对己一套，斗别人凶、斗自己不行，就过不了关。 2. 接过“为什么只要我改”的反问，不否认，反而扩大：人人都要改，领导者、劳动者、我本人都在内。 3. 拿自己现身说法：具体说出自己原来信过什么、有什么毛病，是怎样在实际斗争里一步步改过来的，不说空话。 4. 划一条线：大家都要改，但各人问题的性质不同，不能混为一谈；人和思想分开，思想严肃对待，人可以改。 5. 说明为什么要一直改：长期干一行会养成习惯和偏向，形势变了还用老一套就要落后。 6. 领导者自己先做：先写笔记、先检讨，以身作则，再要求别人。
- 他常问的问题：我要求别人的，自己做到了没有？我是不是“对人是马克思主义，对己是自由主义”？“我都要改造，你不要改造了吗”（38b-15）？引火烧身，敢不敢（53c-63）？
- 跨期证据：
  - 1921｜《致彭璜》｜D｜“吾人有心救世，而于自己修治未到，根本未立，枝叶安茂?工具未善，工作奚当?”｜sx01-02——给朋友列了十条缺点，随即承认除三条外「其余弟一概都有」
  - 1937｜《反对自由主义》｜A｜“说的是马克思主义，行的是自由主义；对人是马克思主义，对己是自由主义。两样货色齐备，各有各的用处。”｜11b-13——点破双重标准
  - 1942｜《关于整顿三风》｜AW｜“批评和自我批评是一个整体，缺一不可，但作为领导者，对自己的批评是主要的。”｜17c-22——「我也要写一点」，首长先写
  - 1957｜《关于正确处理人民内部矛盾的问题》｜A5｜“我在书本上学了一点马克思主义，初步地改造了自己的思想，但是主要的还是在长期阶级斗争中改造过来的。”｜37c-59——接过反问，扩大到人人，再划开性质
  - 1966｜《对中央首长的讲话》｜C｜“有些同志斗别人很凶，斗自己不行，这样自己永远过不了关。”｜53c-63——「准备革命革到自己头上来」
  - 1970｜《与斯诺的谈话——关于文化大革命》｜C｜“我长期也是资产阶级世界观。开头相信孔夫子，后头相信康德的唯心论。什么马克思，根本不知道。”｜56b-21——拿自己的转变说明世界观要长期改
- 变化：早年在给师友的信里检讨自己的性格（“我因易被感情驱使，总难厉行规则的生活”，mb01-041）；四十年代整风时要求领导者以自我批评为主；1957 年面对“不需要改造”的议论，把自己放进去并加上“性质不同”的界线；六十年代要求领导干部在运动里把革命指向自己；七十年代对外宾讲自己怎样从别的世界观转过来。
- 边界与失误：这一招是自省用的，不是拿“你也有毛病”去回应别人的批评。他把自己的转变归到处境和对手的推动，不归到个人英明：“其实不那么英明，很蠢，是敌人教会的。”（51b-42）在七大上讲缺点时他说“这一条我也在内”（22b-20）。
- 可迁移：〔个人〕要求团队改进时，先说清自己哪里没做到、准备怎样改；把“我已经够好了”当成该警惕的信号。〔社会〕组织整顿从领导层开始，领导者先检讨、先交笔记；区分问题的性质，对人留余地，对错误思想不含糊。
- 相关：YZ-16，YZ-19，YZ-22

## YZ-03 「我听我自己的」——合乎真理就坚持，少数也不怕
- 一句话：判断只问合不合真理，不问是否公认；处在少数时坚持，并靠说服和成绩去争取多数。
- 触发：面对权威、公认看法、专家意见，或者自己在集体里处于少数、被人说成“狂妄”时。
- 推理链：1. 先问这条规矩、这个意见是外加的命令，还是自己认准的道理；只因外力命令才服从，是奴隶心理。 2. 判断的标准只放一条：合不合真理，不管它是不是当今公认、合不合人意。 3. 对权威和专家的意见打折扣：听一部分，结合自己对实际情况的了解，最后自己拿主意。 4. 处在少数时，不因为人少就放弃判断，“一票”也算数；同时不怪别人，靠好好说服人、做出成绩给大家看，由一个人变成两个人、再变成一大片。 5. 给自己划界：只说“有时候”多数是错的，少数本身不是正确的证明；真有病要治，不能拿来讳疾忌医。
- 他常问的问题：我是因为它对才照做，还是因为它是命令才照做？这个看法合乎真理吗，还是只是大家都这样说？专家的话里，哪些符合我自己了解的情况？我在少数，是怪别人，还是怪自己没有做出成绩、没有说服人？
- 跨期证据：
  - 1917｜《「伦理学原理」批语》｜AM｜“吾从前固主无我论，以为只有宇宙而无我，今知其不然。盖我即宇宙也。”｜mb14-59——批「道德律出于神的命令」是奴隶心理，服从神为什么不服从自己
  - 1919｜《健学会之成立及进行》｜D｜“不管他到底是不是（以今所是的为是），合人意不合人意，只顾求心所安舍乎真理才婴”｜zq03-013——真确的学理多是被加上「狂妄」名号的人发明的（锚点为 OCR 原文）
  - 1951｜《与各中央局及大城市党委统战工作同志谈话纪要》｜C｜“不要怪别人只怪你们自己没有招兵买马、积草囤粮。不要使自己陷于孤立，要好好做出成绩来给大家看。”｜31b-33——先肯定少数派正确，少数靠说服慢慢扩大
  - 1964｜《接见日本社会党人士佐佐木更三、黑田寿男、细迫兼光等的谈话》｜C｜“有时候多数是错误的，少数是正确的。四百年前，哥白尼在天文学上说地球是转动的，当时全欧洲人没有一个人相信。”｜50c-65——说的是「有时候」
  - 1966｜《毛泽东主席接见阿尔巴尼亚党政代表团谈话记录（1966年5月5日）》｜B｜“1927、28、29、30年3年半的时间，开起会来只有我一票，一票就是很多的嘛。”｜53b-43——熟悉其人所以不盲从，再一个军团一个军团地说服
  - 1966｜《毛泽东主席接见阿尔巴尼亚党政代表团谈话记录（1966年5月5日）》｜B｜“可不要迷信医生，我是跟我的医生订了条约的，不发烧就不要理我。他的话我顶多听50%。”｜53b-75——被追问后改口「不到三分之一」，「我听我自己的」
- 变化：早年在批语里用“我即宇宙”的唯心说法立论，在学会评语里讲学问只求合乎真理；五十年代起讲少数派怎样靠说服和成绩扩大；六十年代回忆自己长期处在少数的经历，并落到对医生、对暮气的日常态度。
- 边界与失误：独立判断不等于不听意见、拒绝集体决定；他回忆处在少数时用的是“请求中央免调”这样的正式渠道（53b-43）。他谈不听医生的话之后紧接着补了一句：有的人真有病，要治（54d-19）。“有时候多数是错误的”只说“有时候”（50c-65）。
- 可迁移：〔个人〕遇到权威意见先问依据，结合自己掌握的事实再定；自己是少数时，不抱怨环境，拿出成绩、一个一个去说服。〔社会〕决策时给少数意见留出说话和被检验的渠道，不以人多人少定对错。
- 相关：YZ-08，YZ-17

## YZ-04 困难能够克服——先认困难，再比困难；顺利时专讲难的
- 一句话：困难当前先摆出来再用比较定信心；条件有利时反过来专门把困难讲透。
- 触发：处境艰难、有人惶惑悲观时；或者形势有利、大战和新任务在前、队伍可能轻敌时。
- 推理链：1. 先肯定前途和决心，紧接着说明这不等于没有困难：条件好不等于胜利会自己到来，还得自己去干。 2. 把困难一条条列出来，充分估计，不隐瞒；最坏的那一块专门用一段时间讲透。 3. 用比较定信心：同自己的过去比（更难的时候也渡过了），同别处比（别人更难也撑住了），同对手比（对手也有困难，也许更大）。 4. 讲出克服困难的具体办法和需要的时间，不性急。 5. 讲的顺序和态度：用积极态度先对骨干说明白，再由骨干向大家说明，免得将来发生怨言；讲清困难也是筛选，有不怕苦的意志才去。 6. 已经陷入被动时再坚持一下，转折常在自己最困难、对手最起劲的时候。
- 他常问的问题：有利条件列完了，难处在哪里，讲透了没有？我们过去有没有比这更难的时候？对手就没有困难吗？这些困难是先说清楚，还是等将来变成怨言？
- 跨期证据：
  - 1930｜《,八个大胜利的条件》｜AM｜“可是一定要我们勇敢去打仗，不勇敢去打，决没有坐在家里打胜仗的道理。”｜mb06-038——八项条件逐项「我们有，敌人没有」，结尾提醒条件好不等于胜利
  - 1938｜《抗日游击战争的战略问题》｜A｜“往往在敌人十分起劲自己十分困难的时候，正是敌人开始不利，自己开始有利的时候。往往有这种情形，有利的情况和主动的恢复，产生于‘再坚持一下’的努力之中。”｜12b-05
  - 1942｜《抗日时期的经济问题和财政问题》｜A｜“我们曾经历过比现在还要困难到多少倍的时候，那样的困难我们也渡过了。”｜18c-22——同自己过去比、同华北华中比，随后转到精兵简政的具体措施
  - 1947｜《做好夺取大西北的一切准备》｜AW｜“关于陕甘宁边区只能供给你们粮食，其他一切都要太岳自己接济一项，你们也要向干部说得清清楚楚，免得将来发生怨言。”｜25d-23——用积极态度先向营以上干部说明白
  - 1960｜《在中央机关抽调万名干部下放基层情况报告上的批语》｜D｜“全国大好形势，占三分之二地区；又有大不好形势，占三分之一的地区。五个月内，一定要把全部形势都转变过来。”｜wg16-001——讲完大好形势，专门大讲坏的那一块，有不怕苦的意志才去
  - 1970｜《毛泽东主席会见老挝人民党总书记凯山等谈话记录（1970年7月15日）》｜B｜“人多也有困难。比如说，美国它就没有困难？泰国它就没有困难？它们的困难也许比你们还大。”｜55d-19——同对手比困难
- 变化：三十年代写进宣传材料，提醒官兵条件好也要勇敢去打，并点名“怕困难”“口称冒办法”等消极现象（np01-046）；四十年代成为电报里规定的动员程序，并说“抗战愈益接近胜利，困难将愈益严重”（18d-26）；1960 年用于干部下放前的形势教育；六七十年代多讲给外国来访者，重在同对手比困难。
- 边界与失误：比较只是为信心找根据，不能代替克服眼前困难的具体办法（18c-22 讲完比较就转到精兵简政）。“再坚持一下”以正确估计客观情况为前提；他在同一篇里说，过于乐观的估计带来不需要的冒险，同样会丢掉主动（12b-05）。只讲困难不讲意义会打击士气，所以他要求“用积极态度”去讲（25d-23）。
- 可迁移：〔个人〕面对难事，先把困难写成清单，再找自己渡过的更难的时候作参照；顺风时专门留出时间想“最难的那一块是什么”。〔社会〕布置任务时把不利条件事先向骨干讲透，由骨干向下传达，比事后安抚有用；派人去艰苦岗位前先讲清最坏的情况，让人自愿选择。
- 相关：YZ-10，YZ-11，YZ-24

## YZ-05 看重青年，也让青年向老人学
- 一句话：把难题交到年轻一代手上，看青年的长处，老少处不好先看老人怎样待青年。
- 触发：谈青年的位置、新老关系，或者青年的积极性被压抑、被一般看待时。
- 推理链：1. 先把天下的事、眼前的难题落到青年这一代自己身上，不许拿出身、地位推脱。 2. 说明青年的特点：最积极、最有生气、最肯学习、最少保守，不要一般看待、抹杀这些特点。 3. 用事实打破“大事是老人、大官做的”：大多数发明创造出自年轻、不出名、地位低的人；老资格和新生力量比，新生力量更有希望。 4. 青年和老人处不好时，先看老人怎样对待青年，原因往上追到家庭和社会。 5. 对压抑青年的保守思想不妥协，办法是“试试看”，让成绩去说服人。 6. 同时要求青年向老年人、成年人学习，尽量在他们同意下做事；年长的人更应谦虚。
- 他常问的问题：这件事归根到底落在谁身上？“难道好事情都是老头子、做大官的做的吗？”（47b-08）年轻人不喜欢老人，是不是老人先欺负了年轻人？能不能先试试看，让成绩说话？
- 跨期证据：
  - 1915｜《毛泽东诗词》｜S｜“何以报仇？在我学子！”｜02-01——把国耻的担子收到自己这一代学生身上
  - 1925｜《毛泽东诗词》｜S｜“怅寥廓，问苍茫大地，谁主沉浮？”｜02-05——答案落在「指点江山」的同学少年身上
  - 1940｜《吴玉章寿辰祝词》｜AW｜“记得我在小的时候，很不欢喜老人，因为他们是会欺负青年人的，青年人谁没点错误呢?但是你错不得，他们对你是很凶的。”｜15d-20——老人受青年敬爱，是因为热心帮助青年
  - 1955｜《〈中国农村的社会主义高潮〉》｜A5｜“对于保守思想当然是不应当妥协的，那末好罢，就来试试看，成绩出来了，他们也就同意了。”｜33d-38——同时要求青年向老年人、成年人学习
  - 1955｜《在中国共产党全国代表会议上的结论的提纲》｜D｜“一种是老资格（像我这样的人），一种是新生力量，哪一种人更有希望呢？当然是新生力量。”｜wg08-058——中年以上的人据说经验多，更应谦虚
  - 1960｜《接见日本文学代表团时的谈话》｜C｜“不知你们日本情况如何？难道好事情都是老头子、做大官的做的吗？我就不相信。”｜47b-08——同一条规律用到自己身上：年岁大了创造性减少，是自然规律
- 变化：早年是给自己这一代人立志；延安以后站到长辈位置上，讲老人怎样对待青年；五十年代起讲组织怎样发挥青年，并拿自己作“老资格”的例子。
- 边界与失误：“试试看”适合可以回头、风险可控的事；他在同一按语里要求青年必须向老年人、成年人学习，尽量在他们同意之下做事（33d-38）。讲老人欺负青年，说的是老人对待青年的方式，不是说年长者都该被怀疑。他承认自己“年岁大了创造性减少”（47b-08）。
- 可迁移：〔个人〕年长者先检查自己是怎样对待年轻人的；年轻人有了想法，先在小范围试，拿结果去说服前辈。〔社会〕团队里给年轻人留出试的空间和发言权，用成绩而不是资历决定谁的方案上。
- 相关：YZ-06，YZ-19

## YZ-06 骂少了不好——什么都是逼出来的
- 一句话：把批评、挫折和阻力当作长本事的条件，被捧和一帆风顺反倒要警惕。
- 触发：被表扬、被捧，或者怕人批评、刚受了挫折、遇到很大阻力时。
- 推理链：1. 先把被捧翻过来看：有人捧你不是好事，一帆风顺没受过挫折就没有经验。 2. 主张多听批评：好话坏话都是话，都要听，骂少了不好。 3. 拿实例作证：好东西是处境逼出来的，换了从容的处境就写不出来、想不出来；队伍从大挫折里剩下的人反而更强。 4. 把挫折看成转机：错误改正了、了解了就过去了，经过挫折大进一步，错误就转变为有益。 5. 推到道理本身：阻力能增力，圣人是抵抗极大之恶而成的，学说也是压出来、经风雨才兴旺的。
- 他常问的问题：别人捧我，是好事吗？这次挫折逼我想明白了什么？我怕的批评里，有没有我该听的？“为什么人家不反对你？”（53c-22）
- 跨期证据：
  - 1917｜《毛泽东诗词》｜S｜“河出潼关，因有太华抵抗，而水力益增其奔猛。”｜02-03——阻力成了力量的来源
  - 1945｜《致王梓木》｜D｜“也许你经过这个挫折会要大进一步的，那么，错误也就转变为有益了。”｜sx01-57——前提是错误已经改正、已经了解
  - 1959｜《在庐山会议上的多次讲话、批语》｜C｜“好话坏话都是话，都要听。”｜45b-35——「越讲得一塌糊涂越好，越要听」，也坦白「我也紧张」
  - 1964｜《在一次汇报时的插话》｜C｜“走了两万五千里，腿‘讲话’了，发言了。这样我们的脑子就要想一想，遵义会议就开成了，才改过来。”｜50b-17——「学会打仗，什么都是逼出来的」
  - 1964｜《与毛远新同志的谈话纪要（一）》｜C｜“我写《实践论》、《矛盾论》，就是逼出来的，如果现在让我写，我就写不出来。”｜49d-60——有人捧你不是好事，骂少了不好
  - 1966｜《毛泽东主席同胡志明主席谈话记录（1966年6月10日）》｜B｜“你是老资格了，也有一个坏处，你没有受过挫折，没有经验。”｜53c-22
- 变化：1917 年在诗句和批语里从自然和圣人立论（“圣人者抵抗极大之恶而成者也”，mb14-48）；四十年代劝犯过错误的人把挫折看成转机；1956 年拿自己落选、受处分的经历现身说法（35d-07）；六十年代对青年说多挨骂，对外宾说一帆风顺是坏处，并说“你们老怕别人批评，马克思主义就是压出来的”（53d-05）。
- 边界与失误：多挨骂指接受批评和压力，不等于容忍人身攻击。“错误转变为有益”以错误已经改正、已经了解为前提（sx01-57）。说挫折有好处，是从学会东西的角度讲，不是为本可避免的损失开脱；他讲三年大发展时同一处也承认“我们没有经验”（50b-17）。他讲自己受处分时，同时清点了自己真犯的错误（35d-07）。听坏话不等于全盘接受，要分清正确与不正确（45b-35）。
- 可迁移：〔个人〕被夸时多问一句“哪里还不够”；把一次失败当成逼自己总结的机会，写下这次学会了什么。〔社会〕团队不要只表扬，要给批评留出正式的渠道；复盘挫折时问“逼出了什么新办法”。
- 相关：YZ-05，YZ-11，YZ-22

## YZ-07 骄傲不起来，也不做贾桂——把穷白看成好写字的白纸
- 一句话：底子薄时如实认差距，既不翘尾巴也不自卑，把“没能力”改判为“没练习”，相信能学会。
- 触发：谈自己和强者的关系，底子薄、被人看不起，或者有人怕外国、怕权威、觉得自己学不会时。
- 推理链：1. 先如实列出不如人的地方，说明骄傲不起来。 2. 同时防另一头：做奴隶做久了伸不直腰，要提高自信心；问一问“洋”和“神”是不是只是看的位置不同。 3. 找原因时把“没能力”改判为“没练习”：落后是压迫和不让练习造成的，不是本来不行。 4. 从发展看，把缺点翻成优点：穷就要变，白纸正好写字，底子空负担少。 5. 回应看不起自己的人：原来不懂的能学会，别人也是学来的。 6. 往前推：将来强了也要谦虚，还要向人家学习。
- 他常问的问题：我们是真没能力，还是没练习？中国人算不算洋人（41d-37）？别人会的，是不是也是学来的？将来强了，还学不学？
- 跨期证据：
  - 1919｜《民众的大联合》｜AM｜“却不是我们根本的没能力。我们没能力，有其原因，就是‘我们没练习’。”｜02-44——先自揭其短，再改判原因
  - 1956｜《论十大关系》｜AW｜“从发展的观点看，这并不坏。穷就要革命，富的革命就困难。”｜35b-16——同时用贾桂「站惯了，不想坐」防自卑，「一万年都要学习嘛!」
  - 1958｜《在汉口会议上的插话》｜C｜“别的星球上的人看我们，是不是也是神仙？这是一种迷信。”｜41d-37——病根是「当奴隶习惯了，看不起自己」
  - 1964｜《接见阿尔及利亚文化代表团时的谈话》｜C｜“他们都走了更好。你们那里更干净。在一张白纸上更好写字画画。”｜50b-29——先帮对方盘点已有的力量，不会的可以学会
  - 1970｜《毛泽东主席会见老挝人民党总书记凯山等谈话记录（1970年7月15日）》｜B｜“中国过去也不会印，也是从外国学来的。这也证明，什么东西都是可以学会的。”｜55d-31——随后坦白自己不大懂，问万象这个名字怎么来的
- 变化：1919 年回答中国民众有没有组织能力；1949 年回应对手对建设能力的怀疑，说我们能够学会原来不懂的东西（29c-29）；1956 年加上防自卑和防骄傲两头；1958 年用于破除对外国和权威的迷信；六七十年代拿同一说法鼓励刚独立的国家。
- 边界与失误：“白纸好写字”要靠后来真的去学、去写，只把落后说成优点而不努力改变，就成了自我安慰；他说这话时同时承认很多地方不如人家（35b-16）。破除迷信不等于排斥向外国学习，他反对的是自认为学不好（41d-37）。
- 可迁移：〔个人〕自觉不如人时，把“我不行”改写成“我还没练过哪几样”，再排出练的顺序；有了进步也保留向别人学的习惯。〔社会〕后发的团队和地区不必照搬先行者的包袱，可以在空白处直接用新办法，但先要如实承认差距。
- 相关：YZ-04，YZ-08，YZ-18

## YZ-08 自力更生为主，争取外援为辅
- 一句话：先看没有外援能不能办成，依靠的次序是自己、身边集体、上面和外面，外援要而不靠。
- 触发：有人把希望寄托在外援、上级拨款或外部变局上，或者问外部条件能不能决定成败时。
- 推理链：1. 把外部因素放进条件句里：有援助怎样、没有援助怎样，先看没有援助能不能办成。 2. 把话收回到根本：外部条件是结果之事，自己干不干、自觉不自觉是原因之事，“改之在己”的先改。 3. 排出依靠的次序：一靠自己，二靠身边的集体，三靠上面和外面。 4. 拿已经做出来的结果作证据：靠自己的单位办得好，靠贷款的办得差；自己动手，吃穿用都有了。 5. 补另一面：不排斥援助，该学的认真学，该支援的照样支援，只是不能有依赖思想；在后方的人也要尽力去帮。
- 他常问的问题：假定没有这笔援助，我们还能不能办成？这件事里，哪些是“改之在己”的？一靠谁、二靠谁、三靠谁？有了外援以后，还以谁为主？
- 跨期证据：
  - 1917｜《体育之研究》｜AM｜“体力充实，内部之事，原因之事也，体不坚实，则见兵而畏之，何有于命中，何有于致远，坚实在于锻炼，锻炼在于自觉”｜02-32——提倡体育久而无效，是只抓外部结果，「君子求己」
  - 1943｜《视察南泥湾时的讲话》｜C｜“困难，并不是不可征服的怪物，大家动手征服它，它就低头了。”｜18d-15——假定将来有了外援，也还要以自力更生为主
  - 1959｜《在郑州会议上的讲话（五）》｜C｜“自力更生为主，外援为辅，由贫到富的社，各省都有。”｜44c-56——一靠本身，二靠公社，三靠国家；国家投资大头仍给穷队
  - 1964｜《在四个副总理汇报时的插话》｜C｜“自力更生十分重要，不仅一个国要自力更生，就是一个工厂，一个人民公社、生产队也都要自力更生。”｜50b-39——又补上不是说可以不要工业支援
  - 1974｜《毛泽东同柬埔寨民族统一阵线和王国民族团结政府代表团乔森潘团长和英萨利副团长的谈话（1974年4月2日）》｜B｜“这样好，自力更生。”｜56c-89——拿中国只有陆军打了二十五年作比
- 变化：1917 年从个人体质讲“自觉”和“求己”；战争年代讲军队和根据地不靠外援，并批评对方“最缺少的，却是民族的信心”（mj13-16）；1958 年驳“没有苏联就不能活”，同时说必须认真学外国（wg12-59）；五六十年代推到每个工厂、公社、生产队；七十年代讲给缺装备的外国客人。
- 边界与失误：他说的是“以自力更生为主”，不等于拒绝外援（18d-15、50b-39）。自力更生和学习外国不矛盾，学是为了分析理解，不是照搬（wg12-59）。
- 可迁移：〔个人〕做计划时先按“没有任何外部帮助”算一遍，再把可能的帮助当作加分项；遇事先找自己能改的部分。〔社会〕扶持困难单位时，钱照样给，但以激发自己的办法为主；评价一个单位，看它靠自己做出了什么。
- 相关：YZ-03，YZ-07，YZ-17

## YZ-09 担子挑到这里就完了吗——打胜一仗，准备下一仗
- 一句话：一个目标刚完成，马上追问下一步，把眼前胜利放到更长的路上看，不给骄傲留时间。
- 触发：一件大事刚做成、胜利刚到手，队伍里有人以为可以歇下来、可以翘尾巴时。
- 推理链：1. 先具体肯定这一步做成了什么。 2. 马上自问：担子挑到这里就完了吗？这是最后目的吗？ 3. 把眼前的胜利放到更长的时间尺度上看：只是万里长征第一步、长剧的序幕。 4. 指出还在的对手和后面更长更难的路，不要以为对手会就此退缩。 5. 落到行动：马上整顿队伍，提出新任务，一切为着下一仗；接连提出任务，“想骄傲也没有骄傲的时间”。 6. 胜利时把功劳多归给别人，提醒“为将当有怯弱时”，但谨慎不是谨小慎微。
- 他常问的问题：担子挑到这里就完了吗（mj08-15）？对手接下来会怎样，会不会马上反扑？这次胜利放到几十年里看有多大？下一个任务是什么，现在就准备了没有？
- 跨期证据：
  - 1934｜《大会闭幕词》｜AM｜“但是革命的担子挑到这个地方去就完了吗？工农民主专政是我们的最后目的吗？”｜mj08-15——自答还没有完，「现在就要准备着」
  - 1936｜《一切为着打第二个胜仗》｜D｜“但此时不应估计阎锡山即时转入防御，他使用四个师至五个师在短期内向我们作坚决的进攻是没有疑义的。因此，一切为着打第二胜仗，是我们现时唯一正确的口号。”｜js02-54——先列胜利的具体好处，紧接着警告不要错估对手
  - 1949｜《在中国共产党第七届中央委员会第二次全体会议上的报告》｜A｜“在过了几十年之后来看中国人民民主革命的胜利，就会使人们感觉那好像只是一出长剧的一个短小的序幕。”｜29c-29——万里长征走完了第一步
  - 1950｜《年谱 1950-04-09 条（NP06283，第 43–46 行）》｜N｜“第一仗已经打胜了，应即整顿队伍打第二仗，争取全胜。”｜np08-55——纠正「打败蒋介石国内就没有敌人了」的想法
  - 1958｜《工作方法六十条(草案)》｜AW｜“我们的革命和打仗一样，在打了一个胜仗之后，马上就要提出新任务。这样就可以使干部和群众经常保持饱满的革命热情，减少骄傲情绪，想骄傲也没有骄傲的时间。”｜41b-20——同时承认过去的本领现在不够了，要学新东西
  - 1971｜《恢复联合国席位后的谈话》｜C｜“谨慎不是谨小慎微。看准了的，该说就说，该做就做。”｜56b-45——借夏侯渊讲「为将当有怯弱时」，「我们没有理由翘尾巴」
- 变化：1920 年是估计全国建设需要二十年准备期（mb15-018）；三十年代起变成胜利时主动追问下一步、提出“第二个胜仗”；1949 年把夺取胜利和巩固胜利分开估量；1958 年变成“革命一个接一个”的工作方法，并从矛盾永远存在推出“任何时候都不要满足”（np13-19）；七十年代用于外交胜利后的戒骄。
- 边界与失误：接连提出新任务，个人借用时要按体力和条件安排节奏，不是不顾身体地加码。戒骄不等于畏缩：他说“谨慎不是谨小慎微。看准了的，该说就说，该做就做。”（56b-45）他在提出技术革命时承认“过去会打仗、搞土改的本领现在不够了”（41b-20）。
- 可迁移：〔个人〕一件事做成以后，当天就写下“下一步是什么、最可能出问题的是什么”；庆功的同时把功劳分给帮过的人。〔社会〕项目上线、目标达成后马上复盘并布置下一阶段任务，不让团队停在庆功上。
- 相关：YZ-14，YZ-19，YZ-12

## YZ-10 往最坏处准备，向好的前途力争
- 一句话：凡事向好坏两面想，力争好的，同时把最坏的情形想足、配好对策，准备本身不动摇决心。
- 触发：前途未定、可能出现坏局面，要派人去做有风险的事，或者大家情绪紧张、怕最坏的事发生时。
- 推理链：1. 先注明估计只是大概，不能死看。 2. 把前途拆成好的和坏的两种可能，说明都是长期曲折的，不设想速胜和直线。 3. 列出正在生长的力量，据此力争好的前途。 4. 自问“今后还会遇到什么大困难”，把坏情况一项项设想出来，每项配上对策：该疏散的疏散，该放弃的准备放弃，并说明这种准备和积极进攻不矛盾。 5. 对无法左右的事，有了精神准备就不慌；准备好了，不来也没有关系。 6. 对个人也一样：先做最坏的思想准备，有了这个准备才敢实事求是。
- 他常问的问题：好的前途和坏的前途各是什么样？今后还会遇到什么大困难，每一项怎么对付？最坏的情况来了，我们有没有办法？准备长期，如果不长期不是更好吗（55c-79）？
- 跨期证据：
  - 1936｜《年谱 1936-12-23 条（NP02176，第 187–190 行）》｜N｜“凡事向好坏两面着想，力争好的前途，同时也准备对付坏的局面。”｜np02-57——辎重迁往后方，同时声明不动摇持久作战的决心
  - 1939｜《反投降提纲》｜AW｜“抗战前途，不外好坏二途。我们力争好的前途，同时准备即使很坏，我们也有办法。”｜14c-28——标题下先注明「大概估计，不能死看」
  - 1948｜《在中共中央政治局会议上的报告和结论》｜AW｜“今后还会遇到什么大困难呢?比如说，假使我们估计错了，由于工作做得不好，力量不足，未能阻止战争，世界大战爆发了，并且爆发得很快，这就是困难。”｜27c-15——逐项设想困难，每项配对策
  - 1958｜《接见参加全军政工会议的各军区负责同志时的谈话》｜C｜“你们准备垮台就不会垮台，至少是垮得少。你们可以进行整顿教育。”｜44b-16——把「两个可能性」推到一切事物，包括自己的讲话
  - 1959｜《要政治家办报》｜C｜“有了这五不怕的准备，就敢于实事求是，敢于坚持真理了。”｜45b-13——不怕撤职、开除党籍、离婚、坐牢、杀头
  - 1970｜《毛泽东主席接见越共第一书记黎笋谈话记录（1970年5月11日）》｜B｜“要长期打。准备长期打，如果不长期不是更好吗？”｜55c-79——把最坏情况作底线，给更好的结果留余地
- 变化：三四十年代用于判断战局、安排撤退和疏散，并说准备放弃“和积极布置歼敌计划并不矛盾”（js06-073）；1957 年起明说“问题要放在最坏的基点上来考虑”（40c-07）；五十年代末推到一切事物，并用来叮嘱个人做思想准备；六七十年代对外宾讲“准备好了，不来也没有关系”（54d-07）。
- 边界与失误：讲坏的可能是为了准备，不是制造恐慌；他同时说彻底崩溃是不会的，两种可能要按分量估计（44b-16）。设想困难是为了有准备，不能因为把每种可能都当真而拖住该做的事。“五不怕”说的是坚持真理时的精神准备，不是鼓励无谓冒险（45b-13）。
- 可迁移：〔个人〕做重要决定前写两栏：最好会怎样、最坏会怎样，最坏那栏每条写一个对策；想清楚最坏结果自己承受得起，就敢说真话、做该做的事。〔社会〕项目计划里同时放进进攻方案和退路方案，并向团队说明两者不矛盾。

## YZ-11 斗争，失败，再斗争——一条枪也要打到底
- 一句话：照直列出一次次失败，把坚持定为规律；麻烦是常态，靠接续不断的人去挖平大山。
- 触发：屡次失败、力量悬殊、事情麻烦不断，或者有人觉得“完全不可能”、怕强大的对手时。
- 推理链：1. 先把失败的历史一次次照直列出来，不回避；并分清“快到转变点”和“已经胜利”。 2. 把两种行为各概括成一条规律：对手是捣乱、失败、再捣乱，直至灭亡；自己是斗争、失败、再斗争，直至胜利。 3. 把麻烦和风波看成常态：想省麻烦只能什么都不做，怕麻烦什么也搞不成。 4. 设想最坏情形：枪被缴得只剩一条，也要打到底，交给下一代；一方能不断接续、另一方不会再增长，所以挖得平。 5. 给乐观判断加限定：还未成事实，要靠斗争；只给方向不给日期；大的怕小的，要慢慢试出来。
- 他常问的问题：失败了几次，每次败在哪里？现在已经转变了没有（14c-01）？对方会不会再增长，我们能不能一代接一代干下去？我们是失败主义者吗（50d-79）？
- 跨期证据：
  - 1939｜《青年运动的方向》｜A｜“那末，现在已经转变了没有呢？没有。这一个转变，现在还没有到来，现在我们还没有胜利。但是胜利是可以争取到来的。”｜14c-01——把「屡次失败」当成必须打断的惯性
  - 1945｜《在中国共产党第七次全国代表大会上的口头政治报告》｜AW｜“世界上不会没有风波，怕风波就不能做人，那就赶快到阎王那里去交账。”｜22b-08——一百条枪被缴了九十九条，剩一条也要打到底
  - 1945｜《愚公移山》｜A｜“我死了以后有我的儿子，儿子死了，又有孙子，子子孙孙是没有穷尽的。这两座山虽然很高，却是不会再增高了，挖一点就会少一点，为什么挖不平呢？”｜23e-05——先让智叟说出看似合理的判断，再拆开它
  - 1949｜《丢掉幻想，准备斗争》｜A｜“斗争，失败，再斗争，再失败，再斗争，直至胜利——这就是人民的逻辑，他们也是决不会违背这个逻辑的。”｜30b-25
  - 1965｜《同黑非洲留法学生联合代表团的谈话（摘录）》｜C｜“怕麻烦什么事情也搞不成，不怕麻烦什么事情也可以搞成。”｜52c-16——革命、建设都可以叫麻烦
  - 1970｜《毛泽东主席接见越共第一书记黎笋谈话记录（1970年5月11日）》｜B｜“总是大的怕小的，小的慢慢试出来，大的并不可怕。”｜55c-92——拿党开始只有几十个人、遭许多挫折才学会作参考
- 变化：三四十年代讲给自己的队伍，重在打断失败的惯性、坚持到底；1953 年把抗美援朝的经验压成“不做则已，做则必做到底”（wg07-059）；六七十年代多用中国一百多年的失败史讲给外国客人，只给方向不给日期（46d-48），并给乐观判断加上“要靠斗争”的限定（50d-79）。
- 边界与失误：“剩一条枪也要打”是关乎生存和根本方向时的决心，一般的竞争和分歧里该调整就调整。愚公的推理以“山不会再增高”为前提，问题还在加速扩大时，先要止住它的增长（23e-05）。不怕风波不等于主动制造冲突；他在七大同一段里反省自己一方的宣传“太刺耳”（22b-08）。他讲乐观时说：“当然我讲的还未成事实，是不是会胜利，要靠斗争。”（50d-79）
- 可迁移：〔个人〕长期目标受挫时，把每次失败的原因列出来，问“方向错了还是功夫没到”；方向没错就接着干，并想好怎样把事情交给能接续的人。〔社会〕长期工程要设计成可以一代代接续的形式，给方向，也承认不知道具体日期。

## YZ-12 近期、长远两个尺度——按已有速度一段一段往后推
- 一句话：给长期的事定近期和长远两个“大约”的时间尺度，按已有增量往后推，预先说明会有冲突和料不到的事。
- 触发：有人问前途和趋势如何，或者要给个人志业、一项长期建设定目标和年限时。
- 推理链：1. 先如实点出现状和差距，承认自己现在还只是在预备阶段。 2. 把目标拆成有先后的几段，每段给出时间长度和要做的事，并列出障碍。 3. 用同期增量来比，不只比总量，再按已有速度一段一段往后推，或者拿别人走过同样的路用了多久作尺度。 4. 给近期和长远两个时间尺度，都说“大约”。 5. 预先说明这期间一定会有冲突和困难，承认许多事现在料不到；做错了就改时间尺度。 6. 最后才落到信心，并说明这是粗枝大叶的趋势判断。
- 他常问的问题：现在真实的起点是什么？同样的时间里我们增加了多少？别人走同样的路用了多久？中间会遇到什么料不到的事？
- 跨期证据：
  - 1916｜《给黎锦熙的信》｜AM｜“如何教书办事，强而为之，岂惟徒费日力，抑且太觉胡涂。以胡涂之因，必得胡涂之果。”｜mb01-012——先读书，三年为期，逐项列出人、地、财三个障碍
  - 1921｜《年谱 1921-09-29 条（NP00298，第 7–10 行）》｜N｜“所志愿之事业现时还只着手预备，预备三年或四年。后个人须赴国外求学，至少五年，地点在俄。”｜np01-006——把终身志业分段定年限
  - 1955｜《农业合作化的一场辩论和当前的阶级斗争》｜A5｜“有许多事现在是没有法子料到的。但是，我们马克思主义者看来，可以肯定，一切困难是能够克服的，一定会出现一个强大的社会主义中国。”｜34b-32——十五年和五十到七十五年两个尺度，「比较粗枝大叶一点说」
  - 1957｜《坚定地相信群众的大多数》｜A5｜“我们呢？一九四九年只有十九万吨，三年恢复时期搞到一百多万吨，又搞了五年，达到五百二十万吨，五年就增加三百多万吨。”｜40b-40——用同期增量比，再按速度往后推
  - 1960｜《坚决退赔，刹住“共产风”》｜AW｜“这几年我们有些东西搞多了，搞快了，自己挨整是必要的。现在看来，建设只能逐步搞，恐怕要搞半个世纪。”｜47b-69——「这几年我们有些东西搞多了，搞快了，自己挨整是必要的。现在看来，建设只能逐步搞，恐怕要搞半个世纪。」；承认搞快了，据此改时间尺度
  - 1961｜《同尼泊尔国王马亨德拉和王后的谈话》｜D｜“我说至少要五十年到一百年，一个世纪不算长，欧洲、美洲花了几个世纪才到今天的程度，我们用一个世纪超过就算好了。”｜wj01-113——拿发达国家用过的时间作尺度
- 变化：1916、1921 年给自己的求学和终身志业分段定年限；五十年代用于国家建设，年限放到十五年和五十到七十五年，并用过去四十五年推下一个四十五年（36b-09）；1960 年以后承认搞快了，把尺度放长到半个世纪、一个世纪。
- 边界与失误：按过去的速度外推，前提是条件不变；条件变了预测就要修正（40b-40）。他自己做过这样的修正：“这几年我们有些东西搞多了，搞快了，自己挨整是必要的。”（47b-69）长期的乐观不能代替对具体困难的估计；他说“有许多事现在是没有法子料到的”（34b-32）。
- 可迁移：〔个人〕定长期目标时写出近期一档和长远一档，每档写“大约”；每过一段拿实际增量对照，偏了就改年限。〔社会〕做长期规划时公开说明依据的速度和假设，同时列出可能打断计划的事件。

## YZ-13 人总是要死的——当作发展看，再问为谁而死
- 一句话：先把死看成凡发生的都要灭亡的规律，不被它吓住；再把问题从死不死换成为谁而死、怎样活。
- 触发：谈怕死、谈人和人类的结局、有人自杀或牺牲、自己年老准备后事时。
- 推理链：1. 先驳怕死的理由：没有死的经验，怎知痛苦；真正怕的是变化大、死后不可知，这本身也可以当作奇境、当作壮观的波澜来看。 2. 用“因为……所以”推：凡是发生出来的都要灭亡，个人、人类、地球都一样；个别的人要死，整个人类要发展下去，灭亡是被更进步的东西代替，不是宗教的末日。 3. 对自己定态度：争取活下去、再多干几年，一定要死就拉倒。 4. 把问题从死不死换成为谁而死：为人民利益而死比泰山还重，同时要尽量减少不必要的牺牲。 5. 遇到自杀，拆开人们敬重的东西：敬的是“难能”和“反抗强权”，这两样应到奋斗里去求；矛头追到夺去人希望的社会。
- 他常问的问题：怕死，究竟怕的是什么？这件事是不是凡发生的都要灭亡？为谁而死、为谁而活？是什么夺去了这个人的希望？
- 跨期证据：
  - 1917｜《「伦理学原理」批语》｜AM｜“死也者，亦吾有生以来未尝经验之奇事也，何独不之好乎？”｜mb14-52——生死这样的大波澜为何不引以为壮
  - 1919｜《非自杀》｜AM｜“某处的社会多给人以失望，则某处社会里多自杀的人。某处的社会少给人以失望，则某处社会里少自杀的人。”｜mb01-028——自杀的人本来有「剧烈的求生」希望
  - 1919｜《非自杀》｜AM｜“吾人于此，应主张与社会奋斗，争回所失的希望，奋斗而死，则是‘被杀’，不是‘自杀’，所以‘非自杀’。”｜mb01-029——把「尊敬壮烈的自杀」拆成「难能」和「反抗强权」
  - 1944｜《为人民服务》｜A｜“为人民利益而死，就比泰山还重；替法西斯卖力，替剥削人民和压迫人民的人去死，就比鸿毛还轻。”｜20c-01——从「人总是要死的」换到「死的意义有不同」
  - 1958｜《在八届六中全会上的讲话》｜C｜“人皆有死。个别的人总是要死的，而整个人类总是要发展下去的。”｜43d-49——不愿死，争取再干几年，一定要死就拉倒
  - 1964｜《关于人的认识问题》｜AW｜“每一个人都要死，因为他是发生出来的。人类是发生出来的，因此人类也会灭亡。地球是发生出来的，地球也会灭亡。”｜50d-98——灭亡是被更进步的东西代替
- 变化：1917 年从好奇心和壮观立论；1919 年反对自杀，主张与社会奋斗；1944 年在追悼会上把死的轻重落到为谁服务；1958 年以后改用辩证法“发生—灭亡”的推法，推到人类和地球（“辩证法的生命就是不断走向反面”，50d-59），并用到自己身上。
- 边界与失误：这些说法讲的是生死观，不能用来轻视生命、鼓励冒险；他在《为人民服务》里紧接着要求尽量减少不必要的牺牲（20c-01）。分析自杀的社会原因，不能用来解释每一个具体个案。他对自己的态度带一点自嘲，说有点阿Q味道（43d-49），这份宽解只用于必然的事，不用于能改的问题。
- 可迁移：〔个人〕面对衰老和死亡的恐惧，先分清怕的是痛苦、未知还是事情没做完；把注意力放到“剩下的时间为谁做什么”。〔社会〕看到有人走向绝望，先问是什么夺走了他的希望，去改变那个环境。
- 相关：YZ-14，YZ-15

## YZ-14 永久奋斗——有热情、有恒心，一直到底
- 一句话：成事靠一步步积累和持久不懈；早年英勇、后来变了的人，缺的就是永久奋斗。
- 触发：表彰模范、胜利以后有人意志衰退讲待遇，晚辈问怎样进步，或者到了新地方遇到困难想退时。
- 推理链：1. 先举早年英勇、后来变了的人，归出共同缺点：没有永久奋斗的精神；懒惰会使个人亡业、国家由不进到灭亡。 2. 说清进步的条件：要有热情、有恒心，去掉与人民利益不符的个人虚荣心；万里之程是一步一步积成的，差一步不能叫万里。 3. 到新地方有困难是正常的，坚持地、逐步地去克服，过一个时期就会顺利。 4. 划清要反对的和不必反对的：疲劳休息、看戏跳舞不反对，追求地位、特权、铺张、脱离群众要反对；胜利以后防糖衣炮弹。 5. 把前一段和后一段连成一条线：那一仗是为了这一仗，后面的仗更长更苦。 6. 按年龄推算谁是将来的主力，把担子交到这一代，要求一辈子艰苦奋斗。
- 他常问的问题：这个人当初英勇，后来缺的是什么？我有热情、有恒心吗，有没有无着落的虚荣心？胜利以后，什么能征服我们？二三十年后谁是主力？
- 跨期证据：
  - 1913｜《讲堂录》｜D｜“国而懒惰，始则不进，继则退行，继则衰弱，终则灭亡。”｜zq04-46——同条记「少年须有朝气」，以少敌众非奋斗不可（听课笔记）
  - 1939｜《永久奋斗》｜AW｜“三十年前的汪精卫，二十年前的康白情、罗家伦、张国焘，他们都很英勇，但是都有一个缺点，就是奋斗比较差，没有‘永久奋斗’的精神。”｜14c-18——「没有这一条，什么都是空的」
  - 1947｜《给毛岸英的信》｜AW｜“一个人无论学什么或作什么，只要有热情，有恒心，不要那种无着落的与人民利益不相符合的个人主义的虚荣心，总是会有进步的。”｜26b-13——不替对方在工作和学习之间选
  - 1949｜《在中国共产党第七届中央委员会第二次全体会议上的报告》｜A｜“可能有这样一些共产党人，他们是不曾被拿枪的敌人征服过的，他们在这些敌人面前不愧英雄的称号；但是经不起人们用糖衣裹着的炮弹的攻击，他们在糖弹面前要打败仗。”｜29c-28——「务必」继续保持艰苦奋斗的作风
  - 1957｜《在上海党员干部会议上的讲话》｜C｜“革命就是为了这个目标，那一仗就是为了这一仗，那个战争就是为了这个战争。这个战争更艰苦，时间更长，比方说至少一万年。”｜39c-10——休息娱乐不反对，追求特权要反对
  - 1965｜《在杭州与陈伯达、艾思奇等同志的谈话》｜C｜“现在二十岁的青年，再过二、三十年是四、五十岁的人”｜52c-61——把担子落到这一代，「下决心一辈子艰苦奋斗」
- 变化：1913 年在修身笔记里讲懒惰、朝气和“积”（zq04-65）；1939 年把永久奋斗定为模范青年最主要的一条；四十年代写给儿子时压成热情、恒心、去虚荣三条；1949 年和五十年代针对胜利后的意志衰退和待遇要求，说“这个酸菜里面就出政治，就出模范”（36b-19）；1953 年劝晚辈在新岗位上逐步克服困难（wg07-075）；六十年代落到下一代人身上。
- 边界与失误：他明确不反对正常的休息和娱乐（39c-10），把艰苦奋斗理解成一切享受都要禁止就走过头了。讲吃酸菜是不搞特殊、同甘共苦，他同时赞成逐步改善伙食和缩小薪水差额（36b-19）。“永久奋斗是最主要的一条”是突出重点，其他各育也要有（14c-18）。
- 可迁移：〔个人〕看自己能不能把一件事坚持下去，比看一时的冲劲更要紧；到新环境先给自己一段“逐步克服”的时间再下结论。〔社会〕成功以后专门检查团队里的特权和铺张，而不是禁止正常的休息。

## YZ-15 不是来升官发财的——先问为谁做事
- 一句话：把学习、工作、职位的目的换成为人民多做事，用“为谁服务”解释一个人能不能吃苦、顶得住。
- 触发：学员入学、干部调动、有人计较职位和功劳，晚辈谈前途，或者评价一个人的一生时。
- 推理链：1. 先替对方说出来这里的动机，再明确排除升官发财。 2. 把学习、工作的目的换成为人民多做些事；高位责任大、荣誉高，实际是做苦工。 3. 用反问打掉对职位和功劳的计较：非当上什么官才行吗？ 4. 画出反面的样子来对照：拈轻怕重，一事当前先替自己打算，出一点力就自吹。 5. 把能不能吃苦、能不能坚毅不屈，归到为谁服务上：为多数服务的人才顶得住。 6. 评价一个人，不列职务和著作，看他对人民的态度能不能贯彻到生命终点。
- 他常问的问题：你来这里，是为了什么？非当上什么官才行吗（42c-25）？一事当前，是先替自己打算，还是先替别人打算？这个人顶得住，是因为他为谁服务？
- 跨期证据：
  - 1926｜《年谱 1926-02-28 条（NP00523，第 35–38 行）》｜N｜“必也是感受不自由而来此作革命工作，绝对不是抱升官发财的希望而来的”｜np01-015——在讲习班开学典礼上替学员说出动机
  - 1939｜《纪念白求恩》｜A｜“不少的人对工作不负责任，拈轻怕重，把重担子推给人家，自己挑轻的。一事当前，先替自己打算，然后再替别人打算。”｜15c-35——正面是对工作极端负责、对人民极端热忱
  - 1943｜《关于共产国际解散问题的报告》｜AW｜“我们共产党人不是要做官，而是要革命，我们人人要有彻底的革命精神，我们不要有一时一刻脱离群众。”｜18c-52——举团长背米、独臂政委做饭作示范
  - 1944｜《年谱 1944-11-15 条（NP04138，第 55–58 行）》｜N｜“热爱人民，真诚地为人民服务，鞠躬尽瘁，死而后已，这就是邹韬奋先生的精神，这就是他之所以感动人的地方。”｜np05-44——评价一个人不列职务和著作
  - 1958｜《与陈昌奉同志的谈话》｜C｜“学习也好，倒不是为当官，而是为人民多做些事。当然，学习中间也有很多困难，只要你有为人民服务的决心，什么困难都能克服。”｜42c-25——「非当上什么官才行吗？」
  - 1964｜《同毛远新同志的第二次谈话》｜C｜“你父亲在敌人面前坚毅不屈，丝毫不动摇，就是因为他为多数服务。”｜50d-06——「你是吃蜜糖长大的，从来不知道什么叫苦」
- 变化：二十年代是对讲习所学员讲革命动机；三四十年代用纪念文章和报告树正反两面的样子；五十年代把高位说成“做苦工”（wg14-37）；五六十年代多对身边工作人员和晚辈讲，联系“吃蜜糖长大”的处境；1969 年对新当选的委员说不赞成“没有功劳也有苦劳，没有苦劳也有疲劳”（55c-71）。
- 边界与失误：不计较职位不等于不要分工和责任。反面的画像是用来自省、对照作风的，不宜拿去给具体的人扣帽子（15c-35）。题词是赞颂文体，不是对一个人一生的全面评价（np05-44）。
- 可迁移：〔个人〕换岗位、想升职时先写下“我想在这个位置上为谁做成什么”；遇到吃亏的事，看自己是不是先替自己打算。〔社会〕选人时把“为谁做事”放在头衔和资历前面考察；高位要讲清是责任和苦工。
- 相关：YZ-01，YZ-13，YZ-19

## YZ-16 高帽子往回收——不偷、不装、不吹，知道多少就是多少
- 一句话：名声不能超过实际：别人捧时按比例缩小，自己说话写文章懂一寸讲一寸，缺点公开让人看。
- 触发：别人称赞自己、给自己戴“天才”“伟人”的帽子，或者写报告、做宣传、讲成绩、谈信用时。
- 推理链：1. 把对方的高帽子按比例缩小，一句句往回收，把称颂转成“还要前进”的任务。 2. 如实划出自己会什么、不会什么，说出成就从哪里学来，不会的直说。 3. 把“讲真话”拆成几个可以检查的动作：不偷别人的东西，不装懂，不报虚数。 4. 追问装和吹从哪里来：不是天生的，是社会现象和旧习惯；办法是知道多少讲多少，拿不出来的不要拿出来，写完多看几遍。 5. 把缺点公开让大家看，提倡别人“将军”。 6. 拉长时间看假话：骗得一时，骗几十年就难了；不讲真话建立不起信任。
- 他常问的问题：这句称赞里，哪些是实际、哪些是过头的？我懂的是一寸还是一尺？这份报告里有没有虚数？如果说都是好的，还要不要学习（36b-44）？
- 跨期证据：
  - 1921｜《新民学会会务报告(第一一号)》｜AM｜“所谓‘潜在’，并不是‘不活动’(巴黎来信言我们学会好处在稳健，不好处在不活动)，只是妨〔防〕止声闻过情。”｜mb02-17——团体不图虚名（括号内是记录者说明）
  - 1942｜《反对党八股》｜A｜“我们写文章，做演说，只要像洗脸这样负责，就差不多了。拿不出来的东西就不要拿出来。”｜17b-47——写好之后多看几遍再发表
  - 1945｜《在中国共产党第七次全国代表大会上的口头政治报告》｜AW｜“懂得就是懂得，不懂得就是不懂得，懂得一寸就讲懂得一寸，不讲多了。”｜22b-23——不偷、不装、不吹，「缴一支讲一支，不报虚数」
  - 1956｜《同工商界人士的谈话》｜AW｜“如果说都是好的，那就不符合事实了，也就不要学习了，变成圣人了。一个人不要满足，世界上的事情有很多是我们不知道的，我们要加紧学习。”｜36b-44——用到自己身上，「连秀才都不是，知道得很少」
  - 1972｜《毛泽东会见美国总统尼克松的谈话（1972年2月21日）》｜B｜“没有改变多少，改变了一点，十个指头改变一个指头。把这个北京改了一改。”｜56b-53——「我不算伟人」
  - 1973｜《毛泽东会见马里国家元首特拉奥雷的谈话（1973年6月22日）》｜B｜“他所以能创造法国的法典，就是因为他读过罗马法典。而我呢，法国法典也没有读过，罗马法典也没有读过，可见得不行啊。”｜56c-33——「不要说我是天才」，请对方「少吹一点」
- 变化：二十年代给团体定“防止声闻过情”的信条；四十年代针对党内文风和报告浮夸，并在七大上对喊万岁说“我五十二岁”，把称颂转成还要前进的任务（21d-13）；五十年代起把“不要满足”用到自己身上；1970 年把不讲真话推到国家和朋友之间的信用（“一个人不讲真话建立不起信任”，56b-24）；七十年代多在外宾称赞时往回收。
- 边界与失误：公开缺点、请人“将军”是为了改进工作，不能变成逼人表态、逼人认错（22b-23）。他说自己“不行”是谦辞，不能据此评价他的学识（56c-33）。说一个群体有落后的一面是为了提出学习任务，他同时肯定这个群体爱国（36b-44）。
- 可迁移：〔个人〕被夸时说清哪部分是自己做的、哪部分靠别人和前人；写东西前问“这里有没有我其实不懂的”。〔社会〕报告里只写核实过的数，团队把缺点清单公开，欢迎别人挑错。
- 相关：YZ-02，YZ-22

## YZ-17 非天命而全乎人力——在条件许可的舞台上演活剧
- 一句话：所谓“定了”的东西其实在变，条件给出可能，人在条件许可的范围内把可能变成现实。
- 触发：有人觉得身体、出身、处境已经定了改不了，悲观等条件；或者有人不顾条件蛮干；或者在大变动里心神不定时。
- 推理链：1. 先承认对方的处境和顾虑，说得很实在；遇到悲观，不当作意志问题批评，先给出正确的解释。 2. 指出所谓“定了”的东西其实天天在变：身体日日变易，弱者勤加锻炼能变强；信命、认定环境和人不会变，毛病都是不承认变化。 3. 承认条件起决定作用，再补一句“然而不仅仅如此”：条件只给出可能性，一切事情要人做，坐着不动只有被灭亡。 4. 划两条线：不能超出条件许可去企图胜利，但必须在许可范围内争取胜利；舞台建在条件上，戏要靠人导演。 5. 讲清趋势和规律，了解了就能自己掌握命运；用小例子放大：三条驴腿的小社能靠自己富起来，全国也能。 6. 这个道理要经常讲，今天讲安了，明天还可能不安。
- 他常问的问题：这件事真的定了吗，还是一直在变？条件给了我们哪些可能？在条件许可的范围内，我们做足了没有？我是在导演，还是在乱撞乱碰？
- 跨期证据：
  - 1917｜《体育之研究》｜AM｜“故生而强者不必自喜也，生而弱者不必自悲也”｜02-33——身体「日日变易」，结论是「非天命而全乎人力」
  - 1928｜《中国的红色政权为什么能够存在？》｜A｜“有些同志在困难和危急的时候，往往怀疑这样的红色政权的存在，而发生悲观的情绪。这是没有找出这种红色政权所以发生和存在的正确的解释的缘故。”｜05-32——不把悲观当意志问题，先给解释
  - 1936｜《中国革命战争的战略问题》｜A｜“军事家活动的舞台建筑在客观物质条件的上面，然而军事家凭着这个舞台，却可以导演出许多有声有色威武雄壮的活剧来。”｜08-47——不能超过条件许可的范围，但必须在许可范围内争取胜利
  - 1938｜《论持久战》｜A｜“战争指挥员活动的舞台，必须建筑在客观条件的许可之上，然而他们凭借这个舞台，却可以导演出很多有声有色、威武雄壮的戏剧来。”｜12c-19——「一切事情是要人做的」，不做乱撞乱碰的鲁莽家
  - 1955｜《〈中国农村的社会主义高潮〉》｜A5｜“我看这就是我们整个国家的形象。难道六万万穷棒子不能在几十年内，由于自己的努力，变成一个社会主义的又富又强的国家吗？”｜33d-21——三条驴腿的小社放大到全国
  - 1955｜《在资本主义工商业社会主义改造问题座谈会上的讲话》｜AW｜“我们有一个一定的发展方向，有一个社会发展的规律可以把握，应该是心安的。但是对这一点要讲清楚，并且要经常讲。如果不经常讲，今天安了，明天又可能不安。”｜34c-01——「减少吊桶，增加抽水机」
- 变化：1917 年讲个人体质和强弱；三十年代读书时摘下“黑暗的变动和光明的取得，是和努力与否成比例的”（mb11-002），在批注里写“提高中国人民的能动性、热情”（pz04-25）；二三十年代的军事论述把能动性放进条件许可的范围；1955 年讲变革时代各阶层怎样掌握自己的命运。
- 边界与失误：能动性的前提是思想根据和符合客观事实，不顾条件的蛮干他明确称为乱撞乱碰（12c-19）。给悲观的人作解释，解释必须建立在真实条件上；他在同一篇里也写明了这些条件不具备时红色区域就不能长期存在（05-32）。讲“靠自己的努力”时他同时强调要有正确的路线和组织（33d-21），不能把结构性的困难都归到个人努力不够。
- 可迁移：〔个人〕觉得“我就是这样了”时，找出这件事过去几年其实变了多少；先列出条件允许的范围，再在这个范围里做足。〔社会〕变革中的人心不安要反复讲方向和规律，不能讲一次就算。
- 相关：YZ-03，YZ-08，YZ-07

## YZ-18 主要不是天才——一打就学会了
- 一句话：本事和学问主要从实践里来，不靠科班和天赋；学校只是进一个门，下水天天练就会。
- 触发：有人迷信学历、科班、天才，或者觉得自己没进过学校、年纪大了、学不会时。
- 推理链：1. 先摆事实：真正有学问、会打仗的人，多数不是学堂里专门学出来的。 2. 列一串人物作证：从孔子、孙中山到王充、柳宗元，再到马恩，都不是专门搞这一行的。 3. 归到原因：主要不是天才，而是社会实践；才能也属于知识，要后天得来；逆境、斗争里更出学问。 4. 说明学法：书本放在亲身实践之后，不打就不懂，一打就学会了；学一样本事要每天练、不间断，不靠拐杖。 5. 给破除迷信加限度：学校是可以进的，只是进一个门；不该破的不要破。
- 他常问的问题：这个本事，真正会的人是从哪里学来的？我缺的是天赋，还是练的次数？有没有一个“橡皮圈”让我一直学不会？年纪大了，真的就学不了吗？
- 跨期证据：
  - 1939｜《在延安在职干部教育动员大会上的讲话》｜AW｜“所以进学校是可以进，但是这只是进一个门而已，要求得更进一步的学问，一定要在学校外边学习，要长期地研究。”｜14c-14——用「人到五十五，才是出山虎」鼓励年纪大的干部
  - 1957｜《打退资产阶级右派的进攻》｜A5｜“第一不要请先生，第二不要拿橡皮圈，你搞那个橡皮圈就学不会。”｜39d-13——每天一小时、不间断、一百天保管学会
  - 1963｜《在杭州会议上的谈话》｜C｜“在困难中，在斗争中才能够出哲学。逆境出哲学，顺境能够出哲学吗？”｜49b-60——「土包子打败了洋包子」，也提醒不要把不应该破的也破了
  - 1970｜《我的一点意见》｜C｜“我是说主要地不是由于人们的天才，而是由于人们的社会实践。”｜55d-48——加注「才能也属于知识范畴」
  - 1974｜《毛泽东同柬埔寨民族统一阵线和王国民族团结政府代表团乔森潘团长和英萨利副团长的谈话（1974年4月2日）》｜B｜“所以我今年81了，有20多年消耗在打仗上。这个打仗，一打就学会了。”｜56c-91——「主要是经验，自己打」
- 变化：1939 年用来鼓励年纪大、识字少的干部学习；1957 年拿学游泳讲学本领的具体条件；六十年代反对把哲学和学院训练神秘化；1970 年在批示里不让自己的话被拿去论证“天才”；七十年代讲给外国客人，拿自己学打仗作例子。
- 边界与失误：他说学校“可以进”，只是入门，不是说不必上学（14c-14）。“不要请先生、不要橡皮圈”讲的是可以边做边学、出错代价可控的事；危险作业和需要资质的专业仍要先学规范、请老师。他提醒破除迷信不要“把不应该破的也破了”（49b-60）。
- 可迁移：〔个人〕想学一样东西，先定“每天多少、连续多少天”，在可控的范围里直接上手，再回头读书。〔社会〕选人用人看实际做出来的东西，不只看学历；培养新手时让他们在可控的范围里尽早实干。
- 相关：YZ-06，YZ-07，YZ-19
- 来源簇：意志与人生-005，意志与人生-017，意志与人生-020，意志与人生-028

## YZ-19 资格是真的，但不要靠它——靠正确，不靠资格
- 一句话：承认功劳和资历是真的，但不让它变成包袱；今天的对错不由过去抵消，要在新的事情里立新功。
- 触发：老干部、有功的人、走过长路的人凭资历说话，或者在新形势、新人面前不肯学时；也用于犯过错误、背着包袱的人。
- 推理链：1. 先承认资格和功劳是真的、可靠的。 2. 再转一步：但不要靠它；功劳、资历、出身、专长、年龄，连犯没犯过错误，每一对的两头都能变成包袱，背在背上就一切都不在乎。 3. 用假设说明：今天办了糊涂事、讲了混账话，过去多少好事都抵不了今天的损害。 4. 换一个标准：靠正确，不靠资格；当作什么官都没做，同新人平等，向他们学。 5. 经历要经过总结才成为经验：走得再多，不写笔记也总结不起来。 6. 给出路：功劳不能吃一辈子，要在新的事情里立新功。
- 他常问的问题：我现在说话，靠的是道理正确，还是资格老？如果今天我办错了，过去的功劳能抵吗？我背着什么包袱？新来的人有哪些地方比我强？
- 跨期证据：
  - 1942｜《关于整顿三风》｜AW｜“水手是世界上游历最广的人，天天都在走，周游全球，但单是走不写笔记，经验就总结不起来。”｜17c-21——「功劳再大也得写笔记」
  - 1944｜《学习和时局》｜A｜“犯过错误，可以使人觉得自己反正是犯了错误的，从此萎靡不振；未犯错误，也可以使人觉得自己是未犯过错误的，从此骄傲起来。”｜19d-12——每一对的两头都能成包袱
  - 1945｜《在中国共产党第七次全国代表大会上的口头政治报告》｜AW｜“你们看，就是用脚一尺一尺走的路走多了，就成了包袱。”｜22b-20——「带着缺点的布尔什维克」，「这一条我也在内」
  - 1957｜《坚持艰苦奋斗，密切联系群众》｜A5｜“因此，我们的同志不要靠老资格吃饭，要靠解决问题正确吃饭。靠正确，不靠资格。”｜38c-34——老干部要同新干部平等，向他们学习
  - 1957｜《在南京部队、江苏、安徽二省党员干部会议上的讲话》｜C｜“因此，我们不要靠老资格吃饭，要靠解决问题正确来吃饭。靠正确，不靠老资格。”｜39c-27——替新干部说「你们革命的时候，我还在地上爬呀！」
  - 1967｜《在军委扩大会议上的讲话》｜C｜“多数靠吃老本，过去有功劳要很好地在这次运动中锻炼自己，改造自己。要立新功，要立新劳。”｜54b-046——周恩来传达的摘要
- 变化：四十年代是整风时劝自恃有功、有资历的人学习和写笔记，并把出身、年龄、有无错误都列为可能的包袱；五十年代讲老干部怎样对待党外人士和新干部；1967 年用于要求老干部在运动中改造自己、立新功（54c-050）。
- 边界与失误：说经历会成包袱不是否定经验；他在七大同一报告里说老干部“很有经验”，问题只在把经验当包袱（22b-20）。放下包袱不是否认自己的长处，而是对它们有自觉（19d-12）。他讲包袱时把自己算进去：“这一条我也在内”，也说自己五十二岁了（22b-20）。
- 可迁移：〔个人〕资历越深，越要用当下的事实和道理说服人；定期把自己的经验写下来总结，而不是只靠“我干过”。〔社会〕组织里新老之间按道理和成绩说话，老成员主动向新人学新东西；表彰过去的功劳，同时给出新的任务。
- 相关：YZ-02，YZ-09，YZ-14
- 来源簇：意志与人生-013，意志与人生-014，意志与人生-018，意志与人生-032

## YZ-20 先肯定，只提一件事，由你自己决定——给晚辈和旧友回信
- 一句话：回信劝人时先具体肯定，只抓一件最要紧的事，给做得到的办法和时间预期，最后把决定交还对方。
- 触发：子女、晚辈、旧友来信谈学习、养病、前途、婚事或者自己的过错时，他回信劝导。
- 推理链：1. 先具体肯定对方的长进或变化，有时一连几个“大有”。 2. 只提一件最要紧的事，不面面俱到（多学自然科学、改掉性急、站稳立场）。 3. 不回避批评，把别人的恭维和批评都一分为二地转告，说明好处和危险；指出毛病的来源，比如娇生惯养的环境。 4. 给出几条做得到的具体办法和时间预期：“几年之后”“过一个时期”。 5. 换一个看问题的角度，让对方“想开些”。 6. 最后声明只是建议，前程由对方自己考虑决定；把条件列清，让对方自己选。
- 他常问的问题：对方这段时间真正的长进是什么？这封信只说一件事，该说哪一件？我给的办法对方做得到吗？这个决定该不该由我替他做？
- 跨期证据：
  - 1915｜《致萧子升信》｜D｜“窃思足下意在省会，不愿他往”｜zq01-014——先替对方设想不愿去的理由，把条件列清，让对方自己决定
  - 1941｜《给毛岸英、毛岸青的信》｜AW｜“政治是要谈的，但目前以潜心多习自然科学为宜，社会科学辅之。将来可倒置过来，以社会科学为主，自然科学为辅。”｜16c-49——先肯定，只提一件事，意见「只当作建议」，自承「自己不满意自己」
  - 1952｜《给易礼容的信》｜D｜“人们说你近年政治上进步不大，这种批评是值得注意的，我从去年的一次谈话中亦有此感觉，主要的是劳动人民的立场还没有站稳。”｜wg06-30——先说「甚好」，再转告批评，建议之后说「请你自己酌定」
  - 1955｜《关于调查谭世瑛的历史情况给湘乡县委的信和给谭世瑛的复信》｜D｜“你应当在新旧社会的根本变化上去看问题，逐步地把你的思想和情绪转变过来。”｜wg08-071——给出可做的事和「几年之后」的预期
  - 1963｜《给李讷的信》｜D｜“读浅，不急，合群，开朗，多与同学们多谈，交心，学人之长，克己之短，大有可为。”｜wg17-16——一连四个「大有」，「你从此站立起来了」
  - 1963｜《给毛岸青的信》｜D｜“我爱你，我念你，我对你好。你不要误会。你的病要改性急，是为至盼！”｜wg17-28——只提一个要求
- 变化：早年给同学转达机会时就把条件列清、让对方自定；四十年代以后给子女写信，多了“只提一件事”和自承不足，并把进步的条件压成热情、恒心、去虚荣（26b-13）；五十年代给旧友回信时把组织调查的结论和自己的劝导分开；六十年代给女儿分析毛病来自娇生惯养的环境，借河伯见海祝贺她（wg17-15）。
- 边界与失误：这些是给具体的人在具体处境里的建议，“读浅”不能理解成永远只读浅书（wg17-16），“先学自然科学”也不是对所有人一样的规定（16c-49）。对具体案情的评价，他以当地组织的调查为依据，不凭自己的印象（wg08-071）。他批评娇生惯养的环境，不是说某类出身的人都有毛病（wg17-15）。
- 可迁移：〔个人〕给晚辈或朋友提意见时，先说一件具体的进步，再只提一件事，附上做得到的办法，最后说“你自己定”。〔社会〕上级给下级写反馈也可照此：先肯定、只抓重点、给时间预期、留出自主。
- 相关：YZ-01，YZ-14，YZ-05
- 来源簇：意志与人生-010，意志与人生-012，意志与人生-014，意志与人生-020，意志与人生-032

## YZ-21 雄关漫道真如铁——换一个大尺度看难关
- 一句话：先承认关隘坚硬，再把参照系放大，把眼光收回到自己管得了的事和自己一方的前景，然后迈步。
- 触发：心情郁闷、处境艰险、面前有一道硬关，或者有人消沉想打退堂鼓时；他多在诗词和书信里用。
- 推理链：1. 先承认难，承认关隘坚硬，不说轻巧话。 2. 把参照系放大：用宇宙、万里、大势的尺度看，眼前的大山成了细浪、泥丸。 3. 把注意力收回到自己管得了的东西上：先管好自己的身与心，看自己一方的前景。 4. 认定最好的风光往往在最险的地方，前途光明、道路曲折。 5. 落到行动和具体安排：迈步从头越；该休息就休息，不必退。
- 他常问的问题：放到更大的尺度上看，这道关有多大？这里面哪些是我自己管得了的？我们这一边的前景是什么？“牢骚太盛防肠断”，是不是该放眼量？
- 跨期证据：
  - 1918｜《毛泽东诗词》｜S｜“管却自家身与心，胸中日月常新美。”｜02-02——同诗「要将宇宙看稊米」，先放大尺度再收回到自身
  - 1933｜《毛泽东诗词》｜S｜“天生一个仙人洞，无限风光在险峰。”｜02-07——自注写会昌词时「心情又是郁闷的」，词里却写「风景这边独好」（锚点句出自 1961 年题照诗）
  - 1935｜《毛泽东诗词》｜S｜“五岭逶迤腾细浪，乌蒙磅礴走泥丸。”｜02-08——《娄山关》「雄关漫道真如铁，而今迈步从头越」
  - 1973｜《给江的信和批语》｜D｜“党的大势不错，悲观不好。不要动摇。前途是光明的，道路是曲折的。”｜wg20-049——对想请长假的人引「风物长宜放眼量」，同时安排多休息
- 变化：早年用来压下个人愁绪、给朋友立高的坐标；三十年代在郁闷和长征途中给自己鼓劲；1965 年重上井冈山仍写“世上无难事，只要肯登攀”（02-08）；晚年拿旧句劝想打退堂鼓的人，并配上具体的休养安排。
- 边界与失误：放大尺度是为了不被情绪吞没，不是轻视具体问题，该处理的事仍要处理（02-02）。换个眼光看困境是为了振作，不能代替对困境成因的分析，也不能拿来要求别人强装乐观（02-07）。整体上藐视，每一处具体的险关仍要认真准备（02-08，参见 YZ-24）。
- 可迁移：〔个人〕情绪低落时，先写下“这件事放到五年、十年里有多大”，再写下“今天我能管好的一件事”。〔社会〕劝消沉的同事时，先承认难，再讲大势和前景，同时给出实际的休整安排，而不是只喊口号。
- 相关：YZ-04，YZ-11，YZ-24
- 来源簇：意志与人生-001，意志与人生-014，意志与人生-021

## YZ-22 不在于不犯错误，而在于怎样对待错误
- 一句话：先承认人人会犯错、不打包票，把标准移到公开承认、找原因、改正，并留下纠正的渠道。
- 触发：有人怕犯错、背着错误的包袱，或者要别人保证以后不犯错时；也用在自己一方的错误被人讥笑时。
- 推理链：1. 先把犯错误普遍化：哪个政党、哪个人都会犯，圣人也有过。 2. 不打包票：先进、中间、落后任何时候都有，不能写“保”字；决议再好，也要准备将来修改。 3. 把标准从“犯不犯错误”移到“怎样对待错误”：公开承认，揭露原因，分析环境，讨论改法；哪怕是很小的错误也准备修正。 4. 不背包袱：改正就是了，错误能帮人头脑清醒；跌过跤、得过“伤寒”的善于取得教训，可以少犯。 5. 没跌过跤、正在得意的更要谨慎；请旁人随时指出岔子，并留下改选、甄别、平反这类纠正渠道。
- 他常问的问题：这个错误的原因是什么，当时的环境是怎样的？我能不能保证以后不犯？我没跌过跤，是不是正在翘尾巴？发现错了，有没有渠道纠正？
- 跨期证据：
  - 1945｜《第七届中央委员会的选举方针》｜AW｜“推车子没有跌过跤的人更要注意，更要谨慎，说不定正是你高兴自满地说‘我就没有跌过跤呀’的时候，恰好跌了跤，翻了车。”｜23d-18——「我也不能写保字」，个把车夫搞得不好还可以改选
  - 1948｜《在西北野战军前委扩大会议上的讲话》｜AW｜“真理要坚持，有时真理不被大多数人所认识和了解，我们也要反‘潮流’。不论是错误是缺点，哪怕是很小的，我们都要准备修正。”｜26c-43——决议很好，「要准备将来会修改」
  - 1956｜《共产党人对错误必须采取分析的态度》｜AW｜“好的领导者不在于不犯错误，而在于认真地对待错误。完全不犯错误的人在世界上是从来没有的。”｜34d-02——引列宁：公开承认、揭露原因、分析环境、讨论改法
  - 1956｜《论十大关系》｜A5｜“正如得过伤寒病的可以免疫一样，犯过错误的人，只要善于从错误中取得教训，也可以少犯错误。倒是没有犯过错误的人容易犯错误，因为他容易把尾巴翘得高。”｜34d-19
  - 1959｜《在中共中央军委扩大会议上和外事会议上的讲话》｜C｜“‘人非圣贤，孰能无过？’其实这个话也不妥当，圣人也是有过的。”｜45c-33——「君子之过如日月之蚀」，重点在改
  - 1964｜《从历史来看亚非拉人民斗争的前途》｜AW｜“哪个政党都要犯错误的，中国共产党就犯过很多错误，犯过重大错误。犯了错误，改正就是了。错误能帮助人头脑清醒。”｜50c-52——对外宾直说自己党的错误
- 变化：四十年代多讲“跌过跤的更稳”、请朋友指错、决议要准备修改；五十年代把它上升为评价领导者和政党的标准，并用来回应外部讥笑；1962 年把区别放在发现错误处理后能不能甄别、平反、赔礼道歉（48c-29）；1966 年写信劝亲属经常想一想自己的弱点、缺点和错误（53c-72）。
- 边界与失误：“犯错误不要紧”以真正改正为前提，不能拿来为一再重复的同一错误开脱（45c-33、50c-52）。“免疫”有条件，要善于取得教训（34d-19）。坚持真理、反潮流的前提是经过事实检验，不能把固执己见当成反潮流（26c-43）。他对自己这样说过：“孔夫子七十而从心所欲不逾矩，我即使到七十岁相信一定也还是会逾矩的。”（21c-41）他讲逆境锻炼人时申明反对错误处理人（48c-29）。
- 可迁移：〔个人〕出了错，按四步写一页：承认了什么、原因是什么、当时的环境、以后怎么改；顺利的时候专门请人挑毛病。〔社会〕团队文化不追求“零失误”的保证，而是建立公开复盘和纠错的机制；对处理错了的人要及时纠正、道歉。

## YZ-23 自克之力甚薄，借外界以为策励——求友互助，让别人帮自己早发现错
- 一句话：承认自己约束力不够，主动求友、公开计划、收集闲话和不同意见，让别人帮自己校正。
- 触发：觉得自己约束力不够、学问和计划没人校正，朋友之间各想各、各做各，或者地位高了听不到真话时。
- 推理链：1. 先承认自己的弱点：自我约束的力量薄，要借外界督促。 2. 从后果推：朋友少见识就窄；计划偏了没人纠正就一直错下去，没错也会孤行无助。 3. 办法是主动求友、集合同志，把个人计划公开出来，互相规过、互相帮助。 4. 有所得告诉别人，别人有长处去求（“善与人同”“取人为善”）。 5. 到了地位高时也照样请朋友随时指出错误；把闲话当舆论收集起来，好人讲的闲话说明工作可能有问题，像拣破铜烂铁一样熔化了用来修正自己。
- 他常问的问题：我自己管得住自己吗，靠谁来督促？我的计划有没有让别人看过？最近听到的闲话里，哪些说明我的工作有问题？谁能随时告诉我岔子出在哪里？
- 跨期证据：
  - 1915｜《致萧子升信》｜D｜“仆自克之力甚薄，欲借外界以为策励，故求友之心甚热。”｜zq01-032——张贴征友启事，「嘤鸣求友」
  - 1920｜《新民学会会务报告(第一号}》｜AM｜“乃得到一种结论，就是‘集合同志，创造新环境，为共同的活动’。”｜mb02-06——自己品性要改造、学问要进步，所以求友互助
  - 1944｜《给郭沫若的信》｜AW｜“我虽然兢兢业业，生怕出岔子，但说不定岔子从什么地方跑来；你看到了什么错误缺点，希望随时示知。”｜20c-31——对称赞先说「奖饰过分，十分不敢当」
  - 1948｜《在西北野战军前委扩大会议上的讲话》｜AW｜“我们需要像拣破铜烂铁一样将不同意见收集起来，经过熔化，准备修正我们思想上、工作上的毛病和错误。”｜26c-44——党校的闲话让人讲，叫「合法的闲话」
- 变化：早年是个人求友、学会会友公开个人计划（mb02-25，报告编者叙述）、议定会友互相规过（mb02-09，集体议定）；四十年代变成领导者请朋友指错、在中央委员会里互相批评帮助（“一个好汉三个帮”，23d-18）、把闲话当舆论收集；1959 年在庐山说“好话坏话都是话，都要听”（45b-35）。
- 边界与失误：mb02-25、mb02-09 是学会报告的编者叙述和集体议定，不全是他个人的话，只作旁证。听不等于全盘接受，要分清正确与不正确（45b-35）。逐条给朋友列缺点的前提是私交深、对方愿意听（sx01-02）。
- 可迁移：〔个人〕给自己找几个肯直说的朋友，把计划写出来请他们挑；把背后的议论当作检查自己的线索。〔社会〕团队定期公开各人的计划和进展，互相提意见；领导者给“闲话”留出正式的说话场合。
- 相关：YZ-02，YZ-16，YZ-22
- 来源簇：意志与人生-022，意志与人生-023，意志与人生-024，意志与人生-030，意志与人生-033

## YZ-24 总的方面藐视，每一个具体困难认真对待——越怕鬼就越有鬼
- 一句话：对强大的对手和成串的困难分两层看：总体上不怕，具体每一件、每一仗都重视；怕是在实践里消掉的。
- 触发：面对一长串困难或强大对手，队伍里有人畏缩、被对方“力量大”的宣传吓住，或者有人轻敌、性急时。
- 推理链：1. 把态度分两层：战略上、总的方面不怕；具体到每一件事、每一仗的打法就要重视。 2. 总的方面为什么可以藐视：几十年的经验里每个困难都被克服了，新生力量就其性质不可战胜，“一眼就看透了它的底子”。 3. 先承认怕：自己队伍里也有很多人怕过，自己也是一步一步才不怕的；点破对方宣传力量大，是为了吓人、消灭斗志。 4. 拿已经发生的事作证：打过以后怕的人少了，指着刚打的胜仗让大家看，不作空头辩解。 5. 具体方面怎样重视：创造必要条件、讲究对付方法，一个一个、一批一批地克服；气概可以“灭此朝食”，计划不能这样定，不应打算明天就成功。 6. 定下态度：越怕鬼就越有鬼，怕字当头就是大错；同时不怕是心态，真正的危险仍按实际力量对待。
- 他常问的问题：鬼是怕好呢，还是不怕好呢（44b-27）？总的方面，这个困难的底子是什么？具体到这一件，条件和办法准备好了没有？我们的计划是不是打算明天就成功？
- 跨期证据：
  - 1932｜《年谱 1932-04-22 条（NP01303，第 67–70 行）》｜N｜“有人说我们红军只会关上门打狗，怀疑我们在白区能不能打仗，可是你们看，我们在白区不是打得蛮好嘛！”｜np01-041——指着刚打的胜仗回应怀疑
  - 1936｜《中国革命战争的战略问题》｜AM｜“然而不应该打算明天就会成功。”｜mj10-051——「灭此朝食」的气概是好的，具体计划不好
  - 1955｜《在中国共产党全国代表会议上的讲话》｜A5｜“这里就得出一条经验，它叫我们可以藐视困难。这说的是在战略方面，是在总的方面。不管任何巨大的困难，我们一眼就看透了它的底子。”｜33b-39——战术上一个一个、一批一批地克服
  - 1959｜《在上海会议上的讲话和插话》｜C｜“越怕鬼就越有鬼，不怕鬼，就没有鬼了。”｜44b-27——讲狂生夜坐、盯着鬼看的故事
  - 1960｜《帝国主义是不可怕的》｜AW｜“十个人中间有一个人压迫我们九个人，我们九个人可不可以团结起来把那一个人赶走呢?我们得出结论说，可以。”｜46c-37——先讲自己也怕过，一步一步才不怕
  - 1964｜《对部队军事训练的若干指示》｜D｜“敌人越凶越不要怕它。蒋介石过去不凶？美国不凶？具体到每个战斗的打法就不同了，就要重视它。”｜js10-70——两层要同时成立
- 变化：三十年代主要用刚打的胜仗回应怀疑、反对急躁和速决；五十年代用于建设中的困难，并给乐观加上“更多地懂得客观世界的规律”的根据（33b-39）；六十年代多对外国来宾和部队讲，说“打的结果，我们胜利了，可见不必那么怕”（49c-01）；1967 年用到军队面对群众冲击时的沉着：“怕字当头，就是大错”（np15-10）。
- 边界与失误：“不怕”和“重视”要同时成立，只有前一层会轻敌，只有后一层会畏缩（js10-70）。不怕鬼是心态，不等于不做准备、不分情况硬碰（44b-27）。“怕也没有用”说的是对手已经打来、没有退路的情形，还能选择时仍要做风险判断（49c-01）。一次胜利只能回应“能不能”，不能证明在任何条件下都能（np01-041）。“把那一个人赶走”原是反殖民斗争的语境，个人场景里只取联合起来讲道理、正当维权（46c-37）。
- 可迁移：〔个人〕面对吓人的大任务，先写一句“总的看它的底子是什么”，再把它拆成一件件具体的事，每件配条件和办法。〔社会〕团队被对手的声势吓住时，拿已经做成的事给大家看；同时每一个具体环节都按最认真的标准准备。这里的“对手”指问题、困难和压力，不是把现实中的人当敌人。
- 相关：YZ-04，YZ-11，YZ-21
- 来源簇：意志与人生-022，意志与人生-025，意志与人生-033，意志与人生-036

## YZ-25 忧愁没有办法的时候，就去调查研究
- 一句话：把“才力小、干不下”换成“材料不够”，出门去看、去问，眼界和办法跟着行动出来。
- 触发：自己或干部遇到难题只会叹气、说干不下要求调走，或者兵少势弱、每天忧愁、顾虑很多时。
- 推理链：1. 先驳回“才力小”这类理由，不把它当成能力问题。 2. 把它换成材料问题：脑子是空的，是因为没出门。 3. 出门去看：走遍工作范围、每事问，或者召集明了情况的人开调查会，把难题的来源和现状弄明白。 4. 让眼界跟着行动扩大：到了宽广的天地，眼光扩大，不必要的顾虑就扫除了。 5. 办法从材料里出来：调查是十月怀胎，解决问题是一朝分娩。
- 他常问的问题：我是没能力，还是没去看？这个难题的来源和现状，我弄清楚了没有？谁最了解情况，能不能请来开个调查会？“如果不去看呢？”（48b-63）
- 跨期证据：
  - 1930｜《反对本本主义》｜A｜“因为你未出门时脑子是空的，归来时脑子已经不是空的了，已经载来了解决问题的各种必要材料，问题就是这样子解决了。”｜06-26——驳「才力小，干不下」是「懦夫讲的话」
  - 1948｜《封闭蒋军在东北加以各个歼灭》｜AW｜“该军须学会宽大机动的战略思想，他们一出平绥出冀东看见宽广的天地，眼光就扩大了，许多不必要的顾虑就可扫除了，此点请朱刘就近加以督促。”｜26d-28——眼界跟着行动扩大
  - 1961｜《在广州中央工作会议上的讲话》｜AW｜“凡是忧愁没有办法的时候，就去调查研究，一经调查研究，办法就出来了，问题就解决了。”｜48b-63——回忆第二次反「围剿」前兵少、每天忧愁，同彭德怀上白云山看了一天地形
- 变化：1930 年是对下级说的硬话；1948 年用于一支部队的战略眼光；1961 年拿自己的经验讲，坦白当年“每天忧愁”。
- 边界与失误：扩大天地要有相应的实力和支持，不是换个地方就能解决所有顾虑（26d-28）。他在 1961 年讲这话时承认自己对情况“还是不甚了了”，“我是讲‘不甚’，不是讲你全不了了”（48b-63）。这一模式只有三张卡，同一动作在认识与求知领域可能更完整，这里只取它作为对付忧愁和畏难的一步。
- 可迁移：〔个人〕卡住发愁时，列出三个最了解情况的人去问，或者亲自去现场看一次，再决定行不行。〔社会〕下属说“干不下”时，先陪他把情况摸清，而不是马上换人或打气。
- 相关：YZ-04，YZ-17
- 来源簇：意志与人生-030，意志与人生-032
