# 决策咨询工作流

用户带着一个具体决定或困境来时使用。目标是帮他把问题想清楚、把决心下定、把下一步做实，并且做到底。不替他拍板。

思考的主线和动作见 `thinking-engine.md`。这份文件讲怎样把它用在一次咨询里，写法示范见 `worked-examples.md`。

## 先确认三件事

- 要做的到底是什么决定，什么时候必须做出，最坏结果能不能承受。
- 已知事实和用户的猜测分别是什么。
- 是否涉及医疗、法律、财务、心理危机等专业领域。涉及时，方法只用来理清思路，结论要交给专业人士。

缺的事实会改变结论方向时（例如这笔钱是不是全部积蓄），先问用户最关键的一两个问题。不方便来回追问，就把需要先查清的事列出来，并按不同情形分别给建议。不要用想象补齐。

## 按思维引擎走一遍

简单问题可以几步并成一步；重大、难以挽回的问题，每一步都要走到。括号里是 `thinking-engine.md` 的动作和可以借用的方法卡。

1. **问准**：把用户的问题改写成一到两个能被事实回答的问题；写出两个极端答案和它们各自片面在哪里；把「能不能」改成「在什么条件下能」（动作 1）。
2. **摸情况**：列出缺的关键事实，以及怎样拿到一手信息：问谁，看什么，做什么小实验（动作 2；卡 2、16）。
3. **找特点、抓矛盾**：给双方，或者自己和环境，各列三到五个基本特点；写出几对矛盾，指出主要矛盾和其中起主导作用的方面；判断矛盾的性质，按性质选方法（动作 3、4；卡 4、5、6、17）。
4. **算力量账**：硬实力和软实力，差距的程度，每一项变化的方向，得失和消耗补充（动作 5；卡 8、9）。
5. **看对手和环境**：替对方做一次判断：他要什么，怕什么，会怎样反应，内部有什么分歧，会在哪里估计错（动作 6；卡 7、25）。个人和团队关系默认按人民内部矛盾处理（卡 6）。
6. **分阶段**：现在在哪一段，凭什么这样判断；进入下一段的标志；本阶段该做和不该做的事（动作 7；卡 8、28）。
7. **定关节**：撬动全局的那一件，最低目标，放弃清单（动作 8；卡 9、26）。
8. **出方案**：主案，两三个分支，最坏情况和应对，所需资源的数量，没把握的点和求证办法；留出余地（动作 9；卡 27）。
9. **下决心**：决定和两三条主要理由；从什么时候起不再犹豫；要说服谁，怎样说服（动作 10；卡 19）。
10. **边做边认识**：复盘的时间点和要看的指标；哪些数字变了要改做法，哪些变了要改方针（动作 11、12；卡 1、24）。
11. **条件检查**：对照下面的表，指出这次最可能在哪里走样。

## 两种常用模式

### 下决心、将革命进行到底

用户已经有方向、缺的是决心，或者正处在最关键的最后一段时：

1. 先核实方向：主要矛盾判断对不对，条件够不够（卡 4、9）。
2. 写清楚不做会怎样、半途而废会怎样（卡 19）。
3. 写出破釜沉舟的具体动作：集中哪些资源，放弃哪些分散精力的事，在什么时间点前完成。全部积蓄、健康、法律责任这类退路不断（见上面的先确认三件事）。
4. 写出顶住困难的办法：困难时看到成绩和光明，提高勇气（卡 19、23）。
5. 定下胜利后的下一步和防松懈的措施（卡 18、20）。

### 不断革命、自我革新

用户的事业或团队已经取得一定成功，想防止停滞和变质时：

1. 总结已经完成的这一步，确定下一步（卡 18、24）。
2. 检查有没有被糖衣裹着的炮弹打中：骄傲、松懈、特权、脱离一线（卡 20）。
3. 斗私批修：列出自己和团队需要革掉的私心、惰性、旧习惯（卡 21）。
4. 不破不立：写出要破的和要立的两张清单（卡 22）。
5. 接班与吐故纳新：培养谁接手，淘汰哪些过时的做法（卡 20）。
6. 定下下一次总结的时间（卡 24）。

## 条件检查（据他本人的论述）

| 想用的思路 | 他本人强调的条件 | 检查问题 |
|---|---|---|
| 破釜沉舟、将革命进行到底 | 不打无准备之仗，不打无把握之仗（卡 9、19） | 方向和条件判断清楚了吗？撑到最后的资源够不够？ |
| 不断革命、一个接一个 | 经过一切必要的阶段；反对冒险主义和急性病（卡 18） | 上一步巩固了吗？下一步的条件具备了吗？ |
| 敢想敢干、只争朝夕 | 有个清醒头脑，打个折扣（卡 16、23） | 数字核实了吗？ |
| 斗争、批评 | 要文斗，不要武斗；惩前毖后，治病救人；团结、批评、再团结（卡 6、14） | 针对的是事还是人？目的是改进和团结吗？ |
| 动员、发动群众 | 抓革命，促生产；要安定，要团结（`continuing-revolution.md` 第 6 节） | 主业有没有受影响？动员以后怎么巩固成果？ |
| 胜利以后 | 两个务必；警惕糖衣裹着的炮弹（卡 20） | 有没有骄傲、松懈、搞特殊？ |
| 吐故纳新、整顿队伍 | 惩前毖后，治病救人；不要一犯错误就打倒（卡 20、21） | 更新的是做法和流程吗？人员去留是不是按正常的绩效和制度办？ |
| 让人讲话 | 言者无罪，闻者足戒；哪怕是骂自己的话，也要让人家讲（卡 14、15） | 提意见的人会不会吃亏？ |
| 替对手做判断 | 计划宁可放在对手少犯错误的假定上（卡 25） | 计划是不是押在对手犯错上？ |
| 定关节、放掉一部分 | 关节因事而定；丢掉的要能换回更大的东西（卡 26） | 放掉的东西以后拿得回来吗？关节拿不下时有预案吗？ |
| 最坏打算 | 准备最坏是为了争取好的可能（卡 27） | 是不是因为最坏打算而不敢动了？余地留在关键资源上了吗？ |
| 先站稳一块再扩大 | 对手暂时稳定时逐步推进，混战时才可以扩得快（卡 28） | 现在对手是稳定还是混战？根据地稳固的标志达到了吗？ |

## 回答怎样写

- 先给判断，再讲理由。按问题本身组织段落，不套固定标题，不按篇名分节。
- 下面这些要素，该有的都要有，但不必每样单列一段：判断和它依据的事实；主要矛盾；力量和阶段；关节、最低目标和放弃清单；主案、分支和最坏情况；复盘指标；会推翻判断的事实；还缺的事实。
- 每段讲一件事，太长就拆。需要用户去查清的事，集中写成一个短清单；分支和复盘指标也可以用短列表。不用【】一类的固定标题。
- 没有核实的外部事实写成待查；算账用的假设数字标明是假设。
- 原话零到三条，按 SKILL.md 第 2 条核验和标注。历史例子一般只用一个，说清像在哪里、不像在哪里（`history-literacy.md` 第三节）。
- 不把方法当成命令。有几条可选路径时，写出各自的代价，由用户决定。
- 第三人称，例如「毛泽东复盘第五次反“围剿”时……」。不扮演，不称同志，不用领袖口吻。用户明确要求第一人称时，按 SKILL.md 第 5 条。
