# 存疑与误植语录清单

这些句子在网上和其他 skill 里常被当作毛泽东原话或标错出处。`scripts/verify_quote.py` 会读取下表第一列「」内的句子，命中时给出提醒。新增条目时保持三列格式。

| 句子 | 实情 | 处理 |
|---|---|---|
| 「人有多大胆，地有多大产」 | 1958 年大跃进时报刊上的口号；本库所有层级（含文集、谈话、万岁、语录）都没有出现；本库不收报刊，首见于哪份报纸、哪一天无法在此核实 | 不得作为毛泽东原话；可写“大跃进时期流行的口号”，需要具体出处时请用户查 1958 年报刊或党史研究 |
| 「实践是检验真理的唯一标准」 | 作为口号流行于 1978 年《光明日报》特约评论员文章；《实践论》原文是“真理的标准只能是社会的实践”；本库只在静火版收录的 1963 年“五评”苏共公开信（编辑部文章）里出现 | 引《实践论》时用原文；不要说毛在《实践论》里提出“唯一标准” |
| 「一辈子就做了两件事」 | 常见的“认识世界、改造世界”版本是某个 skill 作者的改写，被大量照抄 | 不得作为原话 |
| 「我一生干了两件事」 | 1976 年流传的谈话（蒋介石、海岛、文化大革命），本库只在静火版第七卷《后事交代》里有；本库所收官方文本未见（本库没有《文稿》《年谱》，不能据此断定是伪作）；日期各处说法不一，静火版作 1976 年 6 月 15 日 | 可以加引号，但必须标“据非官方汇编（静火版），未经官方文本核对”，并说明出处和日期存疑；不能和选集原文并列当定论 |
| 「三七开就不错了」 | 毛用“三七开”评价斯大林（选集第五卷）、估计 1958 年的成绩（文集第 7 卷武昌会议讲话）、评价文革（静火版所收 1975–1976 年谈话）；本库未见他用“三七开”评价自己一生 | 不得写成毛的自我评价 |
| 「千万不要忘记阶级斗争」 | 1962 年八届十中全会精神的口号化概括；本库所收讲话记录（C 层）的原话是“就必须年年讲，月月讲，天天讲” | 引原话用讲话记录并标 C 层；口号可写作“当时的提法” |
| 「文革十年」 | “十年”是 1976 年 10 月以后才有的回顾说法，毛生前不可能这样自述 | 不得放进仿写段，也不能说成他的自述 |
| 「阶级斗争，一抓就灵」 | 只见于《毛泽东思想万岁》（非官方） | 引用时标“据《毛泽东思想万岁》”，不要标高可信 |
| 「知识越多越反动」 | 本库未见；文革时期流行说法 | 不得作为毛泽东原话 |
| 「和尚打伞，无法无天」 | 出自斯诺对 1970 年谈话的英文记述，中文谈话记录未见此句 | 写“据斯诺回忆”，不加引号当原话 |
| 「我是负债大王」 | 本库未见，来源不明 | 不引用 |
| 「心之力」 | 网传“毛泽东青年时期文章”，是后人伪作 | 不引用 |
| 「不管黑猫白猫」 | 邓小平的话；毛泽东 1975–1976 年谈话中引述它是为了批评邓小平 | 不得当作毛的主张 |
| 「摸着石头过河」 | 陈云、邓小平时期的改革方法论说法 | 不得当作毛的话 |
| 「一往无前的精神」 | 常被标为《论持久战》，实际出自《论联合政府》 | 标《论联合政府》 |
| 「一分为二，这是个普遍的现象」 | 常被标为 1963 年文章，实际出自 1957 年莫斯科会议讲话（选集第五卷《党内团结的辩证方法》） | 按实际篇目标注 |
| 「枪杆子里面出政权」 | 常被标为《湖南农民运动考察报告》，实际出自 1938 年《战争和战略问题》 | 标《战争和战略问题》 |
| 「与天奋斗，其乐无穷」 | 流传为 1917–1918 年青年时期语，选集、文集未收；本库 S 层的诗词网页收作《四言韵语·奋斗》，题记说源于 1954 年第 24 期《中国青年》魏巍的文章，属于后人转述 | 可以引用，但要写“据魏巍 1954 年文章的转述”，不标官方出处，不和选集原文并列 |
| 「破釜沉舟」 | 成语，出自《史记·项羽本纪》；本库毛泽东文本中未见 | 可以用来描述他将革命进行到底的精神，但不加引号说成他的原话，也不放进仿写段；要引原话，用“将革命进行到底”“下定决心，不怕牺牲，排除万难，去争取胜利”等（见 `continuing-revolution.md`） |
| 「无产阶级专政下继续革命」 | 这一完整提法和六条要点见于 1967 年 11 月《人民日报》《红旗》《解放军报》编辑部文章（静火版第七卷《论无产阶级专政下继续革命》收录，题注称经他审定）；本库所收他本人的话里，用的是“不断革命”“继续革命”“将革命进行到底” | 可以作为理论名称使用；引原话时用他本人的提法，编辑部的概括要说明出处 |
| 「存人失地」（常见全句「存人失地，人地皆存」） | 本库只在《毛泽东思想万岁》所收 1947 年 3 月 16 日《接见边区部队一部分负责同志的讲话》里有，原文是“有人失地，人地则存，存地失人，人地皆失”；常见的「存人失地，人地皆存」是后人的改写 | 引原话用这段原文，标「据非官方汇编（《毛泽东思想万岁》）」；改写的句子不加引号当原话 |
| 「以苏为鉴」 | 本库未见这四个字；《论十大关系》的原文是“过去我们就是鉴于他们的经验教训，少走了一些弯路，现在当然更要引以为戒”（选集第五卷） | 可以作为概括说法，但不加引号当原话；引原话用“引以为戒”这一句 |
| 「解剖麻雀」 | 本库未见这四个字；常被用来概括他深入调查一两个典型的方法 | 可以作为方法的通称，但不加引号说成他的原话；要引原话，用《反对本本主义》的“没有调查，没有发言权”，或《兴国调查前言》里的“没有这种调查，就没有农村的基础概念” |
| 「得意之笔」（常见全句「四渡赤水是我的得意之笔」） | 后人回忆里的说法；本库没有长征时期的电报，也未见他本人的这句话 | 不加引号当原话；需要提到时写「据后人回忆」；四渡赤水按通行史实简述 |
| 「进京赶考」 | 1949 年 3 月离开西柏坡时的对话，见于后人的回忆和传记；本库未见（本库没有年谱和传记，不能据此断定真伪） | 写「据回忆」，不加引号当原话；要引原话，用七届二中全会报告里「两个务必」那一段（选集第四卷） |
| 「决不当李自成」 | 常和「进京赶考」一起流传，来源同上；本库未见 | 写「据回忆」，不加引号当原话；讲胜利以后防骄傲，可以引 1944 年《学习和时局》里的“引为鉴戒，不要重犯胜利时骄傲的错误” |
