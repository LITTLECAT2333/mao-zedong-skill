# 原文库（kb）

这个目录放分层原文库。`scripts/verify_quote.py`（核验引文）和 `scripts/search_kb.py`（检索原文）都靠它工作。

**公开仓库默认不带原文库。** 原文库里有选集、文集、年谱、建国以来文稿等出版物的全文，以及马恩列著作的中文译本，其中大部分仍受著作权保护（见 `docs/SOURCES.md`）。没有原文库时，skill 照样可以分析问题，但核验脚本会提示「原文库没有安装」，回答里的原话一律按「未核到」处理：不加引号，改为转述。

## 目录结构

每个层级一个顶层目录，目录名的前缀决定层级；下面可以再分卷、分年份。每篇一个 UTF-8 的 `.md` 或 `.txt` 文件，第一行是篇名。

| 目录 | 层级 | 内容 |
|---|---|---|
| `A_选集/第1卷/…` | A | 《毛泽东选集》第一至四卷 |
| `A5_选集第五卷/` | A5 | 《毛泽东选集》第五卷（1977 年版） |
| `AW_文集/第1卷/…` | AW | 《毛泽东文集》第一至八卷 |
| `D_建国以来文稿/`、`D_军事文集/`、`D_外交文选/`、`D_书信选集/`、`D_早期文稿/` | D | 中共中央文献研究室等编的文献集 |
| `S_诗词/` | S | 诗词 |
| `Y_语录/` | Y | 《毛主席语录》 |
| `AM_毛泽东集/`、`AM_毛泽东集补卷/` | AM | 竹内实等编《毛泽东集》正编、补卷 |
| `B_谈话与散篇/` | B | 谈话记录、批示、散篇 |
| `C_静火版/`、`C_毛泽东思想万岁/` | C | 非官方汇编 |
| `P_哲学批注集/` | P | 《毛泽东哲学批注集》 |
| `N_年谱/1949/1949-10.md` | N | 《毛泽东年谱》，按年月分文件 |
| `M_马恩列/` | M | 马恩列原著、艾思奇《大众哲学》（理论来源，不是毛泽东的话） |

选集、文集篇末的「注释」会被自动识别为编者注释，不算毛泽东的话；静火版的编者注释另存为同名的 `.notes.md`。

只放你有权使用的文本。放好以后运行一次：

```
python scripts/verify_quote.py "没有调查，没有发言权"
```

能看到「可引用（最高层级 A……）」就说明装好了。
