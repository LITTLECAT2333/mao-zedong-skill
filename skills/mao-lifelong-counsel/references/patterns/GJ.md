# 国际与世界（GJ）思维模式

（第二步合成。来源：draft_GJ_1、draft_GJ_2，并补入 digest\证据\国际与世界\_新增.md。编号 GJ-两位序号。）

## GJ-01 拿对方自己的话来回答对方
- 一句话：对方提要求、指责或劝告时，先抓住对方的用词、前提和做法，顺着推出对方不能不认的结论。
- 触发：对方提出要求、指责、劝告，或者带着焦虑来求助，需要回答或驳回时。
- 推理链：
  1. 先听清对方用了什么词、立了什么前提（「报复」「有权」「多数支持」「一只脚进了大门」）。
  2. 把对方前后的说法和做法排在一起，找出变化和自相矛盾（先劝不批评蒋，后劝不批评赫尔利；墓地材料前后不一）。
  3. 顺着对方的前提往下推，推出对方自己不能不认的结论，或者拿对方自己的做法反问「为什么我们不能」。
  4. 需要追责时摆出事实先后，说明责任在谁。
  5. 结论落到对方难以反对的办法上，或者把事情交还对方自己处理。
- 他常问的问题：
  - 对方刚才用的这个词，它自己认不认真推下去？
  - 对方自己做过同样的事没有？那为什么我们不能？
  - 对方的材料、说法前后对得上吗？
  - 照对方自己的前提，它还有什么可怕、可要求的？
- 跨期证据：
  - 1944｜《同包瑞德的会谈》｜AM｜“如果双手被反捆着，一只脚进了大门是没有用处的。”｜mb13-26——接过赫尔利「一只脚进了大门」的比喻反用
  - 1991｜《关于批评美国对华政策的电报》｜AW｜“美国报纸经常批评外国元首，去年曾激烈批评蒋介石，为什么中国人不能批评赫尔利?”｜57b-54——1945 年 7 月电报，拿对方的做法反问
  - 1949｜《中国人民解放军总部发言人为英国军舰暴行发表的声明》｜A｜“长江是中国的内河，你们英国人有什么权利将军舰开进来？没有这种权利。”｜29d-19——抓住艾德礼「有权」一词
  - 1954｜《关于掘运朝鲜战争中军事人员尸体问题的电报》｜D｜“尸体既已掘出应即送交我方，没有理由重行予以埋葬。根据这一理由，我们可以提出各自掘运本方地区内对方人员的尸体进行交换的办法，而对方将比较难以反对。”｜wg07-090——找出对方材料矛盾和违反协定之处，落到对方难以反对的办法
  - 1965｜《毛泽东主席、刘少奇主席等同过境我国的苏联总理柯西金谈话记录（1965年2月12日）》｜B｜“今年三月一日，你们如果又改期，对你们不利，丧失威信。说不开，变个名称，不叫起草委员会嘛，这个会一开，就有文章可做嘛。”｜52b-06——对方追问为何不参加，答以「你们信上写了嘛」
  - 1974｜《毛泽东会见马来西亚总理拉扎克谈话记录（1974年5月29日）》｜B｜“那你又何必怕呢？”｜56d-10——顺着对方「多数支持、一小撮」的前提化解焦虑，再把办法交还对方
- 变化：1940 年代多用在公开驳斥和电报交涉中，语气硬，配合摆事实、追责任；1950 年代用在停战后的具体交涉里，落到对方难以反对的方案；1960—70 年代多用在会谈里，语气缓和，常带玩笑，用来婉拒或化解对方的焦虑。
- 边界与失误：要以事实清楚、己方确实占理为前提；事实还有争议时先查清，反问式驳斥会让误会升级。「劝对方照开、我们不参加」一类说法，适用于双方立场已经分开的场合，不适用于要真心合作办成一件事的场合。他本人的复盘未见于本组卡。
- 可迁移：〔个人〕别人批评或提要求时，先复述对方的原话和前提，看它能不能自洽，再回应，比另立一套说法省力。〔社会〕谈判、交涉中找对方文本里的自相矛盾和对方自己的先例，提出对方按自己的标准也难以反对的方案。
- 相关：GJ-02（用对方的言论判断对方处境）、GJ-03（用对方的行动检验对方）

## GJ-02 从对手自己的言论里读对手的处境
- 一句话：把对手的声明、批评、回忆录、报纸当作材料，从中读出对手怕什么、急什么、内部怎样分歧。
- 触发：对手发表声明、批评我们、出版回忆录，或者对手的报纸透露情绪，需要判断对手处境和下一步时。
- 推理链：
  1. 把对手的原文找来读，按时间排开（白皮书、演说、回忆录、报刊言论），不只看一两次表态。
  2. 区分对手不变的根本方针和可伸缩的手法，再在批评和抱怨里找它怕什么、急什么。
  3. 抓出对手自己认输的话、话里的请求和前后矛盾（主战又主和）。
  4. 专门留意对手内部的分歧（英国想让印度参加，美国反对；军部和外务省装红白脸）。
  5. 推出对手的被动之处，据此安排自己的姿态：我们提要求，拒绝的是对方，让对方处于被动。
  6. 把对手的原话拿给第三方或读者看，让人从对方自己的记述里得出结论。
- 他常问的问题：
  - 连当事人自己都这样说，那件事的实情可想而知吗？
  - 对手在批评我们什么？这说明它在怕什么？
  - 对手话里哪一句是认输，哪一句是请求？
  - 对手内部谁和谁意见不一样？
- 跨期证据：
  - 1919｜《和约的内容》｜D｜“他于签约后所发议论是这样，我们就叫想见那和约的内容”｜zq03-016——不逐条分析和约，先摆签约人斯末资自己的话
  - 1939｜《反投降提纲》｜AW｜“但是它执行此基本方针的方法(或策略)是软硬兼施的，有伸缩性的，并可作出某些暂时的、局部的、表面的让步，以求达其根本目的。”｜14c-24——按时间排出二十九条日方材料，读出主战派与主和派之争
  - 1945｜《在延安党校大礼堂关于国共谈判报告》｜C｜“签订中苏条约的不是别人而正是蒋介石，他是合法政府，他签字最好，因为一切的反苏言论都是从他这个反动集团发出的”｜24c-26——抓住对手亲手签下的条款推断内战难打
  - 1949｜《f可奈何的供状—评美国关于中国问题的白皮书》｜AM｜“凡是一个头脑清醒而有最低限度的推理能力的人，都不能不由此得到结论：美国政府是坚决地一贯地抱着侵略中国的目的。”｜mb14-32——用白皮书自己的承认和数字逼出结论
  - 1958｜《为印发杜勒斯批评我国人民公社言论重拟的标题（提要）和批语》｜D｜“他们想把我国拉过去，而他们自己则向中国钻进来美国资产阶级已感到恐慌，感到被动，想要设法脱出这种情况。”｜wg13-62——从杜勒斯的批评读出对方的恐慌
  - 1960｜《同蒙哥马利的谈话》｜AW｜“美国说如果英国要印度参加，美国就要蒋介石和日本参加。”｜46d-12——读艾登回忆录，专看英美内部分歧
- 变化：1919 年已用当事人自己的话推结论；1930—40 年代多用来写公开评论、给党内讲形势，材料排得很满；1950—60 年代更多是内部批注和会谈，把对手言论印发给与会者，或拿对方本国人的书给对方看。
- 边界与失误：判断要建立在大量可核对的材料上，材料不足时不能凭一两次表态断定对方的根本目标。回忆录是当事人的一面之词，可能有自我辩护的成分。用「唯一解释」的推法前，要确认确实排除了其他可能。拟给内部的标题和提要是他的判断，不等于对方原话。
- 可迁移：〔个人〕读竞争者、合作方或评审的公开文字时，留意它反复强调什么、回避什么，从中推它的压力和顾虑。〔社会〕研究一个机构的政策走向，先把它历年的正式表态排成时间序列，看哪些不变、哪些在变。
- 相关：GJ-01、GJ-03、GJ-05
- 来源簇：国际与世界-007，国际与世界-010，国际与世界-012，国际与世界-022，国际与世界-001

## GJ-03 不看招牌看行动，对方的行动看两个侧面
- 一句话：不凭对方的言辞和自我标榜下判断，拿可检验的具体行动作试金石，并同时看威胁和试探两面。
- 触发：对方作出承诺、示好或挑衅，需要判断对方真实意图、决定接不接、怎样应对时。
- 推理链：
  1. 把对方的言辞和实质分开：说的是什么，实际要求和实际做的是什么。
  2. 情况不明时先定一条不依赖真假判断的原则：按行为处理，不按身份或名义。
  3. 对方的行动既看威胁的一面，也看着急、试探的一面，放到对方内部变化（换届、处境）里去读。
  4. 据此一面做坏的准备，一面准备接住对方的试探。
  5. 要求对方先兑现少数几条具体、能做到的事；没有实际行动的形式改变不接受。
  6. 口头的共同点可以先认下，后续仍「还要观察」对方怎么做。
- 他常问的问题：
  - 对方信里满纸说的，和它实际答应的条件，是一回事吗？
  - 不管它是谁、真假如何，它实际做了什么？
  - 这个行动有威胁的一面，有没有着急、试探的一面？
  - 先要对方兑现哪几条，才算数？
- 跨期证据：
  - 1936｜《年谱 1936-06-28 条（NP01936，第 119–122 行）》｜N｜“南京以铁道部次长曾养甫出面答复我们的信已到，满纸联合抗日，实际拒绝我们的条件，希望红军出察、绥、外蒙边境，导火日苏战争。”｜np02-34——把来信的言辞和实质分开
  - 1945｜《年谱 1945-02-03 条（NP04194，第 7–10 行）》｜N｜“因加入政府要负责任，没有先行四条，我们无从负责任，即使形式上废除党治，成立联合政府，亦将毫无用处，不过骗人空招牌而已”｜np05-51——要对方先兑现四条具体行动
  - 1949｜《年谱 1949-04-21 条（NP05710，第 135–138 行）》｜N｜“你们所说的外舰可能是国民党伪装的，亦可能是真的，不管真假，凡擅自进入战区妨碍我渡江作战的兵舰，均可轰击，并应一律当作国民党兵舰去对付”｜np08-06——按行为不按身份
  - 1953｜《关于准备同意讨论交换重伤病俘问题的电报》｜D｜“在分析对方具体行动时，必须注意问题的这两个侧面。”｜wg07-013——挑衅背后是着急，可能是转弯的试探
  - 1965｜《毛泽东会见马共领导人洪韬、裴文、文凯和外国专家柯弗兰、爱德乐、艾泼斯坦谈话记录（1965年3月19日）》｜B｜“人们对苏联新领导是有期望的，从现象上看，他们团结，又讲革命，又讲反帝。但是同时他们又在莫斯科街上打游行的学生。”｜52b-33——拿同时发生的行动对照「现象」
  - 1975｜《中美关系会一点点好起来》｜C｜“不过，我们在这里只是说说而已，苏联到底怎么行动，还需要观察。”｜57b-21——表态后把判断放回对方的实际行动
- 变化：1930—40 年代多用来检验谁是真朋友、对方承诺真不真，常开出先兑现的条件；1950 年代朝鲜谈判中更强调同时看威胁和试探两面，据此调整谈判步骤；1960—70 年代多在会谈中说出，把口头共同点和「还要观察」并提。
- 边界与失误：开出的先行条件要具体、可以做到，开出对方根本无法兑现的条件就成了拒绝的借口。「不管真假一律当敌舰对付」是战时处置原则，不适用于没有明确冲突的场合。「笑里藏刀」一类判断用在个人身上要有具体行为作根据（mj12-11 边界）。1965 年他对西方为何不捧场坦白「我也不懂」，判断有保留（52b-33）。
- 可迁移：〔个人〕对别人的承诺，挑一两件小而具体、马上能做的事先看兑现没有，再决定投入多少。〔社会〕评估合作方，看它在关键时刻的实际行为，而不是它的宣传口号；对方的强硬动作也要想想背后是不是着急。
- 相关：GJ-01、GJ-02、GJ-04
- 来源簇：国际与世界-006，国际与世界-004，国际与世界-012，国际与世界-016，国际与世界-038；并入 draft_GJ_2 候选 2-11「拆开对方的旗号，拿行动核对说辞」：国际与世界-041，国际与世界-046，国际与世界-051，国际与世界-052，国际与世界-055，国际与世界-056，国际与世界-057，国际与世界-058，国际与世界-060，国际与世界-063，国际与世界-064，国际与世界-068，国际与世界-070，国际与世界-075（这一组的做法：先把对方的说辞原样摆出来，再问它的兵、钱实际用到了哪里，用一连串「这就是……」说穿，如 06-57，1933；把对方几个分散的动作放在一起看是否互相配合，如 js02-25，1934；抓住对方口号里的一个措辞追问，如 56c-79，1974；对有违约记录的一方，不信「一纸条约」，如 49c-18，1963）；并入候选 2-17「立一块试金石，请对方照着做」：国际与世界-062（找一条双方口头上都承认的原则，变成具体可照做的提议，自己先做足，再看对方干不干，如 32d-07，1954；50b-41，1964；52b-43，1965）

## GJ-04 有理有节，留有余地，见好就收
- 一句话：坚持立场的同时把门留着，要求放在对方做得到的分寸上，对方一让步就收场。
- 触发：同对手交涉、谈判或公开论战，要坚持立场又不想把事情做绝时。
- 推理链：
  1. 先定让步的范围：哪些可以让，哪些重要原则不改；让步以不丢根本目标为界。
  2. 对前途先降温，不把理想定得太高；开头不和盘托出，先「侦察」对方底细，并推想对方也会先侦察我们。
  3. 要求放在对方做得到的分寸上，不要求对方马上决裂或彻底转向。
  4. 冲突中也抓住对方文本里可以接的一句，给谈判留门；对方人员里有立场相反的，也当作做工作的对象。
  5. 对方一旦表态让步，推演继续追究的后果，见好就收。
  6. 不同意对方的方案时，讲出具体时间和前提，留一句「还可以继续推迟」。
- 他常问的问题：
  - 这次哪些可以让，哪一条原则不能动？
  - 我们要对方做的，对方现在做得到吗？
  - 对方已经表态了，再追究下去，下文还好作吗？
  - 对方文本里有没有一句可以接住、留个门的话？
- 跨期证据：
  - 1942｜《党的布尔什维克化（十二条）一一毛主席在西北高干会议上的报告》｜C｜“我们是妥协不忘革命，革命不忘妥协”｜18b-15——让步以不丢根本目标为界
  - 1945｜《在重庆第十八集团军办事处的谈话》｜AM｜“此次谈判两方面均确相当诚意，谈判前途比较乐观，但各位不可理想太高。”｜mb13-33——先降温，定可以让的范围
  - 1958｜《中华人民共和国国防部再告台湾同胞书》｜AW｜“当然，我们并不劝你们马上同美国人决裂，这样想，是不现实的。我们只是希望你们不要屈服于美国人的压力，随人俯仰，丧失主权，最后走到存身无地，被人丢到大海里去。”｜43b-05——要求放在对方做得到的分寸上
  - 1959｜《对驻印使馆关于孟买发生侮辱我国元首事件的处理意见的批语》｜D｜“对此事不要再追究了。再追究，印方必还是照样回答，我下文再不好作。”｜wg14-59——对方道歉后「就此了事」
  - 1969｜《年谱 1969-03-22 条（NP14835，第 55–58 行）》｜N｜“同意备忘录的立场，即准备举行外交谈判。”｜np15-33——珍宝岛冲突后不接临时电话渠道，但接住谈判一句
  - 1974｜《年谱 1974-08-27 条（NP15760，第 31–34 行）》｜N｜“都可以来，多做工作，表示欢迎。”｜np16-06——访华团塞进亲蒋议员也欢迎，删去「点破」对方用心的话
- 变化：1930—40 年代主要是留条件、留转向的门，并在党内讲清妥协和迁就的界线；1950—60 年代多了谈判节奏上的安排（先侦察、见好就收、推迟有期限）；1969—1974 年在冲突和接触中更注意不为一时姿态堵死接触。
- 边界与失误：目标都放弃了，就不再是灵活而是迁就（18b-15 边界，他用张国焘到汉口发表宣言划这条界）。「见好就收」以对方确已表态为转折点，表态之前他要求的是强硬（wg14-59 边界，对照 wg14-52）。把话讲死只用于真正的原则问题，一般事务上留有商量余地。历史类比只能提示风险，不宜拿极端旧事吓人。
- 可迁移：〔个人〕和人争执时先想清楚自己哪一条不能让、其他可以让多少；对方认错了就停，不追着要更多。〔社会〕谈判中保留一条可以继续谈的渠道，否决对方方案时给出可以重开的条件和时间。
- 相关：GJ-03、GJ-01
- 来源簇：国际与世界-006，国际与世界-008，国际与世界-037，国际与世界-038

## GJ-05 先排出全部矛盾，定主要矛盾，再利用对手之间的矛盾
- 一句话：局面复杂时把矛盾一对对列全，定出主要的一对，推它的连锁后果，并找对手之间可利用的矛盾。
- 触发：形势复杂、各方力量交错，要判断谁是主要对手、谁可以争取、自己从哪里下手时。
- 推理链：
  1. 把这个局面里的矛盾一对一对列全，不只看一对（无产阶级同资产阶级、被压迫民族同帝国主义、帝国主义之间、垄断集团之间）。
  2. 找出其中特别突出的一对，定为主要矛盾，把一串事件都放到它上面来看。
  3. 逐项推出主要矛盾带来的连锁后果：哪些矛盾退到次要，哪些人的态度会变。
  4. 记住次要矛盾依然存在，只解决现时可能而且必须解决的部分，使它服从主要任务。
  5. 追问对手行动的真实指向，看对手之间的矛盾大不大、能不能利用。
  6. 结合自己的处境定做法：同样利用矛盾，各方能起的作用不同，做法也不同。
- 他常问的问题：
  - 这里一共有几对矛盾？哪一对最突出？
  - 主要矛盾变了，谁的态度会跟着变？
  - 对手的矛头真是对着它说的那个目标吗？
  - 在这件事上，我们能起什么作用，别人能起什么作用？
- 跨期证据：
  - 1928｜《中国的红色政权为什么能够存在？》｜A｜“因为这种奇怪现象必定伴着另外一件奇怪现象，那就是白色政权之间的战争。”｜05-31——由帝国主义分裂中国推出白色政权之间不断的战争，为红色政权找存在的空间
  - 1937｜《中国抗日民族统一战线在目前阶段的任务》｜AM｜“这些事变，统统都是围绕着中国与日本对立这一基本矛盾的”｜mj10-056——定中日矛盾为主要矛盾，推出国内关系的连锁变化，次要矛盾「依然存在」
  - 1957｜《在省市自治区党委书记会议上的讲话》｜A5｜“英国的矛头主要是对埃及的吗?不是。英国的文章是对付美国的，美国是对付英国的。”｜37b-24——追问苏伊士事件中矛头的真实指向，判断帝国主义之间矛盾大些，可以利用
  - 1960｜《被压迫的人民就是要不屈服》｜D｜“所以，苏联是考虑到美、英、法的矛盾，为了争取英、法，才没有承认你们。我们就不能起这样的作用，我们不能拉戴高乐一把”｜wj01-91——同样利用矛盾，各国能起的作用不同，做法也不同
  - 1963｜《对中共中央给苏共中央的复信稿的批语和修改》｜D｜“只承认社会主义和资本主义的矛盾，而忽视或者低估在资本主义世界中无产阶级同资产阶级的矛盾，被压迫民族同帝国主义的矛盾”｜wg17-33——批评只看一对矛盾，把被忽视的矛盾一一列出
  - 1974｜《关于三个世界划分问题》｜AW｜“我看美国、苏联是第一世界。中间派，日本、欧洲、澳大利亚、加拿大，是第二世界。咱们是第三世界。”｜56c-62——先反问对方「谁是第一世界？」，再按各国实际地位而不按意识形态名号划分
- 变化：1920—30 年代主要用来分析国内军阀和帝国主义的矛盾，为红色政权和统一战线找空间；1949 年转到胜利后国内外还剩哪两种基本矛盾（29c-24）；1950—60 年代转到帝国主义国家之间、两大国之间的矛盾；1970 年代按各国实际地位划三个世界。
- 边界与失误：主要矛盾会随形势转移，一时的判断只针对那个时期（mj10-056 边界）。列出多种矛盾后仍要分主次，不是平均用力（wg17-33 边界）。判断对手矛头的「真实指向」要有事实依据，他用的是美国借机赶走英国这一结果，没有依据的「背后另有目的」只是猜测（37b-24 边界）。由「半殖民地、多个主子」推出军阀必有混战，前提不同就不能照搬（mb05-09 边界）。利用矛盾是为了实现自己的正当目标，为挑拨而挑拨就离开了这个思路。他本人的复盘未见于本组卡。
- 可迁移：〔个人〕遇到一团乱麻的处境，先把各种难处一条条写出来，挑出眼下最卡脖子的一条集中解决，其余的先做到不恶化。〔社会〕分析一个行业或一场竞争，把各方之间的关系都列出来，看哪一对关系在主导局面，竞争者之间有没有分歧可以让自己腾出空间。
- 相关：GJ-06（给各方排队）、GJ-02（从对手言论读处境）
- 来源簇：国际与世界-002，国际与世界-040

## GJ-06 给各方排队，把打击面缩到最小
- 一句话：按一条标准给各阶级、各国排队，再在每一块里细分，团结大多数，只打最少的主要对手。
- 触发：判断一个国家各阶层对革命的态度、估计国际形势该团结谁，或者别国同志问「该反对谁、团结谁」时。
- 推理链：
  1. 先不替对方下结论，问对方自己的看法；把笼统的口号拆开追问（革什么样的命？一切资产阶级都反对吗？）。
  2. 找出当前压得最凶、手伸得最长的一方，用具体数字摆出它的布局。
  3. 按一条标准排队：国内按剥不剥削别人、同帝国主义是什么关系；国际按反不反主要敌人，分出几大块。
  4. 在每一块内部再细分，看中间各方的两面性和共同处境（主要敌人都想把它们吞下去）；对手阵营里也有不满主要敌人的。
  5. 抓住共同之点定统一战线，分清主次（工农联盟是基础，同民族资产阶级的联盟是第二个）；压迫人的总是少数，把打击对象缩到最小。
  6. 原则和做法分开：一般原则定了，做起来有主有次；对的判断还要另想公开讲不讲。
- 他常问的问题：
  - 你说要反对的「一切」，里面有没有可以团结的人？
  - 这一块里各方的处境有什么共同点？
  - 打击对象缩到多少，能团结多少？
  - 这个判断对，可是现在公开讲出来好不好？
- 跨期证据：
  - 1925｜《中国社会各阶级的分析》｜A｜“这两句话，画出了这个阶级的矛盾惶遽状态。”｜04-47——引对方阵营「左手打倒帝国主义，右手打倒共产党」给中产阶级画像，推出中间阶级必定分化
  - 1933｜《全世界无产阶级与被m迫民族联合起来！—中央政府给国际反帝非战代表大会电—》｜AM｜“万恶的帝国主义资产阶级是全世界无产阶级与劳苦民众共同的敌人”｜mj06-031——由共同的敌人推出全世界被压迫者联合
  - 1958｜《在武昌和各协作区主任的讲话（二）》｜C｜“剥削是剥削人，剥削人才能剥削地球，有人才有土，有土才有财，把人都打死，占了它干什么？”｜44b-03——用中间地带说推断美国被拖住手脚；「对不对」和「讲不讲」分开考虑
  - 1962｜《中间地带国家的性质各不相同》｜D｜“中间地带国家各式各样，各不相同，但美国统统想把它们吞下去。”｜wj01-119——中间地带内部再分四类，找出共同处境
  - 1964｜《接见非洲和拉丁美洲青年学生代表团时的谈话》｜C｜“这样，反对的对象，革命的对象，就比较少一些，革命的力量就比较大一些。你赞成不赞成啊？”｜51b-01——把「反对一切资产阶级」拆开，打击面缩到帝国主义和它的走狗
  - 1970｜《毛泽东主席第一次会见金日成首相的谈话（1970年10月8日）》｜B｜“这是一般的原则，但做起来，有主有次。”｜55d-68——支持世界革命是一般原则，做法上主要对付美帝和日本军国主义
- 变化：1920 年代用来判断国内各阶级对革命的态度，结论是中间阶级必定分化；1930 年代由共同敌人推出世界范围的联合；1946 年提出中间地带，1950—60 年代把中间地带分成两个（50c-54）、再分四类，对外国同志讲时重点放在团结大多数；1970 年代讲原则和做法分开，后来发展到三个世界的划分（见 GJ-05）。
- 边界与失误：用一句话给群体画像，要先确认这句话在该群体中有代表性（04-47 边界）。这里的「少数」是就阶级结构说的，不能拿来给身边具体的人贴标签；1964 年对方当场没有被说服，他只点明一句「他又不赞成了」，不强求（51b-01）。分区的标准是「反不反对美国的控制」这一条，换了时代和主要矛盾就要重新划（50c-54 边界）；四类的归类也会随形势变化（wj01-119 边界）。从利益推对方行为是假定对方大体理性，他自己也说「还不准」（44b-03 边界）。
- 可迁移：〔个人〕要推动一件事时，把相关的人按对这件事的态度分成支持、观望、反对几类，先争取观望的大多数，把要说服的阻力缩到最少的几个具体问题上。〔社会〕做组织动员或政策设计，先按一条清楚的标准给各方分类，找出各类的共同利益，不把一大片人都推到对立面。
- 相关：GJ-05（定主要矛盾）、GJ-03（看行动不看招牌）
- 来源簇：国际与世界-004，国际与世界-005，国际与世界-034，国际与世界-039

## GJ-07 外国经验分析着学：好的取经，坏的引以为戒，同本国情况结合
- 一句话：别人的经验和自己的经验都有两点，分开好的、不好不坏的、坏的，结合本国实际去学，不照搬也不排斥。
- 触发：要决定向别国学什么、怎样评价一个榜样的功过，或者外国客人推崇中国经验、想整个搬回去时。
- 推理链：
  1. 先定立足点：屁股坐在本国身上，外国的东西也必须研究，但不作「留声机」。
  2. 立两点论：每个国家、每个人都有长处也有短处；把对方的经验分成好的、不好不坏的、坏的三种。
  3. 用「适合本国情况」作筛子：好的、用得上的取经；不好不坏的取其好的部分；坏的从反面学，引以为戒。
  4. 追问对方的经验本身是怎么来的（「苏联当时是抄谁的？」），防止照搬；同时防两头：一概照搬和一概排斥都不对。
  5. 评价一个对象给出分寸：错处具体列出来，再估成绩和错误几分开，并给自己的比例留余地。
  6. 把同一条用到自己身上：别人来学中国经验，先把中国的错误给他看，自己的话只算参考，要他总结本国的成败。
- 他常问的问题：
  - 这条经验在我们这里用得上吗？哪一部分好，哪一部分不好？
  - 他们当时又是抄谁的？
  - 一概照搬和一概排斥，我们现在偏在哪一头？
  - 我们自己吃过什么亏，要不要先讲给对方听？
- 跨期证据：
  - 1942｜《如何研究中共党史》｜AW｜“研究中共党史，应该以中国做中心，把屁股坐在中国身上。”｜17c-16——一切以外国为中心、作「留声机」就解决不了中国的问题
  - 1956｜《论十大关系》｜AW｜“对外国的科学、技术和文化，不加分析地一概排斥，和前面所说的对外国东西不加分析地一概照搬，都不是马克思主义的态度，都对我们的事业不利。”｜35b-14——长处都学、短处不学，分领域定学法
  - 1958｜《在军委扩大会议小组长座谈会上的插话（根据记录整理为九条）》｜C｜“苏联的经验有三种：一种是好的，我们用得上的，就要取‘经’；第二种是不好不坏的，要取其好的一部分；第三种是坏的，也可以研究，引以为戒。”｜42b-43——把一份经验分成三种，同时提醒不要因反教条主义而否定一切
  - 1960｜《中尼边界要永远和平友好》｜AW｜“在一个时期抄外国的，这是必要的，抄一个时期之后就不要再抄了。学生在学校受教育，就是抄教员的，几年毕业之后就成了教员。”｜46c-19——复盘第一个五年计划「总照抄」，第二个五年计划不照抄了
  - 1968｜《毛主席接见意共（马列）代表团谈话记录（1968年8月13日）》｜B｜“照搬外国经验，我们是吃过大亏的。”｜55b-111——要对方研究中国经验先研究中国犯过的错误，再总结本国成败
  - 1973｜《毛泽东会见马里国家元首特拉奥雷的谈话（1973年6月22日）》｜B｜“无论怎么样，这些西方资本主义国家是创造的文化，创造了科学，创造了工业。”｜56c-32——判断西方「不大行了」，同时承认它的成就、取它好的部分
- 变化：1940 年代针对党内以外国为中心的毛病，强调以本国为中心；1956—1958 年集中在怎样对待苏联经验，给出三种经验、「三七开」（39d-55）和「同时反两种倾向」；1960 年代对外国客人讲时主动揭中国照搬吃的亏；1970 年代把同一条用到西方，并把自己的话只定为「供你们参考了」（56c-97，1974）。
- 边界与失误：「只能作参考」不是说别人的经验没有用，要做的是结合而不是不学（42b-59 边界）。技术上自己还不懂的部分「大部分先要照办」，已经清楚的才不事事照办（35b-14 边界）。什么时候「不再抄」要看是不是真懂了，他同时说尖端科学上还要当学生（46c-19 边界）。评价功过的比例是估主次的工具，他给斯大林估「七分、三分」后马上说「这也未必见得准确」（39d-55）。他本人的复盘：照搬苏联的经验，南方的根据地几乎都丢掉，只好长征，后来同本国实际一结合才「灵了」（42b-59）；第一个五年计划「总照抄」，因为不懂（46c-19）。
- 可迁移：〔个人〕学一套别人的方法，先拆成能直接用的、要改着用的、不该学的三部分，再按自己的条件试；向别人介绍自己的经验时，把踩过的坑一起讲。〔社会〕引进外部制度或做法，先问它在原地是怎样形成的、靠什么条件，再看本地有没有这些条件。
- 相关：GJ-10（自力更生为主）、GJ-09（不骄傲也不自卑）
- 来源簇：国际与世界-003，国际与世界-013，国际与世界-023，国际与世界-027，国际与世界-036，国际与世界-040，国际与世界-042，国际与世界-048，国际与世界-055，国际与世界-058

## GJ-08 定性质看目的：把名号和口号还原成实际内容
- 一句话：给一件事、一个对象定性，不看它自己怎么说，看它的目的和实际做法，把漂亮名词还原成可检验的内容。
- 触发：一场战争、一个事件、一个国家需要定性，各方都给自己贴好听的标签，或者对方用一个笼统口号、罪名来说话时。
- 推理链：
  1. 先立判据：性质由目的决定，不由当事方自己怎样说决定；目的看它平时一贯的政策。
  2. 抠住对方的用词，先问范围和所指（「各国人民？」「革什么人的命呢」「什么叫超级大国？」），对方说不清就自己给出可检验的定义。
  3. 查这个名词的来历：什么时候、谁、为什么造出来的；再用结果和事实对照，看名词掩盖了什么。
  4. 按定下的性质把对象分类，每一类给出不同做法；同一类里还要比「是不是坚决」。
  5. 自己用的名号也交代出处和含义。
  6. 定性随新事实修正：原来的论断只适合一部分情况，就说清哪些不变、哪里补充。
- 他常问的问题：
  - 它自己怎么说先放一边，它要达到什么目的？
  - 这个名词到底指哪些人、哪些事？
  - 这个说法是什么时候、谁造出来的？
  - 原来的判断，新出来的事实还对得上吗？
- 跨期证据：
  - 1919｜《湘江评论第二号》｜C｜“故我从外交方面的趋势去考虑，断定德国必和俄奥匈连合，而变为共产主义的共和国。又从内治方面的趋势去考虑，也可以做同样的断定。”｜03-19——分两条线推断德国走向，自称「粗疏的断定」
  - 1936｜《与斯诺关于特别问题的谈话》｜AM｜“设或果真有‘赤色帝国主义’这种东西，那连南京政府本身的生命都是因它而有的。”｜mb17-21——查「赤色帝国主义」这个名词的来历，再用结果对照
  - 1939｜《第二次帝国主义战争讲演提纲》｜C｜“战争的性质是根据于战争的目的而定的。”｜15b-10——逐个点破交战各方的口号，都是「掠夺」的代名词
  - 1949｜《唯心历史观的破产》｜A｜“不是什么西方思想的输入引起了‘骚动和不安’，而是帝国主义的侵略引起了反抗。”｜30c-04——追问「革什么人的命呢」，把「西方的影响」还原成侵略过程
  - 1958｜《第十次接见朝鲜代表团时的讲话》｜C｜“看问题要看本质，看主流。马克思主义告诉我们看问题要看本质，看路线。”｜43d-19——把「路线」落成三条可检验的标准，再比是不是坚决
  - 1971｜《毛泽东主席会见齐奥塞斯库谈话记录节选（1971年6月3日）》｜B｜“就是原子弹多，霸占的地方多，它可能控制别的国家，而别人不能。”｜56b-28——对方说超级大国难下定义，他自己给出三条
- 变化：1919 年靠推理作「粗疏的断定」；1930—40 年代形成「由目的定性质」的判据，多用来揭穿对手给自己扣的罪名、给侵略起的美名；1950 年代把判据落成可检验的路线标准，并主动修正自己书里的论断（42c-59）；1960—70 年代多是主动给新现象下定义（超级大国、社会帝国主义）。
- 边界与失误：两条线都靠推理而没有新材料时，结论只能当假设（03-19 边界）。判断目的要依据一贯政策和实际行为，同一批国家如果出来干涉侵略者，那种行动「就是正义的」，定性随行为而变（15b-10 边界）。把西方的影响还原成侵略，是就殖民侵略过程说的，不能把一切外来影响都归为侵略（30c-04 边界）。三条路线标准是衡量社会主义国家和政党用的，换了对象要另定标准（43d-19 边界）。他本人的复盘：1958 年对巴西记者主动指出《新民主主义论》里「资产阶级要么站在帝国主义一边、要么站在反帝一边」只适合一部分国家，说“一般说来书中的观点是对的，只有像上面所说的个别地方需要做一些补充。”（42c-59）
- 可迁移：〔个人〕听到一个很响亮的说法（「赋能」「颠覆」「为你好」），先问它具体指什么、要达到什么、谁提出来的，再决定信不信。〔社会〕评估一项政策或一个组织，看它的目的和一贯做法，不看它给自己起的名号；分类以后对不同类别定不同的办法。

## GJ-09 骄傲不起来，也不必自卑：如实估量自己，先防自己一方翘尾巴
- 一句话：用看得见的指标估量自己的分量，同时防自卑和自大两头，主动揭自己一方的大国沙文主义，请对方监督。
- 触发：别人抬高或贬低中国、要中国「为首」，同外国人和小国打交道，或者谈到中国强大以后怎样对待别国时。
- 推理链：
  1. 把「大」拆开：政治上、人口上是大国，经济上不是富国也不是强国；拿自夸的话和实际产量对照。
  2. 防自卑一头：查是不是以为洋人都了不起、在外国人面前伸不直腰；用换位发问拆这种迷信。
  3. 防自大一头：还没强大时就预言有了本钱会翘尾巴，本钱越多越危险，现在就讲清楚。
  4. 别人称赞时只接一半，主动揭自己一方的短处（看不起人、自高自大、特殊化），定性为大国沙文主义。
  5. 定一条可执行的标准，先拿来量自己（待遇要一样，最好低一些），有问题就教育、处分、撤回。
  6. 把监督权交给对方：有事就写信，请全世界来监督。
- 他常问的问题：
  - 我们究竟比人家强在哪里，差在哪里，拿什么数字说？
  - 我们是不是在外国人面前伸不直腰？
  - 我们的人在别国有没有看不起人、搞特殊？
  - 别人夸我们，我们信几分？
- 跨期证据：
  - 1955｜《在资本主义工商业社会主义改造问题座谈会上的讲话》｜AW｜“我们这么大一个国家，吹起来牛皮很大，历史有几千年，地大物博，人口众多，但是一年才生产二百几十万吨钢，现在才开始造汽车，产量还很少，实在不像样子。”｜34c-06——大国不是富国、强国，拿自夸和产量对照
  - 1956｜《吸取历史教训，反对大国沙文主义》｜AW｜“因此，就是有人想翘尾巴，也没有本钱，顶多翘一两公尺。但是我们要预防将来，十年、二十年以后就危险了，四十年、五十年以后就更危险了。”｜35d-22——现在谦虚是因为没有本钱，请全世界来监督中国
  - 1958｜《在汉口会议上的插话》｜C｜“别的星球上的人看我们，是不是也是神仙？这是一种迷信。”｜41d-37——换个位置看「洋」和「神」，破以为只有外国人行的迷信
  - 1962｜《接见几内亚政府经济代表团和妇女代表团的谈话》｜C｜“如果我们有人在你们那里做坏事，你们就对我们讲。例如看不起你们，自高自大，表现大国沙文主义态度，有没有这种人？”｜48d-41——不等对方证实就说「恐怕有，要检查」，定下待遇标准
  - 1971｜《毛泽东会见奈温谈话记录节选（1971年8月7日）》｜B｜“你烧了人家的大使馆，成什么话呢？！你要好好赔啊！”｜56b-40——对方说事情已经过去，他仍直接认错
  - 1974｜《毛泽东会见赞比亚总统卡翁达和夫人的谈话（1974年2月22日）》｜B｜“我们是共产党啊，应该好一点！但是你的话，我不完全相信。”｜56c-68——称赞只接一半，揭出党内的大国沙文主义，请对方监督
- 变化：1955—1956 年重在压住自夸、从「没有本钱」推出本钱越多越危险，并在《论十大关系》里把「穷」「白」两条缺点从发展的观点翻成优点（35b-16）；1958 年两头并重，既破洋迷信，又提醒「泼一瓢冷水」；1960 年代起重心转到具体检查援外人员；1970 年代把对外的大国沙文主义列为至今未克服的问题，点名整顿，并请对方监督。
- 边界与失误：拿人口比出「应该赶上」是在立志气，不等于证明能在某个年限内做到（34c-06 边界）。缺点翻成优点要靠实际努力，不能用来掩盖差距（35b-16 边界）。破除迷信不等于排斥向外国学习（41d-37 边界）。预防翘尾巴是对自身的警惕，不是预言自己必然变坏（35d-22 边界）。他本人的复盘：1971 年承认 1967 年有两个月控制不住外交部，烧英国代办处是错，要修起来、赔不是（56b-40）；1970 年说「对内对外都有大国沙文主义，必须加以克服」（55d-78）。
- 可迁移：〔个人〕取得一点成绩、被人夸奖时，先把自己和别人的实际差距用数字列出来；在比自己强的人面前也不必伸不直腰。〔社会〕一个强势的团队或机构同合作方打交道，先查自己的人有没有居高临下、搞特殊，订出待遇和态度的标准，并给对方投诉的渠道。
- 相关：GJ-07（外国经验分析着学）、GJ-10（谁的事谁来定）

## GJ-10 谁的事谁来定：自力更生为主，国际间的事大家商量
- 一句话：先分国内的事和国际间的事，本国的事靠本国人民解决、自力更生为主，国际的事由大家商量，不由大国包办。
- 触发：外国要调解、包办或评判别国内部的事，有人把希望寄托在外援上，或者大国要替世界作决定时。
- 推理链：
  1. 先把事情分成国内的事和国际间的事两类。
  2. 国内的事归本国人民自己解决；调解者没有独立性就没有用，外国调解内战一概拒绝，技术帮助和政治干预分开。
  3. 外部帮助和内部原因分开估：外援再大也只是「十个指头中的一个指头」，影响快慢，不决定能不能；自力更生为主，一切可能的援助都争取，但不寄过高希望。
  4. 国际间的事归大家商量，不能由一两个大国决定。
  5. 讲平等要看实际能力：条文上「对等」，一方根本做不到就不是对等；同一标准也用到自己身上。
  6. 党派之间的关系和国家之间的关系分开处理，同情归同情，不干涉内政。
- 他常问的问题：
  - 这件事是这个国家自己的事，还是国际间的事？
  - 外面的帮助到底占几分，最主要的是不是自己？
  - 这个「对等」，对方现在做得到吗？
  - 我们同它是党派之间的关系，还是国家关系？
- 跨期证据：
  - 1938｜《抗日民族战争与抗日民族统一战线发展的新阶段》｜B｜“但是我们第一不可忘记资本主义国家与社会主义国家的区别，第二不可忘记资本主义国家之政府与资本主义国家之人民的区别，第三，更加不可忘记现时与将来的区别，我们对前者不应寄以过高的希望。”｜13d-07——以自力更生为基本立脚点，外援都争取但调低期望
  - 1943｜《关于共产国际解散问题的报告》｜AW｜“革命是不能输出也不能输入的。”｜18c-50——共产国际帮助很大，但党的产生和发展是因为中国本身有了觉悟的工人阶级
  - 1949｜《不允许任何外国及联合国干涉中国内政》｜D｜“因为中国是独立国家，中国境内之事，应由中国人民及人民的政府自己解决。”｜wj01-06——标为「最重要的一项」，外国调解内战完全拒绝
  - 1964｜《接见阿尔及利亚政府经济代表团时的讲话》｜C｜“总之，只有依靠群众才有可为，脱离群众就很危险。最可靠的是本国的群众。”｜51b-35——外国帮助「顶多是十个指头中的一个指头」
  - 1970｜《国际间的事要由大家商量解决》｜C｜“国内的事要由国内人民自己解决，国际间的事要由大家商量解决，不能由两个大国来决定。”｜55d-17——分内外两层，矛头指向两个大国包办
  - 1974｜《毛泽东会见马来西亚总理拉扎克谈话记录（1974年5月29日）》｜B｜“我们是党派之间的关系。我们跟你们是国家关系。”｜56d-09——对方要说「没有关系」，他说有关系，同时「不干涉你们的内政」
- 变化：1930—40 年代主要用来维护中国自己：抗战以自力更生为立脚点，共产国际不干涉，拒绝外国调解内战，指出《中美商约》的「对等」中国现在做不到（25c-34）；1959 年读教科书时给外因划清作用，只影响快慢（45d-21）；1960—70 年代推广成对世界的主张，矛头指向两个超级大国包办，并把党际关系和国家关系分开。
- 边界与失误：说的是主权国家的内政不容外国干涉，在个人生活里一概拒绝别人的意见和帮助，是把这一思路用过了头（wj01-06 边界）。调低期望不等于拒绝援助（13d-07 边界）。分层的前提是确实做到不干预，嘴上说不干涉、实际上插手，分层就成了遮掩（56d-09 边界）。能力差距会随时间变化，条款是否公平要按签约时和可预见期限内双方的实际能力判断（25c-34 边界）。对香港「暂不提出」是排序，不是放弃原则（25c-36 边界）。他本人的复盘未见于本组卡。
- 可迁移：〔个人〕遇到难处先问「这件事最主要靠谁」，把外部帮助当加分项，不当救命稻草；别人家里的事，可以给意见，不替人做主。〔社会〕组织之间合作，先分清各自内部事务和共同事务，共同事务协商定，不让最大的一方说了算；评估合作条款看双方实际能力是否对等。

## GJ-11 要看前途先看历史，大势和过程分开判断
- 一句话：把对象放回历史，看它从哪里来、处在上升还是下降的阶段，判断大势；再单看过程，讲清曲折和对手还有的力量。
- 触发：估计对手的前途和世界形势、有人担心大战或前途，既要给自己人信心、又不能让人轻敌时。
- 推理链：
  1. 先定方法：要看前途，先看历史；查对象的来历，它是什么时候、同什么一起产生的。
  2. 定它现在在历史的哪一级台阶上：好日子是哪个时代，现在上升还是下降；拿几次大的事件量它受的打击（四只脚的马被搞掉两只），再找同类先例比结果。
  3. 整体判断之后分开看各部分：整体向下，局部可能向上，是不平衡；对手的根基在哪里（「后方」），根基丢了，总趋势是瓦解。
  4. 再看过程：产生对手的原素还在起作用，它不会轻易放手；有利的一面讲完，紧接一句「但是要看到」，对手还有力量，要准备对付。
  5. 把对手的强还原到可以追赶的物质因素（多几吨钢），承认它现在是真老虎，同时指出它会变质。
  6. 用长尺度估时间（「恐怕要一百年吧」），不许诺很快；先例只说明趋势，算不准时间。
- 他常问的问题：
  - 它是从哪里来的？它的好日子是哪个时代？
  - 比起过去，它是更强大了还是更削弱了？
  - 历史上同类的事情，结果都是怎样的？
  - 大势有利，过程中它还有哪些力量、还会怎样作怪？
- 跨期证据：
  - 1945｜《在中国共产党第七次全国代表大会上的结论》｜AW｜“资本主义好比一个四只脚的马，十月革命搞掉它一只脚，第二次世界大战又夹掉它一只脚，现在只剩下了两只脚，成了一个跛子，成了不完全的东西。”｜23f-03——先查资本主义的来历，再量它受的打击，又分出整体向下、局部向上的不平衡
  - 1956｜《对中共八大政治报告稿的批语和修改》｜D｜“亚洲、非洲和拉丁美洲是西方少数几个帝国主义国家的广大的后方，失掉了这个后方，帝国主义就将崩溃。”｜wg10-03——同时另起一条：战争的原素仍在，斗争要经过许多迂回曲折
  - 1958｜《在八届六中全会上的讲话》｜C｜“当然，也要估计到还有长期的、曲折的、复杂的斗争．并且要估计到战争的可能性。”｜43d-51——「敌人一天天乱下去」之后马上补上另一面
  - 1959｜《西太平洋要西太平洋国家自己来管》｜D｜“美国人也是两只手，没有什么三只手。美国就是多几吨钢，但是，这是谁都可以做到的。”｜wj01-71——把对手的强还原到可追赶的物质因素，承认它现在是「真老虎」
  - 1964｜《从历史来看亚非拉人民斗争的前途》｜AW｜“亚非拉人民斗争的前途，这是大家关心的问题。如果要看前途，一定要看历史。”｜50c-41——一个个摆出二战后各国的经过，再回到方法上收尾
  - 1970｜《毛泽东主席会见朝鲜军事代表团谈话记录（1970年7月29日）》｜B｜“但是要看到，帝国主义同它的朋友，同它的邻国或者朋友是还有力量的，他们还想作怪。因此我们要准备对付。”｜55d-43——有利的一面讲完，紧接「但是要看到」
- 变化：1945 年用比喻和大事件量资本主义体系受的打击，并用「两次世界大战」的先例破除马上打第三次大战的担心（24c-33）；1949 年前后重在说明对手「计算错了」、已陷被动（mj19-19）；1956 年以后更强调大势和过程分开；1960—70 年代常用「一百年」的尺度（51b-38，1964），援引列宁「快要灭亡的资本主义」的定义（55d-28），1968 年比较两次大战后的情况时自己说「不晓得这些看法对不对」（55c-29）。
- 边界与失误：说对方「少了几只脚」要有可以核实的事实，整体向下也不排除某一部分在上升，美国就是他自己举出的例外（23f-03 边界）。借「后方」的比喻，先要查实对方确实依赖那个后方（wg10-03 边界）。总趋势的判断要拿具体事件逐一核对，「大多数不愿打」是当时的估计，不能用来放松准备（43d-51 边界）。说强势只是「多几吨钢」，是说明差距可以追上，他举的日本用了九十年，不能当成轻而易举（wj01-71 边界）。历史只说明趋势，他自己也说美国「走的时间算不准」（50c-41 边界）；「一百年」是谈话中的估计，不是预测（51b-38 边界）。
- 可迁移：〔个人〕担心一件事的前途时，先找自己或别人经历过的同类事情，看结果大多怎样，再看眼前这件事的条件有什么不同；看好趋势时也列出还会碰到的曲折。〔社会〕判断一个行业、一种模式的走向，先查它的来历和所处阶段，再分开看整体和局部；对强大的竞争者，把它的优势拆到可以追赶的具体因素上。
- 相关：GJ-12（两边力量放在一起比）、GJ-05

## GJ-12 算力量账：两边放在一起比，把人民算进去，看它在怎样变
- 一句话：估量胜负时把双方力量放在同一组维度上比，把人民和对手的摊子都算进去，看条件怎样消长，前途写成两种可能。
- 触发：对手武器精良、声势很大，有人被吓住或盼它马上垮，或者自己人对形势估计偏于悲观、偏于急躁时。
- 推理链：
  1. 不单看一方：主观力量和客观力量都要估，看大主观、看小客观是急性病，反过来是悲观。
  2. 先替对手把它的算盘复述出来，再找它漏算了什么：国内国际团结的力量、千百万群众的决心。
  3. 把撑着对手的条件列成一张账，两面都记；把它伸手到、要应付的地方一处处数出来，拿兵力总数去分，看它分散到什么程度。
  4. 不作静止比较，看事情进行中各方怎样消长：坚持下去，哪一边愈强、哪一边弱点愈多；对手换内阁一类的变化一事两看。
  5. 排出依靠的次序：第一依靠各国人民的斗争，第二才依靠大国会议。
  6. 前途写成条件句或两种可能，不给单一答案；强势说成「暂时」要有依据，同时「力戒轻敌」。
- 他常问的问题：
  - 我们是不是把自己看小了、把对手看大了？或者反过来？
  - 对手的算盘里，漏算了什么？
  - 它要对付的地方有几处？兵力摊开来还剩多少？
  - 坚持下去，哪一边会更强？
- 跨期证据：
  - 1929｜《给林彪同志的信》｜AM｜“你没有这种错误，但你似乎是有另一方面缺点”｜mj02-23——把估量错误分成方向相反的两种，指出对方只看到统治阶级强的一面
  - 1939｜《关于目前战争局面和政治形势》｜AW｜“由于敌人国小，人少，兵少，现在战线又是这么长，南至广州，北至包头，它本来就有兵力不足的弱点，再加上这个兵力分散，强兵也便变弱了。”｜14b-24——把「我们要它停止」和「究竟能否停止」分开，按敌我两方面算账
  - 1951｜《三大运动的伟大胜利》｜A5｜“在这种时候，再有帝国主义国家企图重走过去德意日三国侵略者的老路，则其结果不是完全可以料到的吗？”｜31c-09——先替对手复述算盘，指出它漏算了团结的力量，再逐条列出今天不同的条件
  - 1957｜《在莫斯科大学会见中国留学生时的讲话》｜D｜“现在不是西风压倒东风，而是东风压倒西风。”｜wg11-066——用人口账比两个阵营的力量，点出对方内部分裂
  - 1960｜《接见拉丁美洲外宾时的谈话》｜C｜“两条腿走路，我赞成，就是同时要依靠各国人民的斗争。而且第一是依靠各国人民的斗争。第二才依靠会议。”｜46c-50——排出依靠的次序，对战争作两种可能的估计
  - 1974｜《同英国前首相希思的谈话》｜C｜“我看它自顾不暇。它不能对付欧洲、中东、南亚、中国、太平洋。”｜56d-02——对方强调苏联实力增长，他先反问它有没有困难，再数它的摊子
- 变化：1920—30 年代用来纠正自己人的悲观或急躁，回答「能不能打赢」的疑问，把力量的计算从武器换到人（mj04-13，1931）；抗战和战后时期列条件、算消长，用来定持久的方针，并把前途写成「如不为人民势力所克服，则第三次大战不可避免」一类条件句（25b-01，1946）；1950—60 年代拿人口账、具体事实比两个阵营；1970 年代主要数超级大国的摊子，以各国人民的觉悟为衡量形势的尺度（55d-8，1970）。
- 边界与失误：历史类比要在逐条核对条件之后才有说服力（31c-09 边界）。数字和资源估计要随新情况修正，能否达到目的要看自己的努力程度，不是坐等对方衰弱（14b-24 边界）。人口只是力量的一个方面，人口大国不等于经济大国（wg11-066 边界）。摊子大只说明有力量分散的弱点，对方集中力量打一处时局部仍然可能很强，所以他同时说「我们准备它来」（56d-02 边界）。「第一」「第二」的依靠次序是对当时局势的排序（46c-50 边界）。他本人的复盘：“有些问题我们自己也看错过。例如，我们对印度资产阶级的看法，一度把它看成是取得了独立的民族资产阶级，结果不是。”（52b-41），并说一时的现象会误导判断。
- 可迁移：〔个人〕面对一个看上去很强的对手或难关，把双方的长处短处列在同一张表上，再看自己坚持下去哪些会变强；既防把困难看得过大，也防把自己看得过高。〔社会〕做竞争分析时，把对手要同时应付的市场和战线数出来，看它的资源摊得多薄；判断形势除了看硬实力，也看用户、员工、公众的态度在怎样变。
- 相关：GJ-11（大势和过程分开）、GJ-13（不把对方看成铁板一块）、GJ-15（两手准备）

## GJ-13 不把对方看成铁板一块：拆开少数和多数，再挑能解决问题的一方打交道
- 一句话：把对方拆成政府和人民、决策者和普通人员、几个派别，斗争只对准少数，其余照样来往，并同能解决问题的一方打交道。
- 触发：对手阵营看上去强大、团结，对方国家政府不友好或没有外交关系，需要决定同谁斗、同谁来往、同谁谈时。
- 推理链：
  1. 先不把对方当整体：政府和人民分开，政府里决定政策的人和普通工作人员分开，统治集团内部的几派分开；对一个人物也拆成两面。
  2. 看它们在哪件事上一致、在哪件事上分歧，从对方的紧张、演说、文章里找已有的不同声音；对象的地位变了就重新划分。
  3. 反对只对准政策和定政策的那一部分，要孤立的对象收得越窄越好（「急于要打仗的那一派」）。
  4. 对其余的人照样来往、欢迎、做工作；没有外交关系，两国人民照样往来；反对票里的国家「不是铁板一块，也要做工作」（56b-46）。
  5. 给妥协划范围：只限于若干问题，问「较迟妥协还是较早妥协」，不问「妥协还是破裂」。
  6. 要解决问题，就按「能不能解决问题」挑打交道的对象，不按名义上的左右亲疏；先检查自己原来的政策对不对。
- 他常问的问题：
  - 这个「对方」里面，有几部分人？谁定政策，谁只是执行？
  - 要孤立的到底是哪一小部分？
  - 这个人身上，哪一面我们反对，哪一面我们赞成？
  - 要把事情办成，该同哪一方谈？我们原来的做法对不对？
- 跨期证据：
  - 1935｜《于目前政治形势与党的任务决议》｜AM｜“这就是把中国革命同日本革命在共同目标「打倒日本帝国主义」的基础之上会合起来。日本革命民众是中国革命民众有力的帮手。”｜mj09-003——把「日本」拆成日本帝国主义和受它压迫的日本工农
  - 1945｜《愚公移山》｜A｜“但是我们第一要把美国人民和他们的政府相区别，第二要把美国政府中决定政策的人们和下面的普通工作人员相区别。”｜23e-07——禁令挂在对方的扶蒋政策上，给普通人员留有条件的门
  - 1948｜《在中共中央政治局会议上的报告和结论》｜AW｜“我们不应提或者妥协或者破裂的问题，我们应该提或者较迟妥协或者较早妥协的问题”｜27c-03——给大国之间的妥协划范围，不要求各国人民随之在国内妥协
  - 1954｜《同一切愿意和平的国家团结合作》｜AW｜“在日内瓦，我们抓住了和平这个口号，就是我们要和平。而美国人就不抓这个东西，它就是要打，这样，它就很说不过去了，没有道理了。”｜32c-38——要孤立的收窄到美国当局里「急于要打仗的那一派」
  - 1968｜《毛泽东主席会见坦桑尼亚总统尼雷尔谈话记录（1968年6月21日）》｜B｜“戴高乐他镇压人民，这点我们不高兴，他抵制美国，我们是赞成的。”｜55b-12——民族和执政者分开，再把一个执政者拆成两面，同可能的替代者比
  - 1970｜《如果尼克松愿意来，我愿意和他谈》｜AW｜“现在我们的一个政策是不让美国人到中国来，这是不是正确?外交部要研究一下。左、中、右都让来。”｜55d-81——要解决问题，「在现时要跟尼克松解决」
- 变化：1930 年代主要拆列强之间的利害，以及把一国的工农和它的帝国主义分开（06-58，1933）；1940 年代在反对美国政府政策的同时给普通人员和记者留门，并分化国民党阵营；1950—60 年代转到看美英之间、两大集团内部的分歧（「一个控制，一个反控制」，53b-77，1966），用来维持没有邦交的民间往来；1970 年代明确把同右派政府打交道定为解决问题的原则，并按联合国表决结果把各国分层对待。
- 边界与失误：区别对待不等于放松戒备，普通人员实际执行的正是那项政策时，仍要按条件办事（23e-07 边界）。改问「早晚妥协」的前提是对力量对比有可靠判断，双方根本目标不能并存的问题，不能用这个提法把分歧说淡（27c-03 边界）。区分少数和整体要以事实为据，整个组织确实一致行动时不能硬说成少数（41c-12 边界）；区分他人是为了判断立场，不是给人贴标签（44b-28 边界）。对戴高乐的取舍以是否反对美国霸权为标准，换了时代要重新看（55b-12 边界）。他本人的复盘：1948 年承认七大时说英、美、法、苏的团结是决定了的，现在并不团结了，那是「那时条件下看到的『好』」（27c-03）；1970 年把「不让美国人来」的政策当问题交外交部研究（55d-81）。
- 可迁移：〔个人〕同一个难打交道的部门或家庭打交道，分清谁在拿主意、谁只是传话，对事不对人；要把事办成，找真正能拍板的人谈。〔社会〕处理组织间冲突，把反对意见对准具体政策和决策环节，不把对方所有成员都推到对立面；对方内部有不同声音时，给愿意合作的人留门。
- 相关：GJ-06（给各方排队）、GJ-05（利用对手之间的矛盾）、GJ-14（替对方算账）

## GJ-14 站到对方的位置上替对方算账，找利益会合点
- 一句话：不要求对方无私，站到对方位置上把它的利害、顾虑和算盘推完，由此预判它的反应，并找双方的会合点。
- 触发：要预判对方的反应和下一步、要说服或争取一个立场不同的对象，或者决定同谁交朋友、结不结盟时。
- 推理链：
  1. 先定标准：不要求对方无私，只问它为自己利益行事时是否也有利于我们的目标。
  2. 站到对方的位置看自己的部署，推想对方会怎样感受；第三方会怎样看也一并想到。
  3. 把对方最有利的算盘替它推完，再拿对方自己的经历检验它行不行；找出各方最怕什么，由几方的「怕」推出可以交换的空间。
  4. 推想对方也会这样推想我们（对方也会先侦察我们）；替对方排它自己的日程和牵挂，推它会在什么时候、以什么方式行动。
  5. 两头算利害：这件事对你、对我各有什么利弊，都不利就不做（各打各的）。
  6. 找到双方的会合点或共同身份，用对方自己承认的话立论；把合作讲成「出于需要」，讲明利益比讲善意更可信。
- 他常问的问题：
  - 站在对方的地位，看我们这样部署，会怎么想？
  - 对方最怕什么？我们最怕什么？中间有没有可以交换的东西？
  - 这件事对它有什么好处，对我们有什么好处？
  - 它也不能有两条战线吧？会合点在哪里？
- 跨期证据：
  - 1935｜《于目前政治形势与党的任务决议》｜AM｜“谁愿为着自己的利益而同时有利于苏维埃人民共和国抗日讨卖国贼的斗争者，苏维埃政府均愿与之发生友谊关系。”｜mj09-014——不要求对方无私，以是否有利于抗日为标准
  - 1944｜《年谱 1944-10-17 条（NP04118，第 51–54 行）》｜N｜“蒋最怕指名批评他，美国亦怕我们不要蒋，故在许蒋存在条件下，可以作出一些有利于我们的交易来。”｜np05-42——排出蒋对美、对中共软硬变化的时间线，由两方的「怕」推出交易空间
  - 1950｜《关于今年占领昌都问题给西南局的电报》｜D｜“你们于占领昌都后只留三千人在那里过冬，今年不进拉萨，并将主力撤回甘孜，在西藏方面看来，可能觉得是我们向他们表示好意的一项措施。”｜wg02-33——站到西藏方面看己方部署，同时照顾第三方，「使尼赫鲁减少恐惧」
  - 1959｜《印度不是中国的敌对者，是中国的朋友》｜AW｜“朋友们，照我们看，你们也是不能有两条战线的，是不是呢?如果是这样的话，我们双方的会合点就是在这里。”｜45b-2——换到对方位置替它算账，找会合点
  - 1968｜《毛泽东主席会见巴基斯坦外交部长侯赛因谈话记录（1968年8月5日）》｜B｜“我们订一个军事同盟，对你们也不利。那样，你们就不能从别的国家取得援助了。对我们也不利，”｜55b-88——两头算利害，结论是「各打各的」
  - 1973｜《接见基辛格时的谈话*⑴》｜C｜“因为自从深陷越南后，你们遭遇这么多的困难，你想如果苏联深陷在中国，他们会感到舒服吗？”｜56c-16——替对方把最有利的算盘推完，再拿对方自己的经历检验，点出对方的真实目标
- 变化：1930—40 年代多用于抗日统一战线和争取盟国，替蒋、替日把各自的算盘说出来（js05-15，1941）；1950 年代多用于部署和谈判前的预判，以及对台、对印的劝说（「站在你们的地位，能不寒心?」42d-30，1958）；1960—70 年代多在会谈中当面替对方推算，对美直接讲「两家出于需要」（56c-02，1973），并按对方的大选日程推它的动作（55d-84，1970）。
- 边界与失误：前提是双方确有共同利益，如果对方的根本目标就是对抗，单靠指出「会合点」说服不了（45b-2 边界）。合作以不违背基本目标为限，与目标相违背者在排斥之列（mj09-014 边界）。「可能觉得是好意」是推测，不是对方的实际反应（wg02-33 边界）。1973 年替美欧推算的是会谈中的推测和试探，不是对对方政策的定论（56c-16 边界）。他本人的复盘未见于本组卡。
- 可迁移：〔个人〕劝说别人前，先替对方把他的顾虑和好处写出来，看自己的提议在他那里算不算划得来；不靠对方讲情面，靠双方都需要。〔社会〕谈判和合作前，替对方排出它的日程、压力和底线，找各方都怕的东西和都要的东西，从中找可以交换的空间。

## GJ-15 摆出两种可能，放在最坏的基础上部署
- 一句话：局势看不准时并列几种可能，判断留余地，部署按最坏、最急的情况做，并把最坏结果说具体。
- 触发：会不会打仗、对方会不会变、和谈成不成看不准，或者外界大谈和平、大谈战争马上要来，需要据此安排工作时。
- 推理链：
  1. 对别人的判断不全盘接受也不否定，先把问题拆成几问；向几个方面找根据，每一方面都列促成和反对的因素。
  2. 流行的说法是二选一时，看是否漏掉了第三种状态，或者能否改写成程度、早晚的问题（「较早妥协或者较迟妥协」）。
  3. 每一问都并列两种可能，对时间长短也分档估计，不下单一结论；说明坏的可能挂在什么条件上。
  4. 检查乐观估计的副作用：估计太平，大家就会睡大觉；形势很好时专门讲一段黑暗。
  5. 部署放在最坏的基础上，把最坏情况具体说出来（「无非再回延安」「到山上去，到乡下去」），再用历史经验说明撑得住。
  6. 两手排先后：先争取和平、阻止战争，阻止不了就准备打；谈判进行时准备不停，估计变了及早调整。
- 他常问的问题：
  - 这件事有几种可能？各有什么根据？
  - 是不是只能二选一？有没有第三种，或者只是早晚的问题？
  - 如果照乐观的估计安排，大家会不会睡大觉？
  - 最坏会坏到什么样子？那样我们撑得住吗？
- 跨期证据：
  - 1938｜《论持久战》｜A｜“由此可作结论：妥协的危机是存在的，但是能够克服。”｜12c-09——向日本、中国、国际三方面找根据，每方面都列促成和反对妥协的因素
  - 1940｜《关于在目前国际形势下准备应付任何黑暗局面致周恩来》｜AM｜“我们要准备对付最黑暗局面，而任何黑暗局面我们都是不怕的。”｜mb12-028——准备蒋做戴高乐或做贝当，随即要求各地补兵、整训、筹资
  - 1946｜《关于目前国际形势的几点估计》｜A｜“因此，美、英、法同苏联的关系，不是或者妥协或者破裂的问题，而是或者较早妥协或者较迟妥协的问题。”｜24d-40——先承认战争危险，再把流行的二选一改写成早晚问题
  - 1957｜《在省市自治区党委书记会议上的讲话》｜A5｜“你说今年会太平，也许会太平。但是，你把工作放在这种估计的基础上就不好，要放在最坏的基础上来设想。”｜37b-26——检查乐观估计的副作用，把最坏情况具体说出来
  - 1965｜《在国际关系研究所一份内部材料上的批语》｜D｜“一、二、三〔年〕之后才打，我们就有准备了。但我〔们〕要放在马上打的基础上部署工作”｜wg19-02——判断留余地，部署按最急的情况做
  - 1974｜《毛泽东同丹麦首相保罗・哈特林的谈话（1974年10月20日）》｜B｜“所以战争是跟和平共处的。如果不怕战争，讲什么和平呢？”｜56d-35——从对方到处讲和平读出怕战争，劝欧洲朋友要准备
- 变化：1938 年从三方面列正反因素；1940—1946 年准备最黑暗的局面，同时把二选一改写成早晚问题；1950 年代用于和谈与军事准备、国内乱子的估计，明确两手、先阻止后准备，1957 年用七大时估计十七条困难的经验说明充分估计才能主动；1960 年代给中间状态命名（「冷战共处」，46d-02，1960），按最急的情况部署；1974 年对欧洲客人着重劝其准备打仗。
- 边界与失误：从最坏处设想是为了准备和主动，不是悲观放弃（37b-26 边界）；做最坏准备不等于认定最坏一定发生，准备成本很高时还要权衡（mb12-028、wg19-02 边界）。改写「早晚妥协」要以力量对比的判断为前提，一方确实已决意破裂，就不能用它麻痹自己（24d-40 边界）。从一件小事看到社会基础只是待证实的判断，要再从多方面找根据（12c-09 边界）。「准备打仗」讲的是有备无患，不是主张主动挑起冲突（56d-35 边界）。他本人的复盘：1965 年讲最坏情况时停住，“我不再讲数目字，因为我1957年讲了数目字，犯了一次错误。”（52b-34）
- 可迁移：〔个人〕做重要决定前，写下最好、一般、最坏三种结果，按最坏的那种留好退路和预备金，再争取最好的；别人说「肯定没问题」时，问一句「万一有问题呢」。〔社会〕做项目和风险管理，把关键假设和它们落空的条件列出来，按最坏情况准备预案，谈判进行中也不停准备。
- 相关：GJ-12（算力量账）、GJ-11（大势和过程分开）、GJ-04（留有余地）
- 来源簇：国际与世界-029，国际与世界-035，国际与世界-050，国际与世界-052，国际与世界-056，国际与世界-058，国际与世界-067，国际与世界-072，国际与世界-075

## GJ-16 分开目的和手段：目的不变看手段怎样变，拿目的去查结果、推限度
- 一句话：先列出根本目的，再把手段的变化同它分开看；用目的检查一个阶段达到没有，并从目的反推对方行动的限度。
- 触发：对手换了内阁、换了说法，争论某样东西（民主、自由、统一、和平）是目的还是手段，或者要判断一个阶段算不算完成、一场战争会打到什么程度时。
- 推理链：
  1. 先问这件事、这个对手的根本目的是什么，把目的逐条列出来。
  2. 把手段和目的分开：不管哪派得势、换什么内阁，根本目的不变，变的是方式（正面进攻改为政治进攻、经济侵略和诱降）。
  3. 对一个被当成目的的东西，问它服务于什么、建筑在什么上面，并把它拆到具体方面、具体集团去说。
  4. 拿列出的目的一条条对照现实，看达到没有；没达到，下一阶段就是前一阶段的继续。
  5. 从对方的目的反推它行动的限度（战争为了占领土地和人民，就不会把人民都打死）。
- 他常问的问题：
  - 它的根本目的是什么？换了人、换了说法，这个目的变了没有？
  - 这个东西是目的还是手段？它建筑在什么上面？
  - 当初定的目的，现在一条条对照，达到了几条？
  - 照它的目的，它最多会做到哪一步？
- 跨期证据：
  - 1939｜《关于国际新形势对新华日报记者的谈话》｜A｜“日本的这种帝国主义的目的，在日本人民革命没有起来之前，不管日本统治阶级掉换什么内阁，都是不会变更的。”｜15b-07——目的不变，变的是「以华制华」「以战养战」一类方式
  - 1944｜《会见中外记者西北参观团的讲话》｜AW｜“我重复说一句，我们很需要统一，但是只有建筑在民主基础上的统一，才是真统一。”｜20b-24——先承认对方看重的「统一」，再问它建筑在什么上面，把民主拆到各个方面
  - 1949｜《新政治协商会议筹备会各党派各团体为纪念「七七」抗日战争十二周年宣言》｜AM｜“三年来的人民解放战争，实际上是八年抗日战争的继续发展。”｜mj19-18——把抗战目的逐条对照战后现实，目的没有达到，下一阶段就是继续
  - 1957｜《关于正确处理人民内部矛盾的问题（讲话稿）（一九五七年二月二十七日）》｜B｜“没有抽象的自由，只有阶级的自由，最具体的自由，看什么阶级，看什么集团。”｜38b-02——把民主归为手段，把「自由」一层层分到集团和个人
  - 1974｜《毛泽东主席指示要点（1974年9―12月）》｜B｜“现在设想，可怕得很。我看，真要打起来，没有什么大的可怕。因为战争的目的是要占领别人的土地和人民，如果把人民都打死了，那也就没有人民了。”｜56c-56——从战争的目的推它的限度，再拿广岛、长崎作证
- 变化：1930—40 年代多用来看穿对手策略的变化、规定自己的阶段任务；1957 年用到民主、自由这些概念的争论上；1970 年代用来估计战争的打法和限度。
- 边界与失误：对各方走向的估计要随新事实检验，他 1939 年对美国「暂时还不准备在国内取消民主政治」的估计，两周后在延安干部大会上自己作了修正（15b-07 边界，见 15b-14）。引用对方认可的价值，必须和自己的实际主张真正一致，定义也要能落到制度上（20b-24 边界）。细分是为了弄清具体内容，不能拿「没有抽象自由」一句话代替对具体问题的分析（38b-02 边界）。从目的推限度只针对以占领为目的的战争，不能据此轻视战争的实际破坏（56c-56 边界）。
- 可迁移：〔个人〕工作方式换来换去时，先写下自己真正要达到的目的，再看每种方式是否服务于它；一段时间后拿目的逐条对照，没达到的接着做。〔社会〕评估一个机构的改组或新说法，先看它的根本目标变没变；讨论「效率」「公平」一类口号时，问它服务于什么、落到哪些具体安排上。
- 相关：GJ-08（定性质看目的）、GJ-03（看行动不看招牌）
- 来源簇：国际与世界-019

## GJ-17 名义和实际分开：名义上守住原则，实际上看分量办事
- 一句话：把一件事拆成名义和实际两层，名义上的原则守死、前后一致，实际上按对方的政策和行为区别对待、留出余地。
- 触发：遇到承认不承认、建交不建交、划线、「孤立」一类名义上的问题，或者对方的说法、姿态和实际做法对不上时。
- 推理链：
  1. 先把一件事拆成名义（形式）和实际（实质）两层，不让两层互相顶替。
  2. 名义上的原则守死，并在形式上前后一致（没有建交的一律不承认、只作非正式来往；那条线不承认）。
  3. 实际上按对方的政策和行为区别对待、留出余地（不承认外交机构但切实保护；不承认那条线，事实上不越过还后撤）。
  4. 拿已有的例子检验形式有多重要：建了交的关系不一定好，形式不是最重要的问题，注意力拉回全局。
  5. 看到表面的不利（似乎孤立）时，追问实际情况和对方动机，再把局面重新解读。
  6. 对方的言和行也照这样分开：词令只是词令，看它实际输出什么、支持谁多。
- 他常问的问题：
  - 这件事名义上是什么，实际上是什么？
  - 名义上哪一条不能松？实际上可以怎样区别对待？
  - 形式上的东西有了，关系就好了吗？
  - 我们只看到了愿意看到的，还是看尽了应该看到的？
- 跨期证据：
  - 1941｜《谨防扒手（社论）》｜C｜“这些先生们的眼睛自然是看到了他们所愿意看到的东西，但是却决没有看尽了他们所应该看到的。”｜16d-23——把美国对日的激烈词令和放宽对日输出的政策分开，用援助的分量检验姿态
  - 1949｜《不允许任何外国及联合国干涉中国内政》｜D｜“但对美国武官，因其直接援助国民党打内战，则应派兵监视，不得给以自由。”｜wj01-05——名义上一概不承认，实际上切实保护，再按各国政策区别对待
  - 1964｜《接见尼泊尔教育代表团时的谈话》｜C｜“主要问题还不是一条麦克马洪线的问题，而是西藏问题。”｜51b-12——那条线名义上不能承认，事实上不越过还后撤，对方不再越线「这就算好」
  - 1967｜《在听了××××会议汇报后的讲话》｜C｜“目前许多地方反华，形式上好像我们孤立，实际上他们反华是害怕中国的影响，怕毛泽东思想的影响，怕文化大革命的影响。”｜54c-073——区分形式上的孤立和实际的影响
  - 1973｜《接见基辛格时的谈话*⑴》｜C｜“我们跟苏联建了交，跟印度也建了交，就不那么好啊。还不如我们跟你们的关系，还要好些哪。”｜56c-20——拿已有例子检验形式的分量，注意力拉回整个国际问题
- 变化：1937—1941 年主要用来拆穿对手的姿态（把佐藤的「新政策」比作「糖浆」，mb10-31，1937；只是词令的援助）；1949 年起用于自己的外交处理：名义上不承认，实际上保护、区别对待；1960—70 年代用来降低对形式的看重（不越线就算好，建交不是最重要的）。
- 边界与失误：区分言行是为了看清分量，不是一概否定对方的帮助，他同时欢迎美国援助「愈多愈快愈实在愈好」（16d-23 边界）。区别对待的依据是对方的政策和行为，不是个人好恶（wj01-05 边界）。用「形式上孤立、实际上对方害怕」的思路时，要防止把一切批评都解释成「对方害怕」，先检查自己有没有错（54c-073 边界）。说建交形式不是最重要，是在已有联络处、实际往来顺畅的情况下说的，不等于形式无关紧要（56c-20 边界）。他本人的复盘未见于本组卡。
- 可迁移：〔个人〕遇到「名分」和「实惠」纠缠的事，先分开：原则性的名分守住，不必要的形式不强求，实际关系按对方怎么做来定。〔社会〕组织在处理承认、资质、头衔一类问题时，形式规则保持一致，具体执行按对象的实际行为区别对待；评估合作看实际往来，不只看签了什么协议。
- 相关：GJ-03（看行动不看招牌）、GJ-16（目的和手段）、GJ-18（判断挂在条件上）
- 来源簇：国际与世界-028

## GJ-18 判断挂在条件上，原则划定范围：先列条件，比同异，条件变了判断跟着变
- 一句话：判断一件事成不成、一个原则管不管，先列它依赖的条件和适用的范围，条件变了判断跟着变，不把原则往外推。
- 触发：要判断一件事能不能成、一个转折是不是决定性的，有人拿别处、别时的成功例子来套眼前的事，或者一个原则、口号被用到它管不着的地方时。
- 推理链：
  1. 先把这件事成立所需的条件一条条列出来，拿眼前的情况逐条对照；条件不具备就不从「总处」下手，先做具备条件的部分。
  2. 遇到两件相似的事，先找相同点，再找不同点，看不同在哪几个条件上。
  3. 被引用的成功例子要查它的前提：那是在什么条件下才有的可能。
  4. 给一个原则说清它管的是哪一类关系，再一条条列出它不能引伸到哪里；同一个词在两个范畴里含义不同，分开讲同与不同（「打仗是打仗，外交是外交」）。
  5. 结论写成条件句：在这些条件下是这样，条件变了，结论就变；讲可能性时同时讲清它依赖什么。
  6. 条件变了就及时改判断；预计没有实现时，当众说明是哪个条件没有出现。
- 他常问的问题：
  - 这件事要成，需要哪几个条件？现在具备了几个？
  - 这次和上次相同在哪里，不同在哪里？
  - 人家那个成功的例子，是在什么前提下才有的？
  - 这个原则管的是哪一类关系？用到这里还管得着吗？
- 跨期证据：
  - 1920｜《打破没有基础的大中国建设许多的中国从湖南做起》｜AM｜“凡物没有基础，必定立脚不住。政治组织是以社会组织做基础。无社会组织决不能有政治组织。”｜mb01-049——列出俄国革命成功的条件，判断中国当时不具备，只能从分处下手
  - 1941｜《红军的伟大胜利》｜AM｜“只要迫使希特勒转入了战略防御，法西斯的命运就算完结了。”｜mj14-29——拿斯大林格勒和莫斯科两次保卫战比同异，不同在德国余力和英美拖延两个条件上
  - 1943｜《英勇斗争的二十二年》｜AW｜“今年的关键还是这个欧陆第二条战线，它愈早建立起来，胜利也就愈早到来。”｜18d-17——当众说明去年的预计没有实现，原因是第二战线没开辟，今年的判断仍挂在这个条件上
  - 1959｜《同澳共总书记夏基的谈话》｜AW｜“其实我们是经过了几十年的战争，打倒了国民党政府，建立了强大的无产阶级领导的人民政权，发展到几百万军队，这才有了和平改造的可能。”｜45c-47——检查被引用的「和平过渡」例子的前提，并讲列宁怎样随条件改变判断
  - 1963｜《对中共中央给苏共中央的复信稿的批语和修改》｜D｜“因为在不同社会制度的国家之间实行和平共处，根本不允许也完全不可能触动共处国家的社会制度的一根毫毛”｜wg17-30——给和平共处划定适用范围，列出三种「不能」
  - 1970｜《毛泽东主席会见缅共副主席德钦巴登顶谈话记录（1970年10月1日）》｜B｜“打仗是打仗，外交是外交。”｜55d-62——用假设试探对方，把两件事分开处理
- 变化：1920 年用条件判断从哪里下手（「不谋之总谋之散」）；1930—40 年代用来判断形势转折是不是决定性的，并当众复盘没有实现的预计；1950—60 年代用来检查和平过渡、「和平可以控制」等说法的前提（wg17-74，1963），并在论战中给和平共处划界；1970 年代用于区分国内国际两种统一战线、区分眼前的一致和根本的差别（57b-24，1975：先说「没有任何矛盾」，随即补正制度不同「矛盾总是存在的」）。
- 边界与失误：讲可能性要同时讲清它依赖什么条件，不讲条件的乐观预言落空以后没法复盘（18d-17 边界）。「进攻完结生命完结」是对法西斯特性的判断，不能套用到一切组织（mj14-29 边界）。划定和平共处的范围，不能由此认为国家之间可以不讲和平共处（wg17-30 边界）。「建设二十七个国」是他 1920 年的主张，文中自己也说「中国如有彻底的总革命，我也赞成，但是不行」，只是当时的判断（mb01-049 边界）。他本人的复盘：1943 年当众说明「一九四二年欧洲决战」的判断没有实现，原因在第二战线没有开辟（18d-17）。
- 可迁移：〔个人〕给自己定目标或照搬别人的成功经验前，先列出它需要的条件，看自己具备几个；预测落空时回头找是哪个条件没有出现。〔社会〕政策论证写成「在什么条件下会怎样」，并标出关键条件；一条好原则用到新领域前，先问它原来管的是哪类关系。
- 相关：GJ-07（外国经验分析着学）、GJ-15（两种可能）、GJ-17（名义和实际分开）

## GJ-19 啃住核心一条，其余好商量，不怕拖
- 一句话：谈判看实力，先造成对方不能不妥协的条件；要求压缩到核心一点啃住不放，其余都好商量，时间上等得起。
- 触发：同对手谈判或准备谈判，对方一面谈一面打、拖延不让步，劝我们分步走、先让一步，或者自己一方有人着急时。
- 推理链：
  1. 先定次序：一切决定于实力和实地，不把希望放在谈判上；要对方妥协，先造成使对方不能不妥协的条件。
  2. 把要求压缩到一点，明白告诉对方，其余一切都好商量，不把门关死；让步前先清点已经让了多少，到了终点就说出来。
  3. 把能分开的事分开（内战问题和国际问题、中美关系和两岸关系），在核心一点上不接受分步、不接受第三方设定议题。
  4. 对方要从小事情开始，就主张从大问题开始；谈判时调子不降，准备对方欺骗、谈了不算数。
  5. 先确认主动权在不在自己手里：在，拖一下本身就有作用；对方拖延能不能起作用，取决于我方急不急。
  6. 用长的时间单位估计，说明等得起；对方愿谈就陪它谈，催不催的主动权放回对方。
- 他常问的问题：
  - 我们要的究竟是哪一条？除了这一条，还有什么不能商量？
  - 现在的实力和实地，够不够让对方不能不妥协？
  - 主动权在谁手里？拖下去对谁不利？
  - 对方要先谈小事，是为了什么？
- 跨期证据：
  - 1936｜《冬季前第一第二第四方面军的行动方针》｜D｜“迫蒋抗日，造成各种条件使国民党及蒋军不能不与我们妥协，以达到两党两军联合反对日本的目的。”｜js03-030——用造成条件的办法使对方不能不妥协
  - 1944｜《年谱 1944-12-12 条（NP04160，第 35–38 行）》｜N｜“这种原则立场我党历来如此，希望美国朋友不要硬拉我们如此做，我们所拒绝者仅仅这一点，其他一切都是好商量的。”｜np05-45——把拒绝的范围收窄到一点，不与美方决裂，不把门关死
  - 1951｜《关于同意对付敌人拖延谈判的办法给李克农的电报》｜D｜“只要我们不怕拖、不性急，敌人就无所施其技了。”｜wg05-09——对方拖延能不能起作用，取决于我方急不急
  - 1959｜《关于西藏问题和台湾问题》｜AW｜“我们和你们美国只在一点上有关系，就是要求你们从台湾撤军。”｜44d-35——拒绝第三方设定议题，估计「恐怕还要谈十年」
  - 1965｜《胜利的信念是从斗争中得来的》｜AW｜“它说，从小事情开始，大的问题好解决。我们说，要从大的问题开始，小的问题才好解决。”｜52c-24——用中美十年谈判的经历教越方「啃住」核心一条
  - 1973｜《接见基辛格时的谈话*⑴》｜C｜“我说，没有台湾也可以，100年以后再来。”｜56c-18——把中美关系和两岸关系拆开，「由你们定，我们不催」
- 变化：1936—1946 年谈判和作战同时进行，重在用战场胜负决定谈判；1949—1952 年用于建交手续和朝鲜停战谈判，「主动权完全握在我们手中」（wg01-060，1950）；1950—60 年代中美大使级谈判时期，重在啃住撤军一条、拖得起、陪它谈；1970 年代把核心之外的门槛降到最低（「谈得成也行，谈不成也行」，55d-82，1970），时间尺度放到「一百年」。
- 边界与失误：「造成条件」指自身力量和局势上的准备，不是不讲道理的胁迫（js03-030 边界）。底线要少而清楚，什么都说成原则就谈不下去（np05-45 边界）。「拖」的前提是主动权确实在自己一方，自己耗得起；拖下去自己损失更大，就不能照搬（wg01-060、wg05-09 边界）。收窄议题要以事实和法理上的区分为根据，不是凡不想谈的都可以说「你管不着」（44d-35 边界）。在核心利益并不对立的合作关系中，从小事积累信任也可能是合适的办法（52c-24 边界）。他本人的复盘：1972 年对尼克松说，“十几年，说是不解决大问题，小问题不干，包括我在内。后来发现还是你们对，所以就打乒乓球。”（56b-50）
- 可迁移：〔个人〕谈条件时先想清楚自己真正不能让的只有哪一条，明说出来，其余尽量灵活；自己不着急、有退路时，不必被对方的拖延逼着让步。〔社会〕谈判前先在实际处境上做准备，核心诉求少而清楚；对立双方谈判时先解决关键分歧，合作关系中可以从小事积累信任。
- 相关：GJ-04（有理有节，见好就收）、GJ-17（名义和实际分开）、GJ-12

## GJ-20 同朋友有分歧，平等相待，当面讲清，各讲各的，再找共同点
- 一句话：同兄弟党、盟友或合作者有分歧时，先定平等的位置和分歧的分量，当面讲透、给对方留余地，再在具体共同点上合作。
- 触发：同盟友、兄弟党或想合作的国家意见不合，对方请他提意见、要他表态，或者对方担心意识形态不同妨碍来往时。
- 推理链：
  1. 先定位关系：自己只为本国人民的利益说话，大小国家一律平等，没有谁领导谁；同一阵营里有分歧不奇怪。
  2. 框定分歧的分量：十个指头九个相同、一个不同，把分歧限在那一个指头上。
  3. 当面把话讲透，不在背后搞，并给对方留余地（「可能我有误会，也可能我是正确的」）；要求对方把原话照转，不要粉饰。
  4. 不一次捅穿所有问题：对方提出、自己不同意的要争；对方一定坚持，可以接受但保留意见，局部分歧放在整体利益之下。
  5. 各讲各的，不要求对方接受自己的意识形态；同每一方各找具体的共同点，对方怀疑时到合作的事实里「找证明」。
  6. 对别国党的内部事务自我设限：用自己犯过的错误说明没有资格批评，缺点让对方自己去纠正；劝第三方修复关系时，站在受伤一方的位置给一个很小但关键的步骤。
- 他常问的问题：
  - 我们之间是几个指头相同、几个指头不同？
  - 这个意见是当面讲了，还是在背后说的？
  - 对方一定坚持的话，我们能不能接受、保留意见？
  - 各讲各的以后，有哪几处是共同的、可以合作的？
- 跨期证据：
  - 1936｜《与斯诺关于特别问题的谈话》｜AM｜“中国共产党不过是中国的一个政党而已，在它的胜利之中，它将必须为整个的民族说话。”｜mb17-19——用类比拆掉「受第三国际支配」的前提，只在两国群众利益吻合处才谈得上一致
  - 1954｜《和平共处五项原则是一个长期的方针》｜D｜“既然现在存在有怀疑，那末就要找证明，看看究竟是互利还是互相损害。在我们的合作中可以找到证明。”｜wj01-15——先承认边民跑动的事实，表态决不利用，再到合作里找证明
  - 1958｜《同苏联驻华大使尤金的谈话》｜AW｜“昨天的问题我又想了一下，可能我有误会，也可能我是正确的，经过辩论可以解决。”｜42c-01——「九个指头相同，一个指头不同」，要求对方把原话照转
  - 1965｜《毛泽东主席、刘少奇主席等同过境我国的苏联总理柯西金谈话记录（1965年2月12日）》｜B｜“我建议你们要取消从前对阿尔巴尼亚的那一套，说那一套错了。只要这样一句话就完了。”｜52b-08——站在阿方位置推想，给出一个很小但关键的步骤
  - 1973｜《毛泽东会见扎伊尔共和国总统蒙博托谈话记录节选（1973年1月13日）》｜B｜“就是各讲各的。有几处共同的，可以合作的。”｜56b-63——不隐瞒过去支持过对方的反对者，也不掩饰「主张革命」，再转到合作
  - 1975｜《毛泽东主席会见柬埔寨共产党中央书记波尔布特谈话记录（1975年6月21日）》｜B｜“中国没有资格批评你们，50年犯了10次路线错误，有些是全国性的，有些是局部的。”｜56d-55——用自己的错误史给发言权设限，缺点让对方自己去纠正
- 变化：1936 年主要是对外表明独立，不会把国家交给莫斯科；1950 年代对苏联、对邻国当面讲、手里留一把，互不利用对方的跑来者；1958—1965 年在同苏联的分歧里当面讲清、要求对方认错；1960 年代对西方人物不要求对方接受意识形态，只找具体共同点（wj01-107，1961）；1970 年代把「各讲各的」写成交往原则，转向平等和自我约束。
- 边界与失误：「九个指头」的框定要符合实际，分歧已经是根本性的还硬说只是一个指头，就成了回避问题（42c-01 边界）。「接受」以不损害根本利益为限，保留意见要讲出来、记下来，不是表面服从、背后拆台（41c-34 边界）。「在合作中找证明」要有可以查验的具体事项（wj01-15 边界）。对方纠正事实时先问清再谈，迁移时也要先核实事实（52b-08 边界）。「没有资格批评」是对别国内部事务的自我约束，不等于什么都不表态（56d-55 边界）。他本人的复盘：回顾 1950 年同斯大林谈判，“第一，你提出，我不同意者要争；第二，如果你一定要坚持，我可以接受，但保留意见。”（41c-34，1958）；1957 年回忆当年名义上是兄弟党、实际是父子党，说服要耐心（40b-48）。
- 可迁移：〔个人〕同朋友、同事有分歧，先估一估是大部分一致、一小处不同，还是根本不同；当面讲，给对方也给自己留「可能是我误会」的余地；对方坚持时可以照办但把意见讲明。〔社会〕合作方之间有分歧，各自立场写清楚，共同点单列出来先合作；不对伙伴内部的事指手画脚，先检查自己的错误。
- 相关：GJ-10（谁的事谁来定）、GJ-09（防自己翘尾巴）、GJ-04（留有余地）

## GJ-21 一国的事放进世界全局里看，定先后看对整个阵线是否最有利
- 一句话：不把一国的战与和、得与失孤立地看，放进世界格局里，按对整个阵线最有利的标准定先后，做事仍从本国着手。
- 触发：有人只从一国的处境提问（能不能单独打赢、先打谁对我们有利、条件满足了还反不反对），或者一处的人只顾眼前利益、只看局部时。
- 推理链：
  1. 先纠正提问的框子：这一处的事不是孤立的，战与和是世界性的问题；一个地方、一个国家、一个地球各有各的全局。
  2. 感情和做事分开：感情要普遍，做事为了便利先从本国着手，也不限于本国。
  3. 从双方各自的需要说明合作的基础，按各国同主要敌人的关系分档定期望，愿意参加共同战线的不论贡献大小都欢迎。
  4. 定先后的标准不是一国的眼前利益，而是先打败哪一个对整个阵线最为有利。
  5. 外援要争取，但不等外援才行动；敌人一时猖獗，先从自己一方找原因（不团结）。
  6. 用一个极端假设检验自己的立场是不是为了一国得失：即使条件全满足，仍然坚持，因为全局解决了自己才最后安宁。
- 他常问的问题：
  - 这件事只是我们一家的事吗？放到全局里看是什么位置？
  - 先做哪一件，对整个阵线最有利？
  - 对方满足了我们的条件，我们的立场还变不变？
  - 对手能猖獗，是不是抓住了我们自己的弱点？
- 跨期证据：
  - 1920｜《新民学会会员通信集第三集》｜C｜“当然应在中国这一块地方做事；但是感情总要是普遍的，不要只爱这一块地方而不爱别的地方。”｜03-51——「改造中国与世界」，感情和做事分开
  - 1925｜《中国国民党选派学生赴莫斯科孙文大学》｜C｜“中国所需于苏俄者在此，苏俄所需于中国者亦在此。”｜04-52——全世界被压迫民众的大敌只有一个，从双方需要说明联俄的基础
  - 1936｜《论反对日本帝国主义》｜AW｜“让我先提醒你，无论是中国还是日本都不是孤立的国家，东方的和平与战争问题是一个世界性问题。”｜05-01——纠正提问的框子，同时说不必等有了外国联盟才开始抗日
  - 1943｜《英勇斗争的二十二年》｜AW｜“所以在决定战略的时候，不应只从一个国家的眼前利益来看，而要看先打败哪一个法西斯国家对于整个反法西斯阵线最为有利。”｜18d-18——反驳不赞成先打倒希特勒的意见
  - 1956｜《增强党的团结，继承党的传统》｜A5｜“一个地方有一个地方的全局，一个国家有一个国家的全局，一个地球有一个地球的全局。”｜35c-29——宗派主义由于只看局部，团结的范围原则上没有边
  - 1963｜《受压迫的人民总是要起来的》｜AW｜“即使如此，我们仍然反对帝国主义，反对美国帝国主义。因为这不仅是我们自己一国的问题，我们要团结世界大多数人民，这样才能打倒帝国主义。”｜49c-14——用四条全满足的假设检验立场不是为了一国得失
- 变化：1920 年代从世界主义讲先从中国做起，并从双方需要讲联俄；1936—1943 年用在抗日和反法西斯统一战线上，重在定先后、分层次团结，并把敌人一时猖獗归到自己不团结（17b-12，1941）；1956 年把「全局」推到一个地方、一个国家、一个地球三层；1963 年用来说明反对帝国主义不是为一国的得失。
- 边界与失误：「按整个阵线最有利定战略」的前提是各方确实结成一个整体、不是孤立作战（18d-18 边界）。从对方利益推断对方行为只是推断，他在文中也只说「我们认为」「我们相信」（05-01 边界）。互相需要会随形势变化，合作的基础要随时重新检查（04-52 边界）。「有一点用处就团结」讲的是团结面要宽，不是不分是非（35c-29 边界）。他本人的复盘未见于本组卡。
- 可迁移：〔个人〕在一个团队里做事，先问自己这一块在全局里是什么位置，排优先级时看对整个目标最有利的是哪一件，不只看对自己这一块最有利的。〔社会〕地方、部门之间有利益冲突时，把问题放到更大的全局里定先后；争取外部支持，但不等支持到位才开始做。
- 相关：GJ-05（定主要矛盾）、GJ-06（给各方排队）、GJ-10（自力更生为主）
- 来源簇：国际与世界-034，国际与世界-059，国际与世界-066

## GJ-22 坏事有两重性：问它暴露了什么、逼出了什么
- 一句话：先承认是坏事，再找它好的一面：暴露了什么问题、逼出了什么力量，掂量哪面为主，说清变成好事要什么条件。
- 触发：国际上出了乱子、对手施压封锁、在各地进攻，或者自己的错误被揭出来，大家只看到「坏」的一面时。
- 推理链：
  1. 先承认坏的一面（「当然不好」），再指出坏事有两重性，在一定条件下又是好事。
  2. 问它暴露了什么：有问题终究要爆发，迟爆发不如早爆发，早爆发问题小些，容易解决。
  3. 问它逼出了什么：对手的压迫把被压迫的人逼到一起、逼他们学会斗争；外来压力（撤走专家）逼着自己走自己的路；对手的强硬断了中间的路。
  4. 两面都找出来以后，掂量哪一面是主要的，再看往哪个方向转化、要什么条件：有人从中取得教训、采取措施，引以为戒。
  5. 由此定对策：对手的手伸到各处，各地就在各地砍断它，互相帮助；自己的错误分清主次，涉及对外的要尽快改正。
  6. 把这类事放进常态：这类事情是题中应有之义，永远也会有，不必大惊；同时不轻敌。
- 他常问的问题：
  - 这件事坏在哪里？有没有好的一面？
  - 它把什么问题暴露出来了？早暴露好还是晚暴露好？
  - 这个压力逼着我们做成了什么？
  - 两面比起来，哪一面是主要的？要变成好事，我们得做什么？
- 跨期证据：
  - 1933｜《反对日本帝国主义占领热河进攻平津！—临时中央政府宣言—》｜AM｜“国民党军阀的军事冒险及经济封锁只有更加激起全国劳苦群众的反抗，并且，给苏维埃运动向前开展以顺利的条件！”｜mj05-27——对手的封锁和进攻激起反抗
  - 1940｜《相持阶段中的形势与任务》｜AM｜“或者亡国，或者解放。此外没有中间的路。”｜mj12-27——把日本的强硬也算作争取时局好转的有利条件
  - 1956｜《在中国共产党第八届中央委员会第二次全体会议上的讲话》｜A5｜“在马克思主义者看来，坏事有两重性，一重是坏，一重是好。许多人看到那个‘事’字上边有一个‘坏’字，就认为它只是坏。”｜36b-21——匈牙利的问题暴露出来了，「纸包不住火」
  - 1957｜《关于正确处理人民内部矛盾的问题（讲话稿）（一九五七年二月二十七日）》｜B｜“脱党好不好？又好又不好，主要的还是好。”｜38b-39——每件事先承认坏，再找好，最后掂量哪面为主
  - 1959｜《对中央关于在对外关系中切实纠正骄傲现象的指示稿的批语和修改》｜D｜“但既然是缺点错误，而且涉及对外，性质严重，就一定要改正，而且越快越好。”｜wg13-94——对外工作的错误材料暴露出来，引以为戒，使坏事变成好事
  - 1963｜《接见阿尔巴尼亚劳动青年联盟代表团、新闻工作者代表团、工会代表团和档案工》｜C｜“修正主义不援助我们，经济上不援助我们，撤走专家，这也要分析，第一是不好，撤走专家，不帮助了，当然不好；但也是好事，让我们自己干，自力更生，对吗？”｜49b-66——外来压力逼出自力更生
- 变化：1930—40 年代着眼于对手的进攻和封锁激起反抗、断了中间路；1956—1957 年用来回答国际乱子怎样看，形成「先说坏、再说好、掂量主次」的说法；1956—1960 年讲美国是全世界人民的反面教员，各地砍断它的手（35d-33，1956）；1960 年代后多用反话讲对手的压力「帮了忙」，1972 年把谈判中的争吵说成「不打不成交」（56b-61）。
- 边界与失误：他说的是「在一定的条件下」才会产生好结果，前提是有人取得教训、采取措施，不能拿来淡化已经造成的损失，更不能故意制造坏事（36b-21 边界）。两重性不是说坏事会自动变好（38b-39 边界）；「坏事也是好事」要以真能转化为前提（49b-66 边界）。「压迫激起反抗」要看被压迫一方是否有组织、有出路（mj05-27 边界）；「敌人强硬是有利条件」的前提是自己有坚持下去的力量（mj12-27 边界）。对亲身受害的人，不能用「也有好的一面」去打发（46d-03 边界）。「欢迎风波」「反面教员」是从对方已有的行为中取教训，不是主动招惹、制造冲突（44b-18、44b-28 边界）。他本人的复盘：1959 年把对外工作中骄傲、浮夸的材料加批印发，说明「暴露了这些错误，可以引以为戒」，并要求涉外的缺点越快改正越好（wg13-94）。
- 可迁移：〔个人〕遇到挫折，先承认损失，再问它暴露了自己哪些早该解决的问题、逼着自己学会了什么，然后定下具体的改正办法。〔社会〕组织出了事故或受到外部打压，复盘时既算损失，也找它暴露的隐患和逼出来的自主能力，并把改正措施落实到人。
- 相关：GJ-12（算力量账）、GJ-10（自力更生为主）、GJ-11

## GJ-23 对方害怕多半是因为不了解：多来往，请他来看，好坏都让看
- 一句话：对方有疑虑、恐惧时不辩解，先承认不了解是自然的，再用多往来、请对方来看、如实交底来消除，不催对方。
- 触发：邻国或对手对我方有疑虑、恐惧（怕侵略、怕被控制），关系因此推不动时。
- 推理链：
  1. 不辩解，先承认一个时期内互不了解、有疑虑是很自然的；把对方没说出口的担心直接说出来。
  2. 判断这种怕从哪里来：多半来自不了解。
  3. 办法是多往来、多接触，请对方来看；来看时好的坏的都让看，如实交底。
  4. 替对方的难处着想，不催，按对方条件许可的去做，对它的场面话表示谅解。
  5. 用自己的实际需要（需要和平环境办国内的事）说明愿望不是客套。
- 他常问的问题：
  - 对方怕的到底是什么？是不是因为不了解？
  - 我们敢不敢请他来看，好的坏的都让他看？
  - 对方现在的处境，允许它走多快？
  - 我们自己为什么需要这件事，说得出来吗？
- 跨期证据：
  - 1954｜《和平共处五项原则是一个长期的方针》｜D｜“两个国家在一个时期之内互相不够了解，这是很自然的。我们应该在合作中增进了解。”｜wj01-09——不辩解，用自身需要说明和平愿望不是客套
  - 1954｜《和平共处五项原则是一个长期的方针》｜D｜“你们可以去观察一下，看看我们在那里所做的，是对你们友好，还是暗害你们。如果我们不让你们去观察，那就不好了。”｜wj01-16——点破对方怕云南对它不利，请对方去看，并提出对等设领事馆
  - 1955｜《我们的愿望是使中泰两国友好》｜D｜“目前你们处在困难中，要慢慢来，必须按照实际情况去做。必要时对美国说几句好话，对我们说几句坏话，我们是谅解的。”｜wj01-34——不催对方，谅解它的场面话
  - 1960｜《在天津会议上的讲话（摘录）》｜C｜“一定要使他们看好坏两种，最好看好中坏三种，‘强迫’让他们看。”｜46c-33——向外宾如实交底三类社的比例，对方反而觉得讲了公道话
  - 1974｜《同英国前首相希思的谈话》｜C｜“他自己说，第一次很紧张，第二次也还有点紧张，第三次不紧张了。”｜56d-06——怕是因为不了解，来往几次就消了；主张「要吵呢，可以，不要大吵」
- 变化：1950 年代用于缅甸、泰国等邻国，重在请对方来看、不催对方；1960 年用于接待外宾，主张好坏都让看；1974 年用到美国，并由此主张各方「都不要吵架」。
- 边界与失误：如果对方的疑虑来自我方正在进行的具体损害，就不能只说「很自然」，要先停止损害（wj01-09 边界）。点破对方心思适合在态度友好、已有一定信任的场合，关系紧张时直接点破可能被理解为威胁（wj01-16 边界）。谅解场面话的前提是对方实际在走向友好（wj01-34 边界）。如实交底要以调查得来的数字为据（46c-33 边界）。接触能消除的是因不了解而来的怕，双方利益确实冲突时，见面多了也不一定不吵（56d-06 边界）。他本人的复盘未见于本组卡。
- 可迁移：〔个人〕新同事、新邻居对自己有戒心时，不急着解释，多打交道，请对方看看自己实际怎么做事；介绍自己时好的不好的都讲。〔社会〕机构面对公众或合作方的疑虑，开放参观、公开数据，包括不好的部分；不逼对方马上表态，给它按自己条件靠近的时间。
- 相关：GJ-14（替对方算账）、GJ-20（同朋友有分歧）
- 来源簇：国际与世界-053，国际与世界-062，国际与世界-065

## GJ-24 用反例和倒推拆掉对方的前提
- 一句话：对方的结论建立在一条看似当然的前提上时，把前提单独抓出来，用对方也承认的反例或倒推让它站不住。
- 触发：对方的主张靠一条没说破的前提撑着（要同社会主义国家接壤才能搞革命、信仰相同就不打、要照抄苏联、德国能分两个中国也能），或者对方拿一个类比来套我们时。
- 推理链：
  1. 先把对方结论下面的那条前提单独抓出来。
  2. 找一个对方也承认的反例（十月革命时苏联同哪个社会主义国家接壤？）。
  3. 把前提倒过来推，看它会不会自相矛盾（没有十月革命，哪里有社会主义国家？）；或者追到对方经验的源头（苏联当时是抄谁的？）。
  4. 对方用类比时，查两边的前提是不是相同；也可以用对等类比反问（别人不这样说，凭什么这样说你）。
  5. 前提一倒，结论自然站不住，再回到具体问题本身。
- 他常问的问题：
  - 这个结论底下，靠的是哪一条前提？
  - 有没有一个对方也承认的例子，正好跟这条前提相反？
  - 把这条前提倒过来推，会不会推出它自己不成立？
  - 他拿来比的那件事，和我们这件事前提一样吗？
- 跨期证据：
  - 1936｜《与斯诺关于特别问题的谈话》｜AM｜“中国共产党不过是中国的一个政党而已，在它的胜利之中，它将必须为整个的民族说话。”｜mb17-19——用对等类比拆前提：没有人说社会民主党组阁的国家是第二国际专政
  - 1958｜《在军委扩大会议小组长座谈会上的讲话》｜C｜“现在教条主义者主张抄苏联，请问苏联当时是抄谁的？”｜42b-51——追到对方的源头反问，并用对等的办法回应「你们不抄，我们也不抄」
  - 1959｜《不能把台湾问题上的国际问题同国内问题混淆起来》｜AW｜“他们说，德国有东德、西德两个，为什么不能有两个中国?我们说德国是战败国，第二次世界大战时是我们的敌人”｜45c-40——不停在类比表面，查两边的前提
  - 1967｜《毛泽东主席接见马共总书记陈平等谈话记录（1967年1月17日）》｜B｜“十月革命时，苏联同哪个社会主义国家接壤？没有十月革命，哪里有社会主义国家？”｜54b-018——用反例加倒推拆掉意见书里的一条前提
  - 1974｜《毛泽东会见李政道教授谈话记录节选（1974年5月30日）》｜B｜“第一次世界大战、第二次世界大战，他们信的都是一个上帝。上帝跟上帝还打呢！”｜56d-32——用历史反例排除「信仰相同就不打」
- 变化：1936 年用对等类比拆斯诺问题的前提；1958 年追问苏联经验的来源，并把同一追问用到自己党的文件上；1959 年查类比两边的前提；1967、1974 年用历史反例驳意见书和「信仰相同就不打」。
- 边界与失误：反问「他抄谁」是为了说明要结合自己的情况独创，不是说别人的经验不必学（42b-51 边界）。找对手的共同点是为了利用这一点上的一致，不等于在其他问题上认同对方（45c-40 边界）。「不可能不打仗」是对帝国主义之间关系的估计，不能套到一切国家关系上（56d-32 边界）。一个反例只能推倒「凡是」「必须」一类的绝对前提，推不倒「多半」「往往」一类的说法。他本人的复盘：1958 年追问时把同一问题用到自己身上，说八大决议关于技术改革的一章过分强调依靠苏联的帮助，按今天的情况看提得不妥当（42b-51）。
- 可迁移：〔个人〕别人说「做这件事必须先有某某条件」时，想一想有没有没具备这个条件也做成的例子；别人拿一个类比来劝你，先查两件事的前提是不是一样。〔社会〕评审方案或政策论证时，把它依赖的关键前提写出来，逐条找反例；对照搬来的经验，追问它当初是怎样形成的。
- 相关：GJ-01（拿对方自己的话来回答）、GJ-18（判断挂在条件上）、GJ-07
- 来源簇：国际与世界-043，国际与世界-048，国际与世界-055，国际与世界-060

## GJ-25 把出路列全，逐条对照、排除，只剩一条
- 一句话：面对道路选择的质疑，先把可能的路全部列出来，逐项对照、主动拿最强的反例检验，排除完了才说「没有第二条路」。
- 触发：面对「该走哪条路」「为什么不能走别人走过的路」「为什么一边倒」「能不能站在中间」这类道路选择的质疑时。
- 推理链：
  1. 先把面前可能的路全部列出来（殖民地的道路和苏维埃的道路；资产阶级专政和新民主主义；倒向一边还是站在中间）。
  2. 每条路按几项具体标准逐项对照（民族独立、剥削、政治自由），或按国际、国内两层检验；能做成对照表的就做成对照表给人看。
  3. 主动提出最强的反例（基马尔的土耳其），讲出它的具体特殊条件，再反问本国有没有这样的条件。
  4. 对「中间道路」的设想，找一件可以核对的事实看它有没有实际根据。
  5. 用长期经验作证据，最好用立场不同的人得出的同一结论互相印证（孙中山四十年和本党二十八年）。
  6. 排除完了才下「没有第二条路」的结论。
- 他常问的问题：
  - 一共有几条路？有没有漏掉的？
  - 每条路拿同样几项标准比，各是什么结果？
  - 最像能走通的那个例子，它靠的是什么特殊条件？我们有没有？
  - 说可以走中间，有什么事实能证明？
- 跨期证据：
  - 1933｜《中央政府庆祝国际反帝非战大会开幕电》｜AM｜“把苏区内工农的革命热情和他们生活的改善，以及苏维埃政府的一切建设，和你们在帝国主义国民党统治区域内所见到饥饿，死亡，失业和灾荒作成一个显著的对照表”｜mj06-032——把两条道路的实际状况做成对照表，请代表团亲眼来看
  - 1940｜《新民主主义论》｜A｜“一九二七年中国第一次大革命失败之后，中国的资产阶级分子不是曾经高唱过什么基马尔主义吗？然而中国的基马尔在何处？中国的资产阶级专政和资本主义社会又在何处呢？”｜15d-11——国际、国内两层检验，主动提出最强的反例再排除
  - 1949｜《论人民民主专政--纪念中国共产党二十八周年》｜A｜“积四十年和二十八年的经验，中国人不是倒向帝国主义一边，就是倒向社会主义一边，绝无例外。骑墙是不行的，第三条道路是没有的。”｜30b-03——两份立场不同的经验互相印证
  - 1956｜《同工商界人士的谈话》｜AW｜“例如化工、钢铁、炼油、坦克、汽车、飞机等工厂，谁给我们设计的呢?没有一个帝国主义国家替我们设计过。”｜36b-41——用一件可以核对的事实检验「做桥梁」的第三条路
  - 1964｜《关于哲学问题的讲话》｜C｜“在我国，八十年，资产阶级领导的民主主义革命都失败了。我们领导的民主主义革命，一定要胜利。只有这条出路，没有第二条。”｜50d-36——用八十年的失败史作反面证据，并指出自己的《新民主主义论》「只是没讲军事」
- 变化：1933 年用对照表，把两条道路的实际状况摆给人看；1940 年用国际、国内两层检验加反例排除；1949 年加上两份独立经验互证；1956 年用可以核对的事实检验「中间道路」，并说明一边倒是平等的、不硬搬；1964 年回头看，用八十年的失败史作证，并指出自己文章的缺口。
- 边界与失误：排除法要先把可能的路列全，漏掉一条结论就不成立；说反例「条件特殊」要讲出具体的条件，不能一句「情况不同」带过（15d-11 边界）。多数现实问题并非非此即彼，只有结构确实两极化、而且有长期经验证明时，才能下「没有第三条道路」的判断（30b-03 边界）。选边不等于放弃自己的判断，他同时强调一边倒是平等的、不照搬（36b-41 边界）。他本人的复盘：1964 年评价《新民主主义论》是完整纲领，「只是没讲军事」（50d-36）。
- 可迁移：〔个人〕在几条路之间犹豫时，把每条路写下来，用同样几项标准逐项打分，再专门找一个最能说明「别的路也行」的例子，看它靠的条件自己有没有。〔社会〕论证一个方案时，把替代方案列全并逐一排除，排除的理由要可核对；只有确实两极、又有长期经验时，才说没有中间方案。
- 相关：GJ-18（判断挂在条件上）、GJ-24（用反例拆前提）、GJ-11
- 来源簇：国际与世界-061，国际与世界-066

## GJ-26 对外文字先看基调，再站在听的一方挑字眼
- 一句话：审改对外文字时先估它的分量和时机，再分基调和用词两层看，站在听者一方删掉刺激而又不必要的字句，原则照说。
- 触发：审改对外的复电、信稿、讲话稿、答记者问，或决定一篇对外文字要不要发、什么时候发时。
- 推理链：
  1. 先估这份文字的分量：它会不会成为以后同类文书的样本，分量重就放慢，迟几天发也不要紧。
  2. 定稿前把双方往来的原文都调来看齐。
  3. 把稿子分两层看：基调对不对，个别用词、个别段落妥不妥。
  4. 挑字眼的标准是站在听者一方想对方能不能接受：去掉感情色彩重、夸大局势的字眼，理顺绕弯的句子，删掉吓人而又不必要的字句。
  5. 再看时机：对方眼下没有攻击，就不主动发驳斥，回应要和对方当下的动作对应。
- 他常问的问题：
  - 这份文字以后会不会成为样本？要不要放慢？
  - 基调对不对？哪几个词、哪几段对方难以接受？
  - 哪些话会吓到对方，又不是非说不可的？
  - 对方眼下在做什么？现在发合不合时机？
- 跨期证据：
  - 1950｜《关于起草复尼赫鲁的电文给刘少奇的电报》｜D｜“复尼赫鲁电全文的措词须加斟酌，因为此项复文即是对英国及一切资本主义国家复文的样本。”｜wg01-061——看出复文的分量，先把双方往来电报全文调来再定稿
  - 1959｜《对〈陈毅外长答新华社记者问，驳斥杜勒斯诬蔑中国的谰言〉》｜D｜“杜勒斯生病，近日美政府对我无多攻击，目前发表此项谈话，似不适宜。”｜wg14-02——回应要和对方当下的动作对应
  - 1962｜《在一份外交信稿上的批语》｜D｜“近几天一些外交文件，在措词方面有些欠当，这就是一件，我改了一点，请你再阅。”｜ds03-026——从一份信稿归纳近几天外交文件措词的共同毛病，亲手改一点再请对方复阅
  - 1964｜《对政府工作报告（摘要）稿的批语》｜D｜“即把可能使外国人害怕而又不必要的字句改了一些，请酌定。”｜wg18-63——换到外国读者的位置读稿，只改吓人而又不必要的
  - 1970｜《年谱 1970-04-04 条（NP15006，第 11–14 行）》｜N｜“照办。此件基调很好。只是个别用词和个别段落，恐怕对方难于接受。”｜np15-35——分基调和用词两层，站在听者一方挑毛病
- 变化：1950 年着眼于样本文书的分量和先看齐原文；1959 年看发表时机；1960 年代以后集中在压低措辞、换到对方读者的位置读稿，并从一封信推到「近几天一些外交文件」的共同毛病（ds03-026）。
- 边界与失误：只改「不必要」的字句，原则立场不能为了不吓人而含糊（wg18-63 边界）。对发言时机的判断只针对那一次，对方持续攻击、或事实必须澄清时不适用（wg14-02 边界）。np15-35 是年谱摘引，未见全文，没有写明是哪些用词（证据包边界）。他本人的复盘：1962 年批示周恩来近几天外交文件措词有些欠当（ds03-026）。
- 可迁移：〔个人〕发重要邮件或回复前，先问它会不会被转发、被当作先例；写完换到收信人的位置读一遍，删掉情绪化、夸大的词，立场照写。〔社会〕机构对外声明分两步审：先审基调和立场，再审措辞和发布时机；回应要对准对方当下的言行，不在对方安静时主动挑起争论。
- 相关：GJ-14（站到对方位置上）、GJ-04（有理有节）
- 来源簇：国际与世界-065，国际与世界-072

**合并情况**：draft_GJ_1 的 33 个候选和 draft_GJ_2 的 20 个候选合成 26 个模式。主要合并：1-4 与 1-5 → GJ-06；1-3、1-23、2-2 → GJ-07；1-9 与 1-13 → GJ-08；1-10、1-15、2-15 → GJ-09；1-11、2-7、1-33 → GJ-10；1-12、1-19、2-10 → GJ-11；1-17、1-20、1-31、2-16 → GJ-12；1-14、1-21、1-22、2-1 → GJ-13；1-16 与 2-8 → GJ-14；1-30 与 2-9 → GJ-15；1-25 与 2-3 → GJ-18；1-26、1-28、2-5、2-13 → GJ-19；1-27 与 2-4 → GJ-20；1-29 与 2-19 → GJ-21；1-32 与 2-6 → GJ-22；2-11、2-17 并入 GJ-03。

**拿不准的地方**：GJ-22 的「两重性」一般方法偏辩证法领域，本领域保留的是对手压迫、外来压力这一面。GJ-09、GJ-23、GJ-26 的证据从 1950 年代开始，缺 1940 年代以前的卡。GJ-01、GJ-02、GJ-03、GJ-08 都以对方的言行为材料，分工是：GJ-01 用对方的话回答对方，GJ-02 用对方的话判断对方处境，GJ-03 用对方的行动检验对方，GJ-08 给整件事定性质。

**没有收进模式的重要单卡**
- 55b-05（1968，国际与世界-零散）：新独立国家的军队要从人民中重新建立，讲建军与政权的关系，本领域没有同类卡，可留给组织与领导或斗争与竞争领域。
- 15b-06（国际与世界-003）：「搬起石头打自己的脚」，卡少，看不出成链的推理。
- 55c-91、55c-110（国际与世界-007）：美国独立时以小胜大的历史类比，只有两张，题材单一。
- 50c-59（国际与世界-036）：把领土问题放大成清单，单卡。
- np12-22（1958）、ds03-008（1960）：「后发制人」，只有两张、同一个年代，不够单独成模式，暂作 GJ-04 的补充证据。
- ds03-002（1960）：由一件外国时事推出「资本主义世界都是如此，不可能有例外」，证据包自己提示由一例推全体要有更多事实，推理偏薄。
- np10-50、np10-58（1954）：宪法草案讨论中的插话，属国内政治，不在本领域。
- np12-38（1959）：论战文章的讽刺笔法，只可取「讲来历、用形象」的写法，不提炼成模式。
- ds03-061（1968）：「结论不一定对，还是会打的」，材料里看不到原文结论，只有他的反对意见。
- mj10-033（国际与世界-035）：战略退却改变强弱对比，属军事题材。
