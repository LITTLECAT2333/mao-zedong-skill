# 原文库层级与引用规则

`kb/` 是本地原文库，按可靠程度分层。目录名的前缀就是层级代码，脚本据此判断层级。

本 skill 的 references 里，用“”括起并在括号里标了层级的，是核过的原文；用「」括起的，是术语、口号、标注格式或别人的话，不是待引用的原文。

## 引用规则

1. 任何放进引号、归于毛泽东的话，先跑 `python scripts/verify_quote.py "原句"`。
2. 命中 A、A5、AW、AM 可以直接引，标篇名和卷次。命中 S 时确认是诗句本身。命中 Y 时尽量用 `search_kb.py` 找回原篇。同一句在几层都出现时，一般标最高层级；诗句例外，以原作（S）的诗题为出处，文集里他对诗词的解释作佐证。各层的标注写法以 SKILL.md 第 2 条为准。
3. 只命中 B 或 C：可以引，但必须在句后写明来源层级，不能和选集原文混在一起不加区分。只命中 D：可以引，标书名和册次；OCR 文本可能有个别错字，看一眼上下文。只命中 P 或 N：先按上表确认是他本人的话，确认不了就改成转述。
4. 没命中：不加引号，改成转述，写「未核到原文」。不要凭印象补字。
5. 命中易错清单（`references/quote-blacklist.md`）时，按清单的处理意见执行。
6. 编者注释不是毛泽东的话：
   - 选集、文集篇末的注释是出版时编者加的。`verify_quote.py` 只拿正文核验，只在注释里找到时会明说；`search_kb.py` 会把注释里的命中标成「编者注释」。
   - 静火版的编者注释放在同名 `.notes.md` 文件里，是编者的说明和观点，不是毛泽东的话，也不作史实依据，默认不参与检索。
7. 同一件事选集版和原始版本文字不同时（例如 1957 年《关于正确处理人民内部矛盾的问题》的讲话稿与正式发表稿），说明用的是哪一版。
8. 同一讲话在《毛泽东思想万岁》和静火版里文字不同时（例如万岁本把人名、数字写成「×××」，静火版补全了），引用时注明用的是哪个本子。涉及人名、数字的句子，如果两本有出入，改为转述并说明版本差异。
9. 比对会去掉标点并统一常见异体字，偶尔会误命中；下结论前看一眼脚本输出的原文上下文。
10. M 层文本里夹有译本编者的注，也有列宁转引马克思的段落。标出处前看上下文：转引的标原作者和原书，编者注标「某书编者注」。
11. C 层有些条目是别人的传达或报道（如「毛主席号召……」「某某传达」），引用时加「据传达」。

## 库里没有的书

- v4 起已收入《建国以来毛泽东文稿》、军事文集、外交文选、书信选集、早期文稿（D 层）、《毛泽东集》正编和补卷（AM 层）、《毛泽东哲学批注集》（P 层）、《毛泽东年谱》（N 层）。这些书都来自扫描件 OCR，没有和纸本逐页对校。
- 《毛泽东传》等传记：未收入。
- 生平细节（具体日期、会议、在场人员）先用 `search_kb.py --tiers N` 查年谱；年谱叙述是编者写的，用作史实线索，正式引用请对照纸本。

## 文革时期的材料分布

官方《文集》第八卷只收 1959–1975 年的 90 篇，1966–1976 年的国内讲话几乎没有收入。文革时期的本人言论主要在 B 层（外交会谈记录）和 C 层（静火版第七卷、《毛泽东思想万岁》1961–1968 部分）。讲文革时引原话，几乎都要标 B 或 C 层。

## 转录勘误

- 诗词（S）：《七律·人民解放军占领南京》“宜将剩勇追穷寇”一句，网页转录正文误作「胜勇」；同一文件的注释里写的是「剩勇」，与通行版本一致，构建时已改正。
- 诗词（S）：原有两份合集，其中一份文件名误作「001-七古·送纵宇一郎东行.md」，内容是同一合集的另一版网页（诗词正文都包含在 `001-毛泽东诗词.md` 里，差别在页面导航、个别注释的措辞和少数异体字，如「馀/余」），已删除。
